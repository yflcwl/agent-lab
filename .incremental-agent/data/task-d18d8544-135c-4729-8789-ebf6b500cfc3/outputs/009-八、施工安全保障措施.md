# 八、施工安全保障措施

## 8.1 安全管理总体原则
施工过程中主要防范高空作业、有限空间作业、用电安全、配件遗留、施工用品及工具建渣坠入地面等风险。必须对施工范围进行有效封闭，防止无关人员进入，并及时清理卫生，确保消防站正常战备秩序不受影响。
- **入场交底**：施工前对本次做法工艺、施工安全要点等进行全面安全技术交底。
- **引领旁站**：施工人员由正式引领人员带入，在施工区域由专职安全员加强旁站监督。
- **清点销项**：施工人员工具、材料配件进退场必须严格清点销项，严禁遗留现场。

## 8.2 组织机构与岗位职责
建立以项目经理为核心的安全管理小组，各成员岗位职责如下：

| 序号 | 职务 | 主要职责 |
| :--- | :--- | :--- |
| 1 | 项目经理 | 统筹安排施工事宜，全面负责施工现场安全生产管理工作。 |
| 2 | 生产经理 | 负责现场组织和管理工作，协调各班组安全作业。 |
| 3 | 技术负责人 | 编制相关技术方案并进行安全技术交底。 |
| 4 | 安全负责人 | 进行日常隐患排查，确保各项安全措施落实到位。 |
| 5 | 施工员 | 落实施工方案，协调相关事宜，监督班组规范操作。 |

## 8.3 动火作业安全保障措施
本工程涉及墙面涂料、屋面防水及金属构件除锈焊接等动火作业，须严格执行以下保障措施：

### 8.3.1 作业前准备
1.  **审批制度**：严格执行动火作业审批制度，办理动火作业许可证，明确动火等级、地点、时间、人员及安全措施，未经审批严禁作业。
2.  **现场清理**：作业前清理动火点 **10米范围内** 易燃易爆物品，无法移除的采用防火毯、石棉板等彻底隔离覆盖。
3.  **设施配备**：检查作业区域消防设施，配备足量合格灭火器、消防沙、消防水带，确保完好有效。
4.  **专项交底**：对作业人员进行专项安全技术交底，明确作业风险、应急措施，特种作业人员必须持证上岗。
5.  **气体检测**：检测作业区域可燃气体浓度，合格后方可动火；在受限空间、密闭场所动火需持续监测。

### 8.3.2 作业中管控
1.  **专人监护**：动火作业实行专人监护，监护人全程在岗，不得擅自离岗，发现异常立即停止作业。
2.  **防护用品**：作业人员按规定穿戴阻燃防护服、防护眼镜、防护手套等劳动防护用品。
3.  **设备管理**：动火工具、设备完好无损，气瓶直立固定、间距不小于 **5米**，距动火点不小于 **10米**，严禁暴晒、倾倒。
4.  **范围控制**：严格控制动火范围与时间，严禁擅自扩大作业区域、延长动火时长；中途停歇、复工前重新检查确认。
5.  **高处动火**：高处动火采取接火盆、防火毯等防火花飞溅措施，防止引燃下方可燃物。

### 8.3.3 作业后收尾
1.  **现场清理**：作业结束后，动火人、监护人共同检查现场，彻底熄灭火源，清理残留火星、焊渣。
2.  **留守观察**：留守监护 **30分钟以上**，确认无复燃、无隐患后，方可离开现场。
3.  **许可关闭**：关闭动火作业许可，做好作业记录，发现隐患及时上报处理。

## 8.4 临时用电作业安全保障措施
现场施工用电采用TN-S接零保护系统，实行三级配电两级保护。

### 8.4.1 作业前准备
1.  **作业许可**：办理临时用电作业许可，明确接线方式、负荷、防护措施，严禁私拉乱接。
2.  **持证上岗**：作业人员为持证电工，对电缆、开关、漏电保护器、配电箱等设备进行全面检查，严禁使用破损、老化、不合格电器。
3.  **保护装置**：临时用电系统必须安装漏电保护器，做到 **"一机一闸一漏一箱"**，接地接零保护规范可靠。
4.  **安全电压**：现场设置明显用电警示标志，潮湿、受限空间等危险区域使用安全电压（**≤36V**，特别潮湿**≤12V**）。

### 8.4.2 作业中管控
1.  **线路敷设**：电缆架空敷设或穿管保护，严禁碾压、拖拽、浸泡水中，穿越通道采取防破损措施。
2.  **配电箱管理**：配电箱上锁管理，防雨、防潮、防尘，非专业人员严禁操作。
3.  **接地保护**：用电设备金属外壳可靠接地，移动电器使用绝缘完好的软橡胶电缆。
4.  **断电操作**：严禁带电接线、拆线、检修，停电作业执行 **"停电—验电—挂牌—上锁"** 制度。
5.  **险情处置**：发现漏电、短路、触电等险情，立即切断电源，严禁带电处置。

### 8.4.3 作业后收尾
1.  **断电拆除**：作业完毕，及时切断总电源，拆除临时电缆、设备，清理现场。
2.  **消除隐患**：检查线路、设备无遗留隐患，做好临时用电拆除记录，关闭用电许可。

## 8.5 动土作业安全保障措施
挡土墙基础开挖涉及地下管线交叉，须严格防范管线破坏事故。

### 8.5.1 作业前准备
1.  **管线排障**：组织相关管线产权单位对施工范围内现有地下管线进行管线确认及排障作业。
2.  **技术交底**：根据管线确认单对工长及班组长、工人进行安全技术交底，明确可能涉及的管线种类及走向；同时对工人进行心理疏导，降低急躁施工情绪，确保人工开挖管线万无一失。

### 8.5.2 作业中管控
1.  **探沟开挖**：结合地下管线图，采用永临结合方式，沿原有挡土墙边线开挖探沟（探沟长36m、宽0.8m、深1m），指派专人全程指挥、跟进。
2.  **管线防护**：开挖作业时，应对各类地下管线进行有效防护，防止管线挖断损坏导致漏水、漏电等，保证作业人员及周边人员的人身安全。
3.  **异常情况处理**：在施工期间，人工开挖若发现管线，应确认其位置，做好标记，通知产权单位对管线进行二次确认，经同意后，确保施工按管线保护要求实施。
4.  **事故报告**：施工过程中，一旦出现导致各类管线受损情况，发现人第一时间向项目负责人报告，并向动能部项目负责人报告，由动能部联系涉及管线的所属单位进行排查、确认，及时恢复损坏管线。
