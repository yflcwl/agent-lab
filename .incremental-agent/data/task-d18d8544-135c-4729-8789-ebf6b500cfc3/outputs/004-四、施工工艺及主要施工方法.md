# 四、施工工艺及主要施工方法

## 4.1 外墙翻新工程

### 4.1.1 前期拆除工程
**（1）保温层及饰面拆除**
对外墙柱面聚苯乙烯泡沫塑料保温层（1361㎡）、外立面抹灰及涂料层（1789㎡）、水泥砂浆粘结层（106㎡）进行全面拆除。采用人工与小型机械相结合的方式，自上而下分段作业，严禁大面积同时剥离。拆除过程中设专人观察墙体稳定性，发现空鼓松动迹象立即停止并清理。拆除的建渣集中装袋，经指定路线清运出场。

**（2）入户处幕墙及龙骨拆除**
对入户处88㎡墙柱面龙骨及饰面进行保护性拆除，拆除后对暴露的结构基层进行清理检查。墙面字体（52个）拆除时注意保护周边墙体及管线。

**（3）空调外机移机及排水管拆除**
对23台空调外机进行保护性断电拆卸，移至安全区域妥善存放，后续进行加氟及利旧安装。拆除墙上182m DN110塑料排水管，临时封堵管口防止雨水倒灌。

### 4.1.2 墙面基层修复与防水
**（1）墙面一般抹灰**
拆除面清理干净后，刷素水泥浆一遍（含胶水），随后进行25mm厚干混砂浆一般抹灰施工。抹灰分两层进行，底层找平后待收水再抹面层，表面搓毛处理以确保后续防水层及腻子层的附着力。

**（2）墙面涂膜防水**
抹灰层干燥后，涂刷1.5mm厚Ⅱ型JS涂膜防水涂料（1789㎡）。涂膜施工前基层须平整、无起砂，采用十字交叉法涂刷两遍，确保厚度均匀、无漏涂。阴阳角部位做加强处理，涂膜完成后进行蓄水或淋水试验，确认无渗漏后方可进入下一道工序。

### 4.1.3 外饰面涂装
**（1）腻子批刮**
防水层验收合格后，满刷界面剂1遍，随后批刮2遍成品耐水型腻子膏。第一遍腻子主要找平，第二遍腻子精平收光，干透后用砂纸打磨至平整光滑，无砂痕、无起皮。

**（2）真石漆喷涂**
涂刷水性封闭底漆一道，底漆干透后采用专用喷枪喷涂外墙真石漆，喷涂厚度均匀、色泽一致。最后涂刷罩面保护漆一道，增强耐候性及自洁性能。

### 4.1.4 幕墙修复及其他
**（1）铝塑板幕墙安装**
入户处新做88㎡铝塑板幕墙。采用60×3镀锌矩管钢骨架（双向间距600mm），4mm厚40丝铝塑板通过外墙耐候结构胶粘贴固定。塑料胶条嵌缝，耐候胶密封收口。骨架焊接前须完成防腐处理。

**（2）塑钢窗打胶维修**
对288㎡塑钢窗原有老化耐候胶进行切割清理，清洁槽口后重新打注耐候密封胶，确保密封效果。金属门油漆翻新106㎡，表面打磨除锈后涂刷防锈底漆及面漆。

**（3）挑檐屋面防水**
拆除挑檐屋面原有空壳和起砂找平层（100㎡），重新抹1:3水泥砂浆找平层（最薄处20mm，2%坡度），随后涂刷2.0mm厚3涂一布聚合物丙烯酸聚氨酯防水涂料。

**（4）空调外机利旧安装**
外饰面施工完成后，将23台空调外机恢复安装就位，更换10台镀锌角钢支架，加氟至满足运行要求。恢复安装182m DN110排水管。

## 4.2 天棚及墙面翻新工程

### 4.2.1 铲除与基层处理
对室内天棚及墙面涂料层（4902㎡）及混合/水泥砂浆面（500㎡）进行全面铲除，铲除至坚实基层。清除浮灰及松动颗粒，涂刷界面剂增强新旧基层粘结力。局部空鼓或开裂区域进行凿除修补。

### 4.2.2 墙面抹灰与涂饰
对修补后的500㎡墙面进行13mm厚干混砂浆抹灰找平。抹灰层干燥后，天棚及墙面满刮腻子，打磨平整后涂刷界面剂一道。随后涂刷乳胶漆底漆一遍、面漆两遍（4902㎡），涂刷顺序为先顶后墙、先上后下，色泽均匀一致，无流坠、无刷痕。

### 4.2.3 石膏板吊顶及防爆膜
对135㎡天棚区域新做600×600石膏板吊顶面层，厚度与原有保持一致。龙骨安装须水平牢固，石膏板接缝处进行嵌缝处理。在指定区域玻璃表面（46.5㎡）加贴防爆膜，贴覆前彻底清洁玻璃表面，采用专业工具刮平排除气泡，确保平整无皱。

## 4.3 车库环氧地面翻新工程

### 4.3.1 原地面拆除
铲除原车库环氧地坪层（758㎡），使用打磨机及铲刀彻底清除残留涂层及粘结层。对局部破损严重的250mm厚混凝土地面进行凿除（28m³），凿除边缘切割整齐，清理基层浮渣。

### 4.3.2 混凝土楼地面浇筑
支设模板，浇筑C30商品混凝土楼地面（112㎡），厚度250mm。采用振捣棒振捣密实，表面刮杠找平，收光机压光。浇筑完成后及时覆盖养护，养护期不少于7天。

### 4.3.3 密封固化地坪施工
**（1）基层打磨处理**
混凝土养护期满且含水率合格后，使用地坪打磨机对758㎡地面进行两遍打磨，去除浮浆及污渍，修补坑洞及局部不平整处，吸尘清理干净。

**（2）密封固化剂处理**
均匀涂刷混凝土密封固化剂，分五次进行固化研磨处理。每次涂刷后待材料充分渗透反应，使用不同目数的树脂磨片逐级研磨，使固化剂与混凝土充分反应形成致密硬化层。

**（3）抛光处理**
固化研磨完成后，进行三次抛光处理，每次抛光后撒布专用抛光剂，使地面呈现光泽致密的表面效果。最终地面达到高硬度、高耐磨、不起尘的使用标准。

## 4.4 二楼战斗员宿舍卫生间翻新工程

### 4.4.1 拆除工程
依次拆除地砖（36㎡）、墙砖（166㎡）、铝合金扣板吊顶（36㎡）、墙面及地面防水找平层（166+36㎡）。拆除100m DN25 PPR给水管，拆除10套蹲便器、灯具、热水器、淋浴器等洁具设备。拆除过程中注意保护承重结构及相邻房间设施，建渣袋装清运。

### 4.4.2 基层处理与找平
清理拆除后的基层，对楼地面进行20mm厚水泥砂浆找平层施工（36㎡），找坡1%坡向地漏，最薄处20mm。墙面进行20mm厚干混砂浆找平层施工（332㎡），表面搓毛处理。找平层完成后充分养护，确保无空鼓开裂。

### 4.4.3 防水工程
**（1）楼地面涂膜防水**
找平层干燥后，涂刷1.5mm厚Ⅱ型JS涂膜防水涂料（36㎡）。阴角、管根部位做圆弧处理并附加增强层，涂膜分两遍交叉涂刷，厚度均匀。完成后进行24h蓄水试验，无渗漏方为合格。

**（2）墙面涂膜防水**
卫生间墙面涂刷1.5mm厚Ⅱ型JS涂膜防水涂料（166㎡），淋浴区防水高度不低于1.8m，其他区域不低于0.3m。涂膜完成后做防水保护层（20mm厚水泥砂浆）。

### 4.4.4 墙地砖铺贴
**（1）墙面砖铺贴**
防水保护层干燥后，墙面铺贴10mm厚300×600内墙面砖（122㎡）。采用25mm厚1:2.5干硬性水泥砂浆结合层，铺贴前墙面洒水湿润，面砖提前浸水晾干。铺贴时从上往下进行，使用十字卡控制缝宽，砂浆饱满、平整垂直。

**（2）地面砖铺贴**
地面铺贴12mm厚300×300防滑地砖（36㎡），采用20mm厚水泥砂浆粘接层。铺贴时注意找坡方向，确保地漏处为最低点。勾缝密实，表面清洁。

### 4.4.5 吊顶及管道洁具安装
**（1）铝合金扣板吊顶**
安装600×600铝合金扣板吊顶（135㎡），金属龙骨安装牢固平整，扣板拼接严密，色泽一致。照明灯具位置预留准确。

**（2）管道安装**
暗埋敷设DN25 PPR给水管100m，热熔连接，打压试验合格后隐蔽。管道走向横平竖直，固定牢靠。

**（3）洁具利旧安装**
7组利旧蹲便器、3组新蹲便器、10套利旧热水器、10套利旧淋浴器、10套利旧吸顶灯依次安装就位。安装牢固、连接密封，通水通电调试正常。
