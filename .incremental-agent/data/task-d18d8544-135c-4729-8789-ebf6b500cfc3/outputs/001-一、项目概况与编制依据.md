# 一、项目概况与编制依据

## 1.1 项目概况
本工程为双流机场东消防站维修工程，项目地址位于双流机场东消防站站内（含110kV羊航线1#杆塔相关区域）。工程旨在通过对消防站既有建筑外立面、室内天棚及墙面、车库地面以及二楼战斗员宿舍卫生间进行全面翻新维修，消除设施老化隐患，提升营房整体环境质量与战备保障形象。

本次维修工程主要涵盖四大板块：外墙翻新工程、天棚及墙面翻新工程、车库环氧地面翻新工程以及二楼战斗员宿舍卫生间翻新工程。工程涉及保温层及饰面拆除、真石漆及幕墙翻新、室内乳胶漆重涂、环氧地坪铲除与固化地坪重做、卫生间防水及给排水管线改造等内容。
