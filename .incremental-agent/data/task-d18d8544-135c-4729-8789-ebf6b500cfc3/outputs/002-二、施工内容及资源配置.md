# 二、施工内容及资源配置

## 2.1 施工内容
本工程为综合性维修翻新项目，施工区域主要分布在双流机场东消防站站内建筑及外部附属设施（含110kV羊航线1#杆塔周边）。整体施工内容划分为以下五大板块：

**（1）外墙翻新工程**
对既有外立面进行彻底整治。包括拆除原有的外墙保温层（聚苯乙烯泡沫板）、抹灰层及涂料饰面，修复空鼓开裂部位。重新进行墙面一般抹灰，涂刷1.5mm厚JS涂膜防水层，随后批刮耐水腻子并喷涂真石漆及罩面保护漆。同时对入户处破损幕墙进行钢骨架修复及铝塑板更换，对塑钢窗进行切割旧胶、清理打胶密封处理。配合外立面施工，完成空调外机的保护性移机、支架更换、加氟及利旧安装，以及排水管拆除恢复和黄角树修枝养护。

**（2）110kV羊航线1#杆塔区域专项维修**
针对杆塔周边设施进行安全隐患治理。包括不锈钢护栏的保护性拆除与后续利旧安装，杆塔周边6m×6m范围地面的硬化处理（100mm厚C20细石混凝土配筋地坪），损坏沟盖板的更换，以及塌陷挡土墙的拆除与重建（370厚砖基础+240厚砖墙身+C20钢筋混凝土压顶）。

**（3）天棚及墙面翻新工程**
针对室内公共区域及功能用房，铲除天棚及墙面的旧涂料和疏松砂浆层，修补基层。新做石膏板吊顶，满批腻子后涂刷底漆及面漆。对特定区域玻璃表面加贴防爆膜，提升防护等级。

**（4）车库环氧地面翻新工程**
针对车库地面破损及起砂问题，铲除原环氧地坪层，对局部破损严重的250mm厚混凝土地面进行凿除，重新浇筑C30商品混凝土。在此基础上进行五遍密封固化剂研磨固化处理，并实施三次抛光及撒抛光剂工艺，形成高强耐磨地坪。

**（5）二楼战斗员宿舍卫生间翻新工程**
对老旧卫生间进行全面升级。拆除原有地砖、墙砖、吊顶及失效防水层。重新开槽暗埋PPR给水管，新做地面及墙面1.5mm厚JS防水层并进行蓄水试验。铺贴300×300防滑地砖及300×600内墙砖，安装铝合金扣板吊顶。原有蹲便器、淋浴器、热水器及灯具经检测合格后利旧安装，部分蹲便器进行更换。
