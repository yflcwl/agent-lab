# 七、质量保证措施

## 7.1 质量目标与体系
### 7.1.1 质量目标
- **总体目标**：工程一次验收合格率100%，确保工程质量符合《建筑工程施工质量验收统一标准》GB50300-2013及相关专业规范要求，实现业主满意。
- **分项质量控制指标**：
  - 挡土墙砌筑砂浆饱满度≥80%
  - 外墙涂膜防水无渗漏
  - 室内墙面乳胶漆平整度偏差≤2mm/2m
  - 地砖铺贴空鼓率≤3%（单块≤5%）

### 7.1.2 质量管理体系
严格执行公司三级质量管理模式：**自检→互检→交接检**。建立以项目经理为第一责任人、技术负责人主管、专职质检员具体实施的质控网络，实行质量一票否决制。

## 7.2 材料进场检验制度
### 7.2.1 原材料控制
所有进场材料（含辅材）必须符合设计要求和相关质量标准，实行"三证"查验（出厂合格证、检测报告、生产许可证）。重点材料如下：

| 材料类别 | 检验项目 | 抽检频次 |
| :--- | :--- | :--- |
| Mu15页岩砖 | 抗压强度、外观质量 | 每15万块为一验收批，不足按一批计 |
| M10/C20/C30混凝土 | 坍落度、强度等级 | 每班至少制作一组试块 |
| JS防水涂料 | 固含量、拉伸强度 | 每批次抽样送检 |
| 真石漆/乳胶漆 | 有害物质限量、色差 | 每进场批次核验报告+现场比对 |
| PPR给水管 | 压力试验、环刚度 | 安装前逐根检查 |

### 7.2.2 材料储存管理
易受潮材料（水泥、腻子粉）须垫高堆放（木方基础100mm），远离水源；油漆、涂料类材料存放于专用库房，保持通风干燥，严禁露天暴晒。

## 7.3 施工过程质量控制要点

### 7.3.1 挡土墙及土方工程质量控制
- **沟槽开挖**：必须人工清底，严禁机械扰动原状土；基底平整度控制在±15mm以内。
- **回填夯实**：分层厚度≤300mm，采用打夯机压实，每层取样检测压实度。
- **砌体工程**：
  - 砂浆拌合采用重量比投料，搅拌时间≥2min
  - 水平灰缝厚度8~12mm，竖向灰缝宽度10mm
  - 每天砌筑高度不超过1.5m，防止墙体变形
  - 临时间断处留斜槎，斜槎长度不小于高度的2/3

### 7.3.2 防水工程质量控制
- **基层处理**：防水层施工前，基层必须清理干净、干燥（含水率≤9%），阴阳角做成圆弧（R=50mm）。
- **涂膜施工**：JS防水涂料分两遍涂刷，间隔时间以手触不粘为宜；第一遍干透后方可涂刷第二遍，十字交叉法作业。
- **闭水试验**：地面防水完成后进行24h蓄水试验，水深30~50mm，确认无渗漏后方可进入下道工序。

### 7.3.3 装饰装修工程质量控制
- **抹灰工程**：底层砂浆终凝后浇水养护；面层抹灰不得有裂纹、空鼓；垂直度偏差≤3mm/2m。
- **涂饰工程**：腻子批刮厚度均匀，打磨后表面无砂眼、无刷痕；乳胶漆涂刷顺序"先上后下、先里后外"，颜色一致无流坠。
- **地面工程**：
  - 固化地坪打磨至混凝土表面骨料均匀露出
  - 地砖铺贴时弹线定位，缝隙宽度一致（2mm±0.5mm）
  - 卫生间地面找坡准确，地漏处为最低点

### 7.3.4 机电安装工程质量控制
- **管道安装**：PPR管热熔连接温度控制在260±10℃，承插深度符合规范，安装后按0.8MPa压力打压试验30min压降≤0.05MPa。
- **电气线路**：电缆敷设前摇测绝缘电阻（≥0.5MΩ），接线端子拧紧无松动，配电箱内回路标识清晰。

## 7.4 成品保护措施
- **已完工部位**：外墙涂装完成后设置警戒隔离带，禁止非作业人员靠近；新铺地砖上覆盖保护膜，上方严禁堆放重物。
- **设施保护**：护栏拆除做好编号分类存放，避免划伤变形；空调管线预留口临时封堵，防止异物进入。
- **交验移交**：全部工程完成后由专人巡检，发现不慎损坏立即标识并安排修补，做好修补记录备查。

## 7.5 质量通病防治
| 序号 | 常见质量问题 | 原因分析 | 预防措施 |
| :--- | :--- | :--- | :--- |
| 1 | 外墙涂膜空鼓开裂 | 基层未干透即施作、涂层过厚 | 严格控制含水率，分层涂刷，每遍厚度≤0.5mm |
| 2 | 室内墙面乳胶漆流坠 | 涂料稀释过度、涂刷不均匀 | 按说明书比例加水，滚涂手法匀速 |
| 3 | 地砖空鼓脱落 | 粘结层不饱满、基层浮灰未清理 | 满浆法铺贴，基层拉毛处理 |
| 4 | 防水层渗漏 | 阴阳角未加强、接口密封不严 | 增设附加层，节点处多遍涂刷 |
| 5 | 砌体灰缝不饱满 | 操作不当、砂浆和易性差 | 选用优质混合砂浆，工人持证上岗 |
