# 三、施工平面布置及现场管理

## 3.1 施工围挡设置
本项目位于机场消防站内及110kV羊航线1#杆塔周边，为降低施工对消防战备执勤的影响，保障现场作业安全，拟对施工及影响区域实施全封闭打围管理。

### 3.1.1 围挡规格与材质
- **高度与长度**：打围高度设定为2.5m，沿施工影响区域布设，总打围长度约36m。
- **框架结构**：采用75型轻钢龙骨或40mm镀锌矩管作为骨架，确保结构稳固、抗风可靠。
- **面板材质**：选用厚度12mm彩钢板，外层要求平整美观，严禁有尖锐物凸出。

### 3.1.2 围挡标识与安全要求
围挡入口一侧离地1.7m处设置施工信息栏，采用喷涂或粘贴形式明示项目名称、施工单位、施工内容及现场负责人信息。同步张贴《施工项目风险控制表》及中英文安全警示标语（如"施工中，请勿靠近"、"必须佩戴安全帽"、"闲人免进"、"注意安全"等）。围挡设置须确保安全稳固、防倾防塌，四周与施工区域边界距离控制在1.2m以内，且不得影响周边消防通道及人行道的正常通行。

## 3.2 材料仓库及加工区部署
为减少现场加工带来的安全风险与场地占用，材料仓库及加工房统一设置于公司集中加工库房，现场仅保留必要周转材料。
- **防潮堆放**：板材、水泥、石膏腻子等易受潮材料，地面须架设100mm高木方基础，上铺木工板隔潮，材料置于木工板之上。
- **分类码放**：零星材料统一配置金属货架，分类整齐堆放并设置清晰标识。
- **环境管理**：库房保持通风干燥，严格执行禁火规定。

## 3.3 消防设施部署
施工现场严格执行消防安全管理规定，按区域足额配置消防器材：
- **施工作业区**：按每50㎡或15m半径内不少于2具3A级5kg干粉灭火器的标准配置。本次施工区面积约36㎡，现场固定配置2具5kg干粉灭火器。
- **库房区域**：每15㎡配置2具3A级5kg干粉灭火器，门口醒目位置悬挂"严禁烟火"警示牌。
- **临时动火点**：专项设置2具4A级8kg干粉灭火器。动火作业前严格办理动火证，作业期间专人全程协同监护。
- **临时用电**：全线采用三级配电箱供电，落实"一机一闸一漏一箱"要求。施工区域内严禁吸烟。

## 3.4 施工作业流程与主要构造参数
### 3.4.1 总体施工流程
本项目作业时段严格控制在每日8:00至18:00。总体施工遵循以下工序逻辑：
> 施工打围 → 地下管线排障 → 不锈钢护栏拆除 → 人工清表 → 拆除杆塔挡土墙内外地坪 → 塌陷旧挡墙拆除 → 沟槽土方挖运与修边捡底 → C20垫层浇筑 → M10水泥砂浆砌筑370厚页岩砖基础（高0.9m）→ 砌筑240厚页岩砖挡土墙（高1.2m）→ 基础土方回填夯实 → 地圈梁钢筋制安与模板支设 → C20地圈梁混凝土浇筑 → 杆塔内100厚C20配筋地坪浇筑（φ8@150单层双向，找2%坡度）→ C30预制沟盖板制安（φ12@150）→ 挡墙及压顶15厚1:3水泥砂浆抹灰 → 界面剂+外墙腻子+一底两面乳胶漆涂装 → 黄黑警示油漆涂刷 → 不锈钢护栏利旧安装 → 场地清理退场。

### 3.4.2 关键构造参数控制
| 构造部位 | 设计参数与工艺要求 |
| :--- | :--- |
| **挡土墙基础** | 100mm厚C20混凝土垫层（宽570mm），上部370厚Mu15页岩砖、M10砂浆砌筑，高度0.9m |
| **墙身砌筑** | 240厚Mu15页岩砖、M10水泥砂浆砌筑，墙体高度1.2m |
| **顶部压顶** | C20钢筋混凝土截面240mm×200mm，主筋4Φ12，箍筋Φ8@200 |
| **内部地坪** | 100mm厚C20细石混凝土，内配φ8@150单层双向钢筋网，表面找2%排水坡度 |
| **沟道盖板** | C30预制混凝土板（100×500×1000mm），配置Φ12@150单层双向钢筋 |
| **外饰面涂装** | 15mm厚1:3水泥砂浆两遍成活 → 界面剂1遍 → 外墙腻子2遍 → 一底两面外墙乳胶漆 → 黄黑相间警示漆 |

## 3.5 现场日常管理与成品保护
- **人员管控**：所有进场人员必须规范佩戴安全帽、反光背心等劳动防护用品；专职安全员实行全过程旁站监督。
- **机具与物料管理**：工具、材料、配件进出场严格执行清点登记与销项制度，严禁遗留现场。
- **环境卫生**：施工建渣与废弃物分类集中堆放，日产日清，运输车辆采取覆盖措施，严防抛洒滴漏影响消防站环境。
- **成品保护**：拆除的不锈钢护栏须编号分类存放，利旧安装前完成除锈补焊；地坪浇筑及墙面涂装完成后设置警戒隔离，避免交叉作业造成破损。发现不慎损坏部位须立即标识并安排专人修补。
