# 五、危险源识别与风险管控

## 5.1 危险源辨识与风险分析
本工程涉及外墙翻新、室内改造、地面固化及杆塔周边土建维修等多项作业，工序交叉多、环境复杂。为有效预防事故发生，本工程采用LEC评价法（作业条件危险性评价法）对施工全过程进行风险辨识与分级管控。
- **L (Likelihood)**：事故发生的可能性（10—完全可以预料；0.1—实际不可能）。
- **E (Exposure)**：人员暴露于危险环境的频繁程度（10—连续暴露；0.5—非常罕见暴露）。
- **C (Consequence)**：发生事故产生的后果（100—10人以上死亡；1—无伤亡）。
- **D (Danger)**：风险值（D=L×E×C）。D值越大，风险越高。根据D值大小将风险划分为重大、较大、一般和低风险四个等级。

结合本工程实际，主要事故类型包括：火灾、触电、物体打击、机械伤害及管线破坏等。

## 5.3 专项风险管控措施

### 5.3.1 临时用电安全管控
- **系统配置**：临时用电采用TN-S接零保护系统，实行三级配电两级保护，严格执行“一机一闸一漏一箱”。
- **线路敷设**：电缆线路采用埋地或架空敷设，严禁沿地面明设或乱拉乱接。过路电缆须加穿钢管保护。
- **人员管理**：所有电气安装、维修或拆除作业必须由持证电工完成。非专业人员严禁私接电源。

### 5.3.2 动火作业安全管控
- **审批制度**：动火前必须办理《动火作业许可证》，明确动火等级、地点、时间及安全措施。
- **现场清理**：动火作业前必须清除动火点周围10米范围内的易燃易爆物品；无法清除的，必须采用防火毯或石棉板进行隔离覆盖。
- **全程监护**：动火期间必须配备不少于2具有效灭火器，并安排专人全程监护。动火完毕后，留守观察至少30分钟，确认无复燃隐患后方可撤离。

### 5.3.3 地下管线保护管控
- **探沟先行**：土方开挖前，必须组织管线产权单位进行现场确认，并沿原有挡土墙边线人工开挖探沟（长36m、宽0.8m、深1m），探明管线走向及埋深。
- **人工挖掘**：探沟及基槽开挖严禁使用十字镐、钢钎等尖锐工具，必须采用人工小心挖掘。
- **应急响应**：一旦发现管线受损或不明管线，应立即停止作业，保护现场，并向项目负责人及管线产权单位报告，经确认并采取保护措施后方可继续施工。

## 5.4 风险预警与应急处置
- **预警机制**：建立日常巡查与隐患排查制度，发现风险值升高或管控措施失效时，立即发布预警并暂停相关作业。
- **应急响应**：一旦发生险情，现场人员应立即停止作业并撤离至安全区域，同时向项目负责人报告。启动相应的专项应急预案，组织抢险救援和医疗救护。
- **信息报告**：事故发生后，严格按照“一级/二级/三级”响应规定逐级上报。一般事故30分钟内上报公司值班领导，重大伤亡或严重影响运行的事故15分钟内上报。
