# 第六章 环境保护与文明施工 记忆摘要

## 核心内容
- 总则：管理目标（5项）、三级管控体系（项目经理→专业管理人员→班组长）
- 扬尘控制：湿法作业、密目防尘网覆盖、车辆冲洗、围挡封闭隔离
- 噪声控制：时段8:00-18:00限制；电镐/切割机/空压机使用规定；低噪机具选型保养
- 固废管理：五类垃圾分类收集表；建筑垃圾集中堆放定期外运；危废单独密封处置；《废弃物处置台账》制度
- 废水控制：简易沉淀处理后回用；生活污水接市政管网防渗漏措施
- 化学品管理：GB 30981.1-2025合规采购；库房通风+防火标识+出入库登记；施工通风排风要求
- 现场卫生：围挡参数及信息栏公示7项内容；材料堆放100mm木方基础+金属货架；工完场清；禁烟；PPE着装
- 成品保护补充：5类已完工项目保护措施表；护栏利旧安装要求；动态监控修复机制
- 机场约束：漂浮物FOD防控、无线电通信干扰禁止、消防通道协调、高空作业防坠
