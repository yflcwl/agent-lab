# 第五章 安全管理制度与措施 — 章节记忆

## 摘要
本章系统编制了双流机场东消防站维修工程的安全管理制度与措施，共五节：安全管理总则（责任制/教育培训/安全检查/封闭管理）、危险源辨识与风险评价（LECS评分法+两份管控清单全文转表）、六项专项作业安全措施（高处作业/动火作业/临时用电/动土沟槽/机械设备/个人防护）、围挡及安全隔离参数、消防设施配置标准。

## 关键参数
- LEC评分法：L(10/6/3/1/0.5~0.1)、E(10/6/3/2/1/0.5)、C(100/40/15/7/3/1)
- 探沟尺寸：长36m×宽0.8m×深1m
- 气瓶间距≥5米，距动火点≥10米
- 留守监护≥30分钟
- 围挡：高2.5m，框架75轻钢龙骨/40镀锌矩管，面板12mm彩钢板，长约36m
- 灭火器规格：3A级5KG（施工区/库房）、4A级8KG（动火点）
- 一机一闸一漏一箱，潮湿区域≤36V，特别潮湿≤12V
- 停电—验电—挂牌—上锁
