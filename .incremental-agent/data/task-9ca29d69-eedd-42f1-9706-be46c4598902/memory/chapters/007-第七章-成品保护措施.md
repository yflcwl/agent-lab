# 第七章 成品保护措施 - 章节记忆

## 摘要
本章系统阐述了施工全过程的成品保护管理制度，涵盖管理组织架构、值班巡检制度、损坏修复处置流程、交叉作业协调管理等通用条款；针对外墙翻新、天棚墙面翻新、车库环氧固化地坪、卫生间翻新四项分部工程分别制定了各阶段的成品保护措施；对挡土墙不锈钢护栏从保护性拆除到修复利旧安装的全周期防护作出详细规定；建立了自检/互检/交接检三级检查验收程序和责任追究机制。

## 事实来源
- **成品保护通用管理要求**：`sources/双流机场东消防站维修工程施工方案-背景资料.docx` offset ~8403–8410，第7～10条
  - 第7条："制定值班和巡检制度，施工现场发现有不慎损坏的部位，要及时标识并立即通知相关值班施工人员进行修补。施工完毕后，应有专人检查修补情况，并做记录。"
  - 第8条："施工完毕后，施行动态监控，应及时进行修补。"
  - 第9条："应避免、移动重型机械设备；尽可能避免交叉作业，以防其他人员破坏，注意成品保护措施。"
  - 第6条："认真执行自检、互检、交接检及工序检查等制度。以确保工程检查验收一次通过。"
- **护栏保护**：offset ~3042 "保护性拆除不锈钢护栏，做好编号、分类堆放，妥善保管，避免变形划伤，为后续利旧修复做准备。" + offset ~4469 "对前期拆除的不锈钢护栏进行除锈、补焊修复，按照原位安装，固定牢固，完成所有收尾清理，清运建筑垃圾，恢复场地整洁。" + offset ~4397 "护栏拆除做好成品保护，利旧安装保证牢固、顺直。"
- **涂装工艺要求**：offset ~4397 "外墙抹灰必须分层施工，避免空鼓开裂；涂装工序必须待前一道工序完全干燥后方可进行。"
- **地坪工艺要求**：offset ~4397 "钢筋间距、保护层严格按方案执行，混凝土振捣密实，地坪做好坡度防止积水。"
