# 第四章 各分项工程施工工艺 - 章节记忆

## 摘要
本章详细描写五项分部工程的施工工艺：外墙翻新（1789㎡）、天棚墙面翻新（4902㎡乳胶漆+500㎡抹灰）、车库环氧/固化地坪翻新（758㎡）、二楼卫生间翻新（135㎡）、挡土墙配套工程。其中挡土墙部分有完整工艺流程和构造参数，其余四项仅见工程量清单，工艺描述基于国标规范和行业通用工法补充撰写。

## 事实来源
- BOQ工程量数据：`sources/双流机场东消防站维修工程施工方案-背景资料.docx` offset 90–425
- 挡土墙施工方法：同文件 offset 1408–4400（"三、施工方法"全文）
- 外墙/天棚/环氧/卫生间工艺无原文覆盖，标注说明并参考GB50210、GB50209、GB50327等规范通用工法编写

## 关键参数（挡土墙）
| 参数 | 数值 |
|------|------|
| 作业时段 | 8:00–18:00 |
| 围挡 | 2.5m高轻钢龙骨彩钢板，~36m长 |
| 探沟 | 36m×0.8m×1m（长×宽×深），人工开挖 |
| 基础砖 | 370厚Mu15页岩砖，M10砂浆，高0.9m |
| 垫层 | 100mm厚C20，宽570mm |
| 墙身 | 240厚Mu15页岩砖，M10砂浆，高1.2m |
| 压顶 | C20钢筋混凝土240×200mm，4Φ12主筋+Φ8箍筋@200 |
| 内部地坪 | 100mm厚C20细石混凝土，Φ8@150单层双向，2%坡度 |
| 地圈梁 | C20混凝土，主筋4Φ12，箍筋Φ8@200 |
| 沟盖板 | C30预制100×500×1000mm，Φ12@150单层双向 |
| 饰面装饰 | 15mm厚1:3水泥砂浆两遍→界面剂→腻子2遍→底漆1遍面漆2遍→黄黑警示油漆 |
| 砂浆饱满度 | ≥80% |

## 术语统一
- "Mu15页岩砖"（非MU15或mu15）
- "M10水泥砂浆" / "C20混凝土" / "C30预制混凝土"
- "Φ12@150"（直径符号保持原文格式）

## 跨章约束
- 外墙真石漆工艺与原第一章工程量1789㎡对应
- 天棚乳胶漆4902㎡与第二章部署相呼应
- 车库固化地坪758㎡需注意清单第4项实际为"混凝土地面固化地坪"而非传统环氧面层
- 卫生间JS涂膜防水厚度≥1.5mm、闭水试验24h等要求与其他章节成品保护措施形成关联
- 挡土墙所有参数必须与第五章安全管理和第七章成品保护保持一致引用

## 后续衔接建议
- 第五章安全管理应重点覆盖高处作业（外墙翻新书）、动火作业（护栏修复焊接）、有限空间（沟槽作业）等风险点
- 第七章成品保护需细化卫生间防水层保护和墙面真石漆防污染措施
