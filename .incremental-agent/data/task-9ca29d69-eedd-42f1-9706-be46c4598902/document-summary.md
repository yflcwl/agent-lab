# 全局资料概览

## 一、参考文档写法分析

### 文档：`reference/reference-document.md`

| 维度 | 特征描述 |
|------|----------|
| **文档类型** | 不停航施工安全协调方案（大型机场飞行区施工组织管理文件） |
| **结构组织** | 采用"二十章大纲目录+正文详情"双层结构。第一章为完整章节框架，后续各节按编号逐一展开详细技术与管理要求 |
| **标题层级** | 阿拉伯数字序号体系："四、影响航空器起降…" → "4.1 …" → "（1）…", 与常规施工方案编号风格一致 |
| **语气风格** | 工程规范型书面语，以"**应/必须/严禁/不得**"等规范性措辞为主；客观陈述技术参数与管理流程，无主观色彩 |
| **篇幅特征** | 长篇文档（数千行），每章含大量并列小项和具体数值约束 |
| **表达方式** | ① 大量使用参数化描述；② 附注引用（详见附件X）；③ 表格化呈现风险矩阵；④ 引用法规编号作为依据 |
| **可借鉴要点** | 总体章节大纲→分项详细说明→关键参数列表→附表/附件引用的模式；语言保持简洁、精准、可执行 |
