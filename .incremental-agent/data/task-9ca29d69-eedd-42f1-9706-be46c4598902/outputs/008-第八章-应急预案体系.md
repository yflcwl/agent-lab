# 第八章 应急预案体系

## 一、总则

### （一）编制目的

为了有效预防和应对双流机场东消防站维修工程施工过程中可能发生的安全事故，保障施工人员的生命安全和身体健康，减少财产损失，提高应急处置能力，特制定本施工安全应急预案。

### （二）适用范围

本预案适用于双流机场东消防站维修工程各项施工过程中可能发生的各类安全事故的应急处置，具体覆盖以下施工作业环节：

| 作业类别 | 涉及工序 | 主要风险类型 |
|---------|---------|-------------|
| 墙面涂料作业 | 外墙真石漆涂刷、天棚乳胶漆涂刷、防爆膜贴覆 | 高处坠落、物体打击、火灾、中毒 |
| 屋面防水作业 | 保温层拆除、JS防水涂料施工 | 高处坠落、机械伤害、火灾 |
| 地面硬化作业 | 杆塔周围6m×6m范围地坪浇筑 | 机械伤害、物体打击、坍塌（挡土墙区域） |
| 护栏拆装作业 | 不锈钢栏杆保护性拆除与利旧安装 | 高处坠落、物体打击、机械伤害 |
| 挡土墙修复作业 | 塌陷挡土墙拆除重建 | 坍塌、高处坠落、机械伤害 |
| 沟盖板更换作业 | 损坏沟盖板拆除与新盖板吊装 | 物体打击、机械伤害 |
| 电气改造作业 | 给排水暗管DN25敷设相关临电使用 | 触电、机械伤害 |

### （三）应急处置原则

| 序号 | 原则 | 具体要求 |
|------|------|---------|
| 1 | 以人为本，安全第一 | 始终将保障人员的生命安全和身体健康放在首位，最大限度地减少事故造成的人员伤亡和财产损失 |
| 2 | 预防为主，常备不懈 | 加强对施工过程的安全管理，做好事故预防工作，建立健全应急救援体系，定期组织演练，做到有备无患 |
| 3 | 快速反应，协同应对 | 一旦发生安全事故，应迅速启动应急预案，各部门、各单位要密切配合，协同作战，迅速有效地开展应急救援工作 |
| 4 | 科学施救，依法处置 | 采用科学有效的救援方法和技术手段，按照法律法规和相关规定进行应急处置，确保应急救援工作的合法性和有效性 |

## 二、危险因素分析

根据施工内容和作业特点，本工程存在以下六类主要安全风险：

| 序号 | 风险类型 | 风险描述 | 主要发生时段 | 关联工序 |
|------|---------|---------|-------------|---------|
| 1 | 高处坠落事故 | 作业人员在高处作业时因防护措施不到位、操作失误等原因坠落 | 脚手架搭拆、外墙施工、屋面防水、护栏拆装 | 外墙翻新、挡土墙配套 |
| 2 | 物体打击事故 | 建筑物上的构配件、工具等物品掉落击中下方人员 | 交叉作业、高空拆除、沟盖板更换 | 全部翻新分部 |
| 3 | 机械伤害事故 | 机械设备因操作不当、设备故障造成人员伤害 | 混凝土切割、砌体施工、机具使用 | 挡土墙配套、地坪施工 |
| 4 | 触电事故 | 施工现场临时用电漏电、短路导致人员触电伤亡 | 全天候（尤其雨天） | 临时用电系统运行期间 |
| 5 | 火灾事故 | 保温材料、溶剂型涂料、油漆等易燃物引发起火 | 保温层拆除、真石漆/乳胶漆施工 | 外墙翻新、天棚翻新 |
| 6 | 中毒窒息事故 | 密闭空间内有机溶剂挥发或通风不良导致中毒 | 地下室、封闭房间、狭小空间作业 | 天棚防爆膜贴覆、卫生间施工 |

**说明：** 原文危险因素分析中未单独列出"坍塌事故"专项条目，但结合第一章所述"塌陷挡土墙修复"施工内容及第五章危险源辨识，挡土墙基坑开挖阶段存在局部坍塌风险，现场应提前排查并采取支护措施。

## 四、预防与预警

### （一）预防措施

| 序号 | 措施内容 | 责任单位 / 责任人 |
|------|---------|------------------|
| 1 | 建立健全安全生产管理制度，落实安全生产责任制，加强对施工作业过程的安全管理 | 项目经理 / 安全负责人 |
| 2 | 编制施工方案并组织技术人员讨论审核，确保方案的科学性和可行性 | 技术负责人 |
| 3 | 对作业人员进行安全教育培训，提高作业人员的安全意识和操作技能 | 安全负责人 / 班组长 |
| 4 | 加强对施工现场的安全检查，及时发现和消除安全隐患 | 安全负责人 / 施工员 |

### （二）预警行动

1. 建立健全事故预警机制，明确预警信息的发布程序和方式。
2. 当发现可能导致安全事故的危险因素时，应立即发布预警信息，通知相关部门和人员采取防范措施。
3. 预警信息发布后，应密切关注事态发展，及时调整预警级别或解除预警。

## 五、应急响应

### （一）事故报告与响应分级

本工程实行三级响应制度，具体如下：

| 响应级别 | 适用情形 | 报告时限 | 处置主体 | 报送流程 |
|---------|---------|---------|---------|---------|
| **一级响应** | 可能导致一般安全及以上事故；已造成人员死亡或严重伤害；严重影响机场运行的不安全事件；各类社会安全事件和公共卫生事件 | 事发项目管理人员 **15分钟** 内报送公司值班领导 | 公司应急指挥领导小组统一指挥 | 项目 → 公司值班领导 → 机场集团 → 行政综合部（**15分钟**内） → 公司应急指挥领导小组 |
| **二级响应** | 可能导致运行不安全事件或已造成人员轻伤的轻微事故 | 事发项目管理人员 **30分钟** 内报送公司值班领导 | 事业部/项目部应急组织机构负责处置 | 项目 → 公司值班领导 → 行政综合部（**30分钟**内） |
| **三级响应** | 后果较轻的其他情况 | 项目负责人现场即时处置 | 项目负责人 | 项目负责人自行处置，视需要上报 |

> 公司值班领导收到消息后，应立即着手调查了解事件情况，持续跟踪事件发展动态。

**报告内容包括：**

| 报告要素 | 说明 |
|---------|------|
| 事故发生时间 | 精确到分钟 |
| 事故发生地点 | 具体施工区域 |
| 工程项目名称 | 双流机场东消防站维修工程 |
| 施工单位名称 | 成都空港建设开发服务有限公司 |
| 事故简要经过 | 事故发生的起因、过程和当前状态 |
| 伤亡人数 | 受伤/死亡人员数量及伤情 |
| 直接经济损失初步估计 | 按可判断的范围估算 |
| 事故原因初步判断 | 基于现场情况的初步分析 |
| 已采取措施及控制情况 | 已实施的应急处置措施 |

### （二）响应程序

```
接到事故报告 → 启动应急预案 → 赶赴事故现场 → 了解情况制定方案 
→ 组织实施救援措施 → 向上级报告进展 → 根据实际情况调整方案
```

各步骤具体要求：

1. **启动预案：** 应急救援领导小组接到事故报告后，应立即启动应急预案，组织各应急救援工作小组赶赴事故现场。
2. **现场处置：** 应急救援工作小组到达事故现场后，应迅速了解事故情况，制定应急救援方案，组织实施应急救援措施。
3. **信息报告：** 在应急救援过程中，应及时向上级主管部门报告事故救援进展情况，根据事故发展态势，适时调整应急救援方案。

## 六、后期处置

### （一）善后处理

1. 做好伤亡人员的善后处理工作，安抚伤亡人员家属，按照有关规定给予赔偿。
2. 对事故现场进行清理和恢复，消除事故影响，恢复正常施工秩序。

### （二）事故调查

1. 成立事故调查组，对事故进行调查和分析，查明事故原因，认定事故责任。
2. 总结事故教训，提出改进措施和建议，防止类似事故的再次发生。

### （三）应急评估

1. 对应急预案的科学性、有效性和可操作性进行评估，总结应急救援工作的经验和教训。
2. 根据评估结果，对应急预案进行修订和完善，不断提高应急救援能力。

## 七、保障措施

### （一）通信与信息保障

建立健全应急救援通信联络体系，明确各部门和人员的通信联络方式，确保应急救援信息的及时传递和沟通。

### （二）应急队伍保障

加强应急救援队伍建设，定期组织培训和演练，提高应急救援队伍的应急处置能力和协同作战能力。
