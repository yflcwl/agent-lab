### 2.1.2 进度计划编制说明

本工程施工进度计划的编制依据以下因素综合考虑：

1. **工程量规模**：四大翻新分部工程合计涉及拆除面积约 7,047㎡（外墙翻新 1,789㎡ + 天棚墙面翻新 4,902㎡），新增抹灰涂装面积相近，另含车库环氧地面铲除及固化 758㎡、二楼卫生间全面翻新 36㎡，以及杆塔挡土墙配套工程等；
2. **作业时段约束**：施工作业每日 8:00–18:00，有效作业时长 10 小时，且需兼顾机场周边环境的运行要求，部分高噪声工序宜避开邻近区域敏感时段；
3. **工序逻辑关系**：各翻新分部工程内部存在先后衔接工序（如先拆除后修补涂装、先防水后饰面），各分部之间可根据现场条件灵活穿插，合理组织流水作业以提高整体效率。

> **待补充事项：** 实际施工前，应由项目技术负责人结合业主单位提供的具体工期要求，细化编制横道图进度计划，明确各分部工程的起止时间节点、关键线路及各专业队伍的进场/退场时间安排。

## 2.2 施工总体部署

### 2.2.1 总体部署原则

针对本项目四项翻新施工并存的实际情况，遵循以下部署原则：

- **"先室外后室内"**：优先开展外墙翻新的拆除与防护类作业，减少对后续室内涂装工序的干扰；
- **"先地下后地上、先结构后装饰"**：凡涉及混凝土楼地面开挖回填的区域，先行完成基槽开挖、管线排查与结构恢复，再进行面层饰面施工；
- **"分区推进、流水穿插"**：将施工现场按功能区域划分为若干施工段，在各段内组织平行流水作业，尽量缩短各区域的空闲等待时间；
- **"安全封闭、最小影响"**：施工范围采用全封闭打围隔离，确保不影响消防站正常运行及周边人员安全。

### 2.2.2 分项施工顺序

#### （一）外墙翻新工程

| 阶段 | 主要工序 | 说明 |
|------|----------|------|
| ① 拆除清理 | 外立面保温层及涂料拆除 → 入户处龙骨饰面拆除 → 墙体及排水管道拆除 | 由上至下分层拆除，废料分类装袋清运 |
| ② 基层处理 | 墙面一般抹灰 → 墙面涂膜防水 | 新做抹灰层应分层施工并养护至规定干燥度 |
| ③ 饰面恢复 | 抹灰面真石漆及腻子 → 金属门油漆翻新 | 饰面施工应待基层含水率达标后进行 |
| ④ 幕墙维修 | 铝塑板带钢骨架幕墙修复 → 塑钢窗打胶维修 → 挑檐屋面防水修复 | 高空作业须搭设脚手架并采取防坠措施 |
| ⑤ 设备移机 | 空调外机移机利旧安装 → 支架更换 → 加氟 | 配合各专业工种同步进行 |

#### （二）天棚及墙面翻新工程

| 阶段 | 主要工序 | 说明 |
|------|----------|------|
| ① 铲除拆除 | 天棚及墙面涂料铲除 → 墙柱面混合砂浆面铲除 | 大面积铲除作业应自上而下逐片进行 |
| ② 基层修补 | 墙面一般抹灰找补 | 局部空鼓区域须凿除空鼓层重新抹灰 |
| ③ 饰面恢复 | 抹灰面乳胶漆及腻子 → 玻璃贴防爆膜 | 每遍腻子干燥后方可进行下一遍 |

#### （三）车库环氧地面翻新工程

| 阶段 | 主要工序 | 说明 |
|------|----------|------|
| ① 旧层拆除 | 铲除原环氧地坪 → 混凝土地面拆除 | 混凝土方量约 28m³，须分类堆放清运 |
| ② 结构恢复 | 混凝土楼地面浇筑 → 找平养护 | 浇筑完成后应按规范进行保湿养护 |
| ③ 面层施工 | 混凝土地面固化地坪处理 | 基层强度与含水率达标后方可施作固化层 |

#### （四）二楼卫生间翻新工程

| 阶段 | 主要工序 | 说明 |
|------|----------|------|
| ① 拆除清拆 | 地砖/墙砖/吊顶/防水层拆除 → 管道及洁具拆除 | 拆除过程中注意保护可利旧的蹲便器（7组） |
| ② 管线重布 | 地面防水找平 → 楼地面涂膜防水 → 管道新安 DN25 给水管（暗埋） | 防水层完成后须进行闭水试验 |
| ③ 饰面恢复 | 防滑地砖铺贴 → 内墙面砖铺贴 → 铝合金扣板吊顶安装 | 铺贴应严格按弹线定位施工 |
| ④ 设备安装 | 灯具/热水器/淋浴器利旧安装 → 蹲便器利旧/新安 | 所有管路通水试压合格后安装洁具 |

#### （五）杆塔挡土墙配套工程

挡土墙改造工程与上述四项翻新工程可交叉并行实施，其主要施工流程为：

地下管线探沟开挖 → 不锈钢护栏拆除 → 场地清表 → 旧挡墙及混凝土拆除 → 土方开挖 → C20混凝土垫层 → 砖基础及挡墙砌筑 → 内部地坪浇筑 → 预制盖板制作安装 → 外立面抹灰涂装 → 警示油漆 → 护栏利旧安装。

### 2.2.3 平行施工与穿插策略

本项目四个翻新分部工程相对独立，可在满足以下条件的前提下组织平行施工：

1. **材料与机具共享协调**：自卸汽车、登高作业车等大型非场内存放机具由项目经理统一调度；电镐、切割机等场内存放工具按施工段分配；
2. **作业人员调配**：泥工班组、涂装班组等专业队伍在各施工段间流转，形成小流水作业；
3. **交叉作业管控**：同一时段不同专业的交叉施工须由生产经理统筹排班，避免上下立体交叉带来的安全隐患；
4. **封闭管理**：全封闭打围区域内各区域可同时作业，但进出通道应保持畅通，建筑垃圾及时清运。

## 2.3 施工平面布置

### 2.3.1 围挡与封闭

- 采用 **2.5m 高轻钢龙骨彩钢板**对施工及影响区域进行全封闭打围；
- 打围长度约 **36m**，围挡四周与施工区域边界距离控制在 **1.2m** 以内；
- 围挡高度确保不影响相邻区域正常运行，围挡上设置施工信息栏（含工程名称、参建单位、安全生产天数等内容）。

### 2.3.2 仓库及材料加工区

- 材料仓库及加工房设置于公司 **集中加工库房**，尽量减少现场二次加工需求；
- 现场不设置大规模加工厂，小型构件及辅材按需领用、即领即用；
- 库房材料应堆放整齐，板材、水泥、石膏腻子等易受潮材料地面采用 **100mm 高木方**做基础，木方上铺设木工板，零星材料设置金属货架整齐码放；
- 库房内每 **15㎡** 配置 2 具 3A 级 5KG 干粉灭火器，门口张贴醒目的"严禁烟火"标志。

### 2.3.3 临时设施与运输

- 现场不设大型临时建筑物，施工人员往返依靠项目部配发的 **3 辆 7 座面包车**和 **2 辆皮卡车**；
- 货物运输使用 **1 辆自卸汽车**，非场内存放，按需进场；
- 场内水平运输以 **6 辆手推车**为主，垂直搬运视登高作业车配备情况协调；
- 施工用水用电利用既有设施接入，按第三级配电系统布设。
