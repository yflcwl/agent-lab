# 第七章 成品保护措施

## 一、成品保护管理总则

### （一）管理目标与原则

为确保各项翻新工程在完成面达到设计效果后免受后续施工或外部因素破坏，特制定本成品保护管理制度。成品保护工作贯穿工程施工全过程，坚持"预防为主、过程控制、动态巡查、及时修复"的原则，将成品保护纳入日常施工质量管控体系。

### （二）成品保护组织架构

成立以项目经理为组长、技术负责人为副组长、各专项施工员和班组长为成员的成品保护管理工作组，职责如下：

| 岗位 | 职责范围 |
|------|---------|
| **项目经理** | 全面负责成品保护管理工作，统筹人员调配和资源配置 |
| **技术负责人** | 编制成品保护专项方案，对各分项完成面的保护技术要求进行交底 |
| **各专项施工员** | 落实本施工区域内的成品保护措施，安排成品保护值班人员 |
| **班组长** | 负责本班组的成品保护日常工作，发现损坏及时上报 |
| **专职安全员** | 对施工现场的成品保护执行情况进行监督检查，制止可能破坏成品的违规行为 |

### （三）成品保护值班与巡检制度

按照施工方案要求，制定成品保护值班表和巡检制度，具体要求如下：

1. **成品保护责任人**应每日在已完成但未交付的区域内巡逻不少于两次（上午一次、下午一次），重点巡查以下内容：
   - 涂装修补面层的表面完整性（无划伤、磕碰、污渍）
   - 地面材料的平整度和完整性（无开裂、翘曲、划痕）
   - 已安装护栏及固定件的外观质量和牢固状态
   - 临时围挡及警示标识的完好性

2. **巡检记录要求**：每次巡检应有专人负责做好检查记录，记录内容包括巡检时间、巡检区域、检查结果、发现的损坏情况、处理措施等。

3. **损坏发现处置流程**：施工现场发现有不慎损坏的部位时，应及时采取以下措施：
   - **①立即标识**：用警示带、警示标志或标记笔明确标注损坏位置；
   - **②通知值班人员**：立即通知相关值班施工人员到场确认；
   - **③评估损坏程度**：由技术负责人评估损坏程度，确定是否需要修补及修补方案；
   - **④实施修补**：相关人员立即进行修补处理，修补工艺应符合原施工方案的技术要求；
   - **⑤专人检查验收**：施工完毕后，由专人对修补情况进行检查，并对修补效果进行确认签字；
   - **⑥归档记录**：将损坏和修复情况如实录入《成品保护巡查记录表》，作为工程质量档案留存。

4. **动态监控机制**：施工完毕后应持续施行动态监控，根据施工进度推进不同阶段的成品保护需求，及时调整保护策略，做到"发现一处、修复一处、消除一处隐患"。

### （四）交叉作业协调管理

为避免不同专业队伍同时施工造成互相破坏，严格执行以下交叉作业管控措施：

1. **工序优先顺序**：总体按"先拆除后新建、先隐蔽后饰面、先湿法后干法、先高处后地面"的原则排布工序，尽量减少不同专业之间的干扰。

2. **重型设备移动管理**：应避免、移动重型机械设备穿越已完成的保护区域；确需穿越的，须提前铺设硬质防护板或钢板作为隔离通道，并设置明显的通行限制标识。

3. **交叉作业通知制度**：当两个及以上专业班组需要在同一区域或相邻区域同时作业时，应由生产经理统一协调，召开现场交接会，明确各自的保护责任和防护措施，并在作业区域设立联合监护岗。

4. **隔离防护措施**：交叉作业区域应采取临时隔离带或硬质围挡进行物理分隔，防止材料搬运、工具坠落等意外造成的成品损伤。

## 二、分项工程成品保护措施

### （一）外墙翻新工程成品保护

外墙翻新涉及保温层拆除、抹灰、防水涂层、真石漆喷涂、铝塑板幕墙安装等多个工序交叉进行，各阶段成品保护措施如下：

1. **保温层拆除完成后的保护**：
   - 拆除完成后应及时清理基层表面的松散砂浆和粉尘，防止污染待施工面；
   - 裸露的保温层基底应采用防尘网进行覆盖防护，防止大风天气下灰尘附着；
   - 恶劣天气（如大雨、强风四级以上）来临前，应对已清理的基层进行临时遮蔽保护。

2. **防水涂层施工完成后的保护**：
   - 防水涂层涂刷完成后应保持通风晾干，在未固化前严禁踩踏、碰撞或其他外力扰动；
   - 必要时可拉设警戒线或在作业面周边设置临时围挡，防止非作业人员误入；
   - 如需进行下一道工序，应等待防水层完全干燥并经检查合格后，方可进入后续施工环节。

3. **真石漆喷涂完成后的保护**：
   - **涂装工序必须待前一道工序完全干燥后方可进行**——这是外墙施工作业质量控制的核心要点，具体为：界面剂干燥后方可批刮腻子，底漆干燥后方可喷真石漆，每遍之间应间隔足够的干燥时间；
   - 真石漆喷涂完成后48小时内不得淋雨、冲洗或直接接触水汽，如遇降雨应及时采用塑料薄膜进行临时覆盖；
   - 在真石漆面层未达到最终硬度之前，禁止悬挂重物或在其上钻孔、钉钉；
   - 施工过程中产生的飞溅污点应使用专用清洁剂及时清除，防止固化后难以处理。

4. **铝塑板幕墙安装完成后的保护**：
   - 面板安装完成后应在表面粘贴保护膜，直至竣工验收前不得撕除；
   - 安装过程中使用的脚手架应定期清理，防止金属构件、紧固件掉落砸伤面板；
   - 清洁时应使用中性清洁剂和软质布料，严禁使用腐蚀性溶剂。

5. **栏杆/护栏保护**：护栏拆除做好成品保护，利旧安装保证牢固、顺直，详见本章第三节。

### （二）天棚及墙面翻新工程成品保护

天棚墙面翻新工程工程量达约4902㎡（乳胶漆）+约46.5㎡（防爆膜），完成面积大且作业高度高，成品保护措施要点如下：

1. **旧涂层铲除完成后的保护**：
   - 铲除后的基层墙面应尽快进入下一道抹灰工序，避免长时间暴露在空气中导致返潮或污染；
   - 新抹灰面应在施工过程中保持表面湿润养护，防止因干燥过快产生收缩裂缝。

2. **乳胶漆涂刷完成后的保护**：
   - 乳胶漆涂刷完成后应封闭施工区域，防止非施工人员进入或在墙面留下手印、污渍；
   - 涂刷过程中应注意邻接部位的成品保护，可采用美纹纸胶带沿门窗框、开关插座边缘做分色遮挡；
   - 每遍涂刷间隔时间内保持室内通风良好但避免强风直吹，以防止涂膜开裂；
   - 涂刷完成后24小时内严禁擦拭、碰撞或粘贴任何物品于已涂层面。

3. **防爆膜贴覆完成后的保护**：
   - 防爆膜贴覆完成后应设置醒目的"请勿触碰"标识，防止人员在未察觉的情况下意外揭破或划伤；
   - 贴膜完成面不得承受尖锐物体的碰撞或切割，必要时可增设临时防护栏进行物理隔离；
   - 清洁时使用微湿棉布轻轻擦拭，禁用含有研磨成分或强酸碱性质的清洁溶剂。

### （三）车库环氧固化地坪工程成品保护

车库环氧固化地坪面积约758㎡，施工区域相对封闭但后续其他工序物料运输可能造成污染，保护措施如下：

1. **混凝土修补完成后的保护**：
   - 修补后的混凝土养护期间不得承重或受振动影响，养护期不少于24小时；
   - 养护完成后方能进入后续的固化剂施工环节。

2. **固化地坪施工过程中的保护**：
   - 钢筋间距、保护层严格按方案执行，混凝土振捣密实，地坪做好坡度防止积水——这是地坪施工质量控制的根本保障；
   - 固化剂施工过程中应保持施工区域整洁，防止杂物混入固化液中影响地坪强度；
   - 施工人员应穿平底软底鞋进入作业面，不得使用硬底皮鞋或高跟鞋。

3. **固化地坪施工完成后的保护**：
   - 固化处理后24小时内禁止车辆通行和行人踩踏；
   - 48小时后方可放行轻型车辆，72小时后正式投入使用；
   - 在交付使用前应对地坪表面进行全面检查，如发现局部瑕疵应及时修补并重新固化处理。

4. **成品存放注意事项**：施工完毕的固化地坪面上，应避免堆放尖锐建材或重物集中压置，防止出现不可恢复的表面凹陷。

### （四）卫生间翻新工程成品保护

卫生间翻新工程涉及给排水暗管、JS防水、墙地砖铺贴、吊顶等多道工序交叉作业，且空间相对狭小，成品保护措施如下：

1. **给排水暗管安装完成后的保护**：
   - DN25给排水暗管安装完毕后应立即进行压力试验检验密封性，合格后方可回填覆槽；
   - 回填覆槽时应用细沙填充至管顶以上50mm厚度后再覆盖砖块或混凝土，防止管道受挤压变形；
   - 管道接口处应设置明显标记标识，防止后续打孔作业误伤管线。

2. **JS防水层施工完成后的保护**：
   - JS防水材料涂刷完成后应充分固化干燥（一般不少于24小时），方可进行闭水试验；
   - 闭水试验期间（蓄水时间不低于4小时）不得排空或向池内注入其他液体；
   - 防水层固化后经检查确认无渗漏，方可进行墙地砖铺贴作业，此阶段严禁在水准测定的防水面上堆载或走动。

3. **墙地砖铺贴完成后的保护**：
   - 瓷砖铺贴完成后至少12小时内不得上人踩踏；
   - 缝勾完成后应将多余填料彻底清理干净，防止硬化后难以去除；
   - 铺贴面应铺设防潮垫或薄木板作为过渡保护层，直至全部收尾工程完工。

4. **吊顶及洁具安装完成后的保护**：
   - 吊顶龙骨安装完毕后应在上方暂留检修通道标记，防止后续施工人员盲目操作造成破坏；
   - 洁具安装完成后应对陶瓷体表面粘贴塑料保护膜，直至竣工验收前不得撕除；
   - 洁具连接的水管和电路接口应张贴"使用中禁动"警示标识，防止调试结束后被误拧或误拆。

## 三、挡土墙护栏利旧保护措施

挡土墙配套工程中不锈钢护栏的保护利用是本项目成品保护的典型环节，其全周期保护措施如下：

### （一）保护性拆除阶段

1. **拆除前准备**：
   - 拆除作业前先对现有护栏进行全面拍照建档，记录原始外观状态和安装位置；
   - 制作不锈钢护栏编号清单，建立"编号—位置"—对应台账。

2. **拆除操作要求**：
   - 严格按照保护性拆除标准执行，做好编号、分类堆放，妥善保管，避免变形划伤，为后续利旧修复做准备；
   - 拆除时应使用橡胶锤或木槌辅助敲击，严禁使用铁锤直接击打护栏管体；
   - 所有焊缝连接部位采用热切割时必须严格控制切割温度，防止母材过热导致强度衰减；
   - 对于螺栓固定的护栏，拆卸时应对螺栓、螺母及配件进行分类收纳并统一登记造册。

3. **堆放与转运**：
   - 拆除后的护栏分段存放在指定的平整场地上，下面垫放不小于50mm厚的木方或橡胶垫，防止管体直接接触硬质地表造成磕碰变形；
   - 长段护栏应水平平放堆放，层高不超过三层，并采取绳索捆绑防倾倒措施；
   - 转运过程中运输车辆应铺垫草垫或麻袋作为缓冲层，装卸时采用吊装方式不得拖拽摩擦。

### （二）存储保管阶段

1. 存放场地应远离施工主干道和机械作业区，选择地势平坦、排水通畅的封闭或半封闭区域；
2. 存放场地周边应设置防撞护栏和安全警示标识，防止过往车辆或人员撞击护栏材料；
3. 存放期间每周进行一次巡查，发现锈蚀加剧或变形等情况应及时进行干预处理。

### （三）修复与原位安装阶段

1. **修复工艺**：对前期拆除的不锈钢护栏进行除锈、补焊修复，确保修复后外观与原状基本一致，结构强度不低于原有水平；
2. **安装要求**：按照原位安装，固定牢固，保证牢固、顺直，完成所有收尾清理，清运建筑垃圾，恢复场地整洁；
3. **验收标准**：护栏安装完成后，应对其牢固度（手推无晃动）、垂直度（≤3mm/m偏差）、表面装饰质量（无明显焊痕、色差）进行逐项检查验收。

## 四、成品保护检查验收与责任追溯

### （一）成品保护检查验收程序

按照施工方案的要求作业，严格执行自检、互检、交接检及工序检查等制度，以确保工程检查验收一次通过。成品保护检查验收按以下程序执行：

1. **自检**：各班组在完成本班组施工任务后，应首先对本班组的成品保护状况进行自检，填写《班组自检记录表》；

2. **互检**：相邻班组之间进行交叉互检，重点检查上一工序对本工序施工范围的成品保护影响情况；

3. **交接检**：每个分部工程完成后，由技术负责人组织相关施工员进行交接检查，填写《工序交接检查记录》，确认成品保护状态后移交下一阶段施工单位；

4. **专项检查**：安全负责人每周组织一次全场范围内的成品保护专项检查，形成检查通报并跟踪整改闭环。

### （二）成品保护资料管理

1. 《成品保护巡查记录表》由值班人员每日填写，随工程进度同步整理归档；
2. 各分项工程的成品保护照片（含损坏前、处理中和修复后的对比照）应分类保存，作为工程竣工资料的组成部分；
3. 护栏利旧的编号清册、拆除/修复/安装全流程记录和影像资料应单独装订成册。

### （三）责任追究机制

1. 发现成品损坏后未按规定及时上报或拖延处理的，对责任人处以警告并要求承担相应修复费用；
2. 故意破坏已完工成品或拒不配合成品保护管理的作业人员，由项目经理部视情节轻重给予停工整顿或清退出场处理；
3. 由于交叉作业协调不力导致的重大成品损坏事故，追究相关协调管理人员的连带责任。
