### 1.1.2 工程建设性质及范围

本项目属于维修类工程，主要包括以下四项翻新施工内容：

1. **外墙翻新工程**：建筑外立面保温层拆除、抹灰涂料翻新、涂膜防水处理、真石漆饰面恢复、铝塑板幕墙维修、塑钢窗打胶、挑檐屋面防水修复及空调外机移机利旧安装；
2. **天棚及墙面翻新工程**：室内天棚及墙面原有涂料铲除、墙面抹灰修补、乳胶漆翻新饰面、玻璃贴防爆膜；
3. **车库环氧地面翻新工程**：铲除原环氧地坪、混凝土地面局部拆除及回填、新做混凝土楼地面及固化地坪；
4. **二楼战斗员宿舍卫生间翻新工程**：原有地砖墙砖及吊顶拆除、管道更换安装、蹲便器利旧安装与新安、JS防水涂料及内墙面砖饰面恢复、铝合金扣板吊顶拆安。

### 1.1.3 施工场地布置

该项目拟采用2.5m轻钢龙骨彩钢板对施工及影响区域进行全封闭打围，打围长度约36m。围挡四周与施工区域边界的距离控制在1.2米以内，围挡高度不影响旁边区域正常运行。施工作业时段为每日8:00至18:00。

材料仓库及加工房设置于集中加工库房，尽量减少现场加工。库房材料应堆放整齐，板材、水泥、石膏腻子等易受潮材料堆放时地面采用100mm高木方做基础，木方上铺设木工板。
