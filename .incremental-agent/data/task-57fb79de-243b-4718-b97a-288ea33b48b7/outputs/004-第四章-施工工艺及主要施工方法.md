# 第四章 施工工艺及主要施工方法

## 一、总则

本章阐述本项目五大分部工程的施工工艺、构造层次、材料规格及质量控制要点。施工全过程严格执行每日 08:00—18:00 作业时段限定，所有分项工程须在围挡封闭区域内分段组织实施，严禁超时段扰民。各道工序须遵循\"先地下后地上、先隐蔽后饰面、先顶后墙\"的施工顺序原则，上道工序验收合格后方可转入下道工序。

---

## 二、杆塔挡土墙修复工程

### （一）施工流程概览

不锈钢护栏保护性拆除 → 人工清表 → 塌陷墙体拆除 → 探沟开挖（人工）→ C20混凝土垫层浇筑 → M10水泥砂浆砌体砌筑 → 地圈梁钢筋制安及模板支设 → C20钢筋混凝土圈梁浇筑 → 养护 → C20细石砼内部地坪浇筑 → C30预制沟盖板制安 → 外立面抹灰 → 饰面涂层施工 → 不锈钢护栏恢复安装。

### （二）基槽开挖与垫层

1. **基础探沟**：机械进场前，沿挡土墙轴线位置人工永临结合开挖探沟（36m×0.8m×1m），探明地下管线走向；确认无管线障碍后方可进入下一步土方作业。遇异常地质情况立即停工并上报技术负责人。

2. **土方开挖**：采用人工开挖方式，严禁机械直挖。基槽边坡以 1:0.33 放坡处理，坑底预留 100mm 人工清底层防止扰动原状土。

3. **垫层浇筑**：基槽验收合格后浇筑 100mm 厚 C20 混凝土垫层，振捣密实，表面拉毛处理，待凝 24h 后方可进入砌筑工序。

### （三）砌体砌筑

1. **基础砌筑**：采用 M10 水泥砂浆砌筑 370mm 厚 Mu15 页岩砖基础，基础砖高度 0.9m；水平灰缝厚度宜为 10mm，不应小于 8mm，亦不应大于 12mm。砂浆饱满度控制 ≥80%，上下错缝搭砌，错缝长度 ≥60mm。

2. **墙身砌筑**：基础验收合格后进行墙身砌筑，墙身采用 240mm 厚 Mu15 页岩砖、M10 水泥砂浆砌筑，墙高 1.2m；墙体垂直度偏差控制在规范允许范围内，每皮砖水平度偏差 ≤5mm。

3. **构造措施**：砌筑至圈梁底部标高时留置马牙槎，槎口深度 60mm，每 500mm 设置两道 2Φ6 拉结筋伸入墙内，全长锚固。

4. **质量控制指标**：
   - 砂浆饱满度：水平灰缝 ≥80%，砖柱竖向灰缝 ≥90%（GB50203-2011）。
   - 砌体轴线位移偏差 ≤10mm，高程偏差 ±15mm。
   - 相邻块材高差 ≤3mm，平整度偏差 ≤8mm/2m。

### （四）地圈梁及压顶

1. **钢筋工程**：绑扎地圈梁主筋 4Φ12，箍筋 Φ8@200；保护层厚度 ≥25mm，箍筋加密区间距 @100（两端各 500mm）。

2. **模板工程**：采用 15mm 厚覆膜木模板拼装，模板支撑间距 ≤400mm，加固采用 Φ14 对拉螺栓 @600 布置。

3. **混凝土浇筑**：截面尺寸 240mm×200mm，采用 C20 商品混凝土浇筑；插入式振动棒分层振捣，每层厚度 ≤500mm，插点间距 ≤400mm，振捣时间 15—30s/点，至气泡不再溢出、砂浆泛浆为准。浇筑完成后覆盖塑料薄膜保湿养护，养护期 ≥7d。

4. **屋面压顶**：顶部压顶同地圈梁，截面尺寸 240mm×200mm，配筋 4Φ12+Φ8@200，外倾 10% 排水坡度防雨水倒灌。

### （五）内部地坪及排水沟

1. **地坪基层处理**：夯实原状地基，铺设 50mm 厚砂石垫层，夯实系数 ≥0.93。

2. **C20细石砼地坪**：浇筑 100mm 厚 C20 细石混凝土，内配 φ8@150 单层双向钢筋网片；面层抹光压实后设置 2% 排水坡度坡向排水沟方向。养护期 ≥7d。

3. **排水沟及盖板**：排水沟断面按设计要求砌筑，安装 C30 预制混凝土沟盖板（规格 100×500×1000mm），配置 φ12@150 单层双向钢筋；盖板安装平整稳固，接缝严丝合缝。

### （六）外立面装饰工程

1. **抹灰层**：墙面清理湿润后满刷界面剂 1 道，再采用 15mm 厚 1:3 水泥砂浆分两遍成活；首遍打底找平，次遍罩面抹平压实，总厚度误差 ≤4mm。

2. **饰面涂层**：批刮 2 遍外墙耐水腻子，打磨平整后涂刷外墙底漆 1 遍 + 外墙面漆 2 遍；饰面颜色及质感符合设计图纸要求。挡土墙外侧涂装黄黑相间警示油漆以起到安全警示作用。

3. **栏杆恢复**：原有不锈钢护栏采取保护性拆除措施，编号归档以便回装；挡土墙完工后按原位恢复，焊缝满焊且打磨抛光处理，防腐层完整无损。

## 三、外墙翻新工程

### （一）拆除工程

1. **保温层拆除**：采用电动工具分段清除外墙柱面原有保温层（工程量 1361㎡），拆除过程中注意避免损坏结构基层；大块保温材料袋装清运出场。

2. **抹灰及涂料层拆除**：采用电镐铲除外立面抹灰及涂料层（工程量 1789㎡），铲除深度至坚实基层；局部粘结层残留（106㎡）采用角磨机配合切割片磨除。

3. **龙骨及饰面拆除**：入户处原有墙柱面龙骨及铝塑板饰面（88㎡）整体割除；墙上字体标识（52 个）采取切割分离方式拆除，严禁暴力敲击导致基层损伤。

4. **排水管拆除**：墙上原有排水管道（182m）分段切割拆卸，管口临时封堵防止建渣落入。

5. **空调设备**：23 台空调外机由专业人员停机、抽氟、拆卸后集中妥善保管，待翻新完工后利旧回装。

### （二）墙面一般抹灰

1. **基层处理**：铲除后的墙面彻底清扫浮灰、油污，提前一天洒水湿润；不同材料交接处（如砖墙与混凝土墙）铺钉钢丝网，搭接宽度 ≥150mm 以防开裂。

2. **砂浆配制**：采用 25mm 厚干混砂浆，拌合均匀后使用；砂浆应随拌随用，初凝前用完，严禁隔夜使用。

3. **增强抗裂层**：抹灰基层上增设外墙抗裂砂浆薄抹面层（4mm 厚），内压入标准网格布，网格布搭接宽度 ≥100mm，严禁空鼓皱折。

4. **养护要求**：抹灰层终凝后喷水养护，养护期 ≥7d；养护期间环境温度 ≥5℃，低于 5℃ 时按冬季施工方案执行。

### （三）涂膜防水层

1. **防水材料**：采用 Ⅱ型 JS 防水涂料，厚度 1.5mm；材料进场须查验合格证、出厂检测报告及有害物质限量检测证明（应符合 GB30981.1-2025 标准），不合格产品严禁投入使用。

2. **施工工艺**：基层清理干净并干燥后涂刷第一遍涂料，表干后交叉垂直方向涂刷第二遍涂料，十字交叉法确保无漏刷、无堆积。阴阳角部位增设 200mm 宽附加层加强处理。

3. **节点处理**：门窗洞口周边、穿墙管根部、女儿墙转角等薄弱部位附加层宽度 ≥250mm；收头部位用密封膏嵌实封口。

4. **闭水试验**：防水层施工完毕且干燥后进行蓄水检查，蓄水深度最浅处 ≥20mm，持续观察 24h 无渗漏方为合格。

### （四）饰面层施工

1. **饰面体系**：外墙大面积区域采用真石漆饰面，工艺流程为水性封闭底漆一道 → 外墙真石漆喷涂 → 罩面保护漆一道。

2. **腻子批刮**：成品腻子膏（耐水型）批刮两道，每道间隔时间 ≥4h（视气候条件调整）；腻子层干燥后用砂纸打磨平整，表面无明显砂痕、起伏。

3. **真石漆喷涂**：喷涂前先行做样板墙，确定喷涂纹路、颜色和用量；正式喷涂时压力控制 0.6—0.8MPa，喷枪口径 6—8mm，走枪速度均匀一致，一次成活的喷涂厚度满足设计要求。

4. **罩面漆**：真石漆完全干燥后涂刷罩面保护漆一道，形成致密保护膜，提高耐候性和抗污性能；罩面漆涂刷均匀，无色差、流挂现象。

### （五）挑檐屋面防水

1. **拆除处理**：挑檐屋面找平层拆除（工程量 100㎡），清理基层至坚实平整无松动。

2. **防水施工**：采用 2.0mm 厚三涂一布聚合物丙烯酸聚氨酯防水涂料加强处理；涂刷过程严格执行\"一涂一布\"顺序，第一遍涂料表干后立即铺设增强聚酯无纺布（搭接宽度 ≥100mm），无纺布铺设平整无褶皱，随即涂刷第二遍涂料浸透无纺布；第三遍涂料表干后复涂第四遍涂料封层面，最终涂层总厚度 ≥2.0mm。

3. **淋水检验**：防水层完工后在雨季或人工淋水条件下检验 2h，确保无渗漏。

## 四、车库环氧地面翻新工程

### （一）拆除工程

1. **原环氧地坪铲除**：采用研磨机械配合铲削方式清除原环氧地坪面层（工程量 758㎡），碎屑集中袋装清运出场，严禁扬尘扩散至非施工区域。

2. **破损混凝土破除**：对存在结构性病害的地段采用破碎工具凿除原混凝土地面层（28m³）；凿除深度至坚实混凝土基层为止，露出骨料但不破坏结构主体。

3. **基层修整**：凿除后将基层表面彻底清扫，高压气枪吹净粉尘，裂缝及缺陷部位采用高强修补砂浆填实找平。

### （二）混凝土修补层

1. **支模浇筑**：破损修补区域（112㎡）四周支设 15mm 厚覆膜木模板，模板内侧涂刷脱模剂；局部修补厚度按照现场实测值控制，平均约 250mm 厚（按清单构件特征确认）。

2. **混凝土标号**：采用 C30 商品混凝土浇筑，坍落度控制在 140±20mm；振捣采用插入式振动棒，分层厚度 ≤500mm，振捣密实后刮杠刮平、铁抹子抹光。

3. **养护要求**：浇筑完毕覆盖塑料薄膜保湿养护，养护期 ≥14d；养护期内禁止任何人员踩踏或堆放材料。

### （三）固化地坪施工

1. **基面打磨**：对整体车库地坪（758㎡）采用地坪研磨机进行粗磨处理，去除浮浆层及松散物质，直至混凝土毛细孔充分开放；打磨等级根据现场实际情况确定，研磨后表面应坚实平整。

2. **密封固化剂渗透**：按照固化剂生产厂家技术指导，均匀洒布密封固化剂溶液于基面上，保持湿润状态 30—60min；待液体吸收后用清水冲洗残余液膜并吸干多余水分。此渗透程序按厂家工艺说明书分多次循环完成。

3. **精细研磨**：渗透反应完成（通常 ≥24h 固化时间）后，逐级更换更高目数的研磨盘进行精细研磨，直至表面呈现均匀光泽度。

4. **抛光撒剂**：抛光阶段分三次进行，每次抛光作业后均匀撒布专用抛光剂，以促进晶体二次生长和镜面效果形成；最终表面光泽度满足消防站车库使用功能需求。

5. **质量控制指标**：固化地坪表面硬度 ≥莫氏 7 级，耐磨度降低 ≥50%，防尘抗渗性能达标；面层无明显色差及裂纹。

> **注**：密封固化剂具体施工工艺遍数、研磨渗透次数及抛光遍数以实际施工时的材料厂家技术手册为准，本方案所述\"五遍密封固化剂研磨渗透+三次抛光\"为参考施工节奏，现场应根据基面状况灵活调整。

## 五、二楼战斗员宿舍卫生间翻新工程

### （一）拆除工程

1. **饰面层拆除**：依次拆除楼地面 300×300 防滑地砖（36㎡）、墙面 10厚 300×600 内墙面砖（166㎡）、铝合金扣板吊顶（36㎡）；拆除过程严禁野蛮操作损坏结构楼板及墙体。

2. **防水层拆除**：铲除原有墙面防水及找平层（166㎡）、地面防水及找平层（36㎡），直至露出坚实结构基层。

3. **管线及设备拆除**：拆除 DN25 给水管（100m），蹲便器 7 组利旧暂存，灯具、热水器、淋浴器等设施（10 套）小心拆卸集中保管以备回装。

### （二）防水工程（核心管控环节）

1. **基层处理**：楼地面及墙面彻底清扫浮灰、松散物，阴角部位做成 R=50mm 圆弧角；管根、地漏周边剔槽嵌密封膏。

2. **找平层**：楼地面整体做平面砂浆找平层（36㎡），坡度坡向地漏方向，坡度 ≥1%。

3. **JS 涂膜防水层**：
   - 地面及墙面均满做 Ⅱ型 JS 防水涂料，总厚度 1.5mm；施工分两遍完成，十字交叉法涂刷确保覆盖均匀、无漏点。
   - 淋浴区立面防水上翻高度按不低于 1.8m 控制；其他区域墙面防水上翻高度 ≥0.3m。
   - 管根、地漏、阴阳角等节点部位增铺一层聚酯布附加层，宽度 ≥200mm。
   - 墙面找平及防水保护层施工（332㎡），采用 1:3 水泥砂浆抹面保护防水层不受后续工序破坏。

4. **闭水试验**：防水层干燥固化后（通常 ≥48h），封堵地漏灌水蓄水，水面高度最高处 ≥20mm，持续闭水 24h 无渗漏、无湿渍方可进入下道工序。

### （三）墙地砖铺贴

1. **地砖铺贴**：选用 300×300mm 防滑地砖，采用 1:3 干硬性水泥砂浆作为结合层（厚度 20—30mm），地砖背面满刮素水泥浆结合；铺贴时从里向外逐块推进，用橡胶锤轻击压实调平；砖缝宽 2—3mm 采用专用十字定位卡控制。

2. **墙砖铺贴**：内墙面砖 10mm 厚 300×600 规格，采用聚合物粘结砂浆粘贴，粘贴面积 ≥85%；排砖时以阳角整砖为主，非整砖置于阴角处；砖缝横平竖直，缝隙宽 3—5mm。

3. **质量控制指标**：
   - 整体空鼓率 ≤3%（单块 ≤5%）。
   - 表面平整度偏差 ≤2mm/2m，缝格平直偏差 ≤1.5mm/5m。
   - 地漏周边找坡合理，排水通畅无积水。

### （四）给排水管道安装

1. **管材及连接**：暗敷给水管道采用 DN25 给水管（PPR 材质），热熔连接；热熔温度控制在 260±10℃，对接时间按管材壁厚确定，冷却期间严禁旋拧或移动接头。

2. **打压试验**：管道安装完毕后实施水压试验，试验压力为工作压力的 1.5 倍（且 ≥0.6MPa）；稳压 1h 压力降 ≤0.05MPa，随后工作压力下检查各接头无渗漏为合格。打压过程由专职质检员旁站记录。

3. **隐蔽验收**：打压合格后办理隐蔽工程验收手续，方可进行墙面保护层及饰面砖铺贴。

### （五）吊顶及设备安装

1. **铝合金扣板吊顶**：按原位恢复安装铝合金扣板吊顶（总量 135㎡），拆除原有吊顶时保留完好龙骨及吊杆，损坏件予以更换；安装前复核吊顶标高及边角线，副龙骨间距 ≤400mm，主龙骨间距 ≤1000mm，吊杆间距 ≤1000mm。

2. **洁具及设备回装**：蹲便器利旧安装 7 组、新安 3 组，灯具、热水器、淋浴器等（10 套）利旧回装；回装过程做好成品保护，避免划伤原有防水层及饰面砖。

## 六、天棚及墙面翻新工程

### （一）拆除工程

1. **涂料层全面铲除**：对室内天棚及墙面原涂层进行全面铲除拆除（工程量 4902㎡），包括原乳胶漆面层及底层腻子的彻底剥离；铲除深度以露出坚实基层为限。

2. **深度铲除区域**：约 500㎡ 涉及混合砂浆面及水泥砂浆面的墙柱面需进行深度铲除，使用电动铲削工具清除松动砂浆层至坚实基层。

### （二）墙面抹灰找平

1. **基层处理**：铲除后的墙面清扫浮灰、油污，提前一日充分浇水湿润；不同基体交接部位挂设标准网格布（搭接 ≥150mm）。

2. **抹灰层施工**：墙面重新进行一般抹灰找平（500㎡），抹灰厚度及砂浆品种按现行规范要求控制，分层施作、每层厚度 7—9mm，总厚度符合设计及规范要求。

3. **养护**：抹灰层终凝后洒水养护 ≥7d。

### （三）腻子批刮

1. **材料要求**：采用耐水性成品腻子膏，进场查验合格证及环保检测报告，各项有害物质限量指标须符合 GB30981.1-2025 标准。

2. **批刮工艺**：天棚及墙面分批批刮腻子 2 遍，第一遍腻子以找平为目的、稍厚批刮；第二遍腻子以收面细腻为目的、薄刮罩面。两遍之间间隔时间视环境温湿度而定（一般 ≥4h），待前一遍完全干燥后方可进行下一遍。

3. **打磨**：腻子层干燥后采用细砂纸打磨至表面平整无砂痕，打磨后清扫干净灰尘。

### （四）乳胶漆涂刷

1. **施工顺序**：严格执行\"先顶后墙、先上后下\"的作业顺序，即先施工天棚乳胶漆再施工墙面乳胶漆；同一墙面从阴角向阳角方向滚涂。

2. **底漆涂刷**：腻子层验收合格后首先涂刷抗碱封闭底漆 1 遍，封闭基层碱性及吸收力，增强面漆附着力。

3. **面漆涂刷**：面漆分两遍滚涂或喷涂施工，每遍间隔时间 ≥4h（以手指按压无指痕为准）；涂料涂刷均匀一致，不得漏刷、流坠、透底。

4. **质量控制指标**：
   - 室内墙面乳胶漆平整度偏差 ≤2mm/2m。
   - 色漆的颜色、光泽度均匀一致，无明显返碱、咬色、流坠、疙瘩等现象。
   - 分色线直线度偏差 ≤2mm/1m，接口顺直。

### （五）玻璃贴膜

1. **防爆膜粘贴**：门窗玻璃区域按要求粘贴防爆膜（46.5㎡），施工前清洁玻璃表面除尘去油，贴膜过程用刮板由中心向四周赶出气泡，边缘裁切整齐并贴牢。

## 七、施工工艺共性要求

1. **物料环保标准**：真石漆、乳胶漆、JS 防水涂料等各类涂料及防水材料必须符合 GB30981.1-2025《建筑用水性木器涂料》有害物质限量标准要求，进场逐一核验检测报告，严禁使用不合格产品。

2. **施工间歇管理**：各涂层工序间须严格把控干燥时间，环境相对湿度 >85% 或气温 <5℃ 时不宜进行水性涂料施工；雨天室外停止一切饰面作业。

3. **成品保护**：每道工序完成后立即实施防护措施，已完成的防水层、饰面层、安装品均须挂牌标识并划定专人看护责任区。

4. **机具进退场**：小型便携式机具按\"先进场后进场\"原则按需调配；每日工完场清，退场机具清点销项登记。
