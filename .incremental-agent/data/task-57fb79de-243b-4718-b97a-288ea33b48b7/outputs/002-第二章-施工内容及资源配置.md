# 第二章 施工内容及资源配置

## 一、工程概况与编制依据简述

本项目为双流机场东消防站维修工程，建设单位为成都空港建设开发服务有限公司，工程规模属小型建筑综合维修项目。施工范围涵盖外墙翻新、天棚及墙面翻新、车库环氧地面翻新、二楼战斗员宿舍卫生间翻新及杆塔挡土墙修复五大板块。施工作业时段限定为每日08:00至18:00，工期以业主签发的开工令为准，总日历天数暂以XX日历天计。

本工程施工方案编制依据《建筑工程施工质量验收统一标准》GB50300-2013等十一部现行国家规范，所有分项工程须严格对标规范执行，确保一次验收合格率100%。

## 六、周转材料及物资管理要求

施工现场周转材料和易受潮材料的堆放及保管须遵循以下规定：

1. **围挡搭设材料**：采用2.5m高轻钢龙骨彩钢板全封闭围挡，骨架采用75型轻钢龙骨或40mm镀锌矩管框架，面板为12mm厚彩钢板，打围长度约36m。

2. **易潮材料堆放防护**：板材、水泥、石膏腻子和各类粉状材料入库存放时，地面须铺设100mm高木方垫层，木方之上满铺木工板防潮隔离；零星材料集中放置于金属货架上整齐码放。

3. **进退场清点销项制**：所有机具材料进场须经专人验收登记，退场执行清点销项制度，防止贵重工具遗落在施工区域内。

4. **涂装材料环保要求**：真石漆、乳胶漆等各类涂料必须符合 GB30981.1-2025 有害物质限量标准要求，严禁使用不合格产品。
