# 第七章 风险管控（LEC评价法）

## 一、概述

本工程采用 LEC 评价法对施工全过程的危险源进行定量风险评估。LEC 评价法通过计算风险值 $D = L \times E \times C$，将风险划分为不同等级，并据此确定管控层级与应对措施。

本工程主要事故类型有：**火灾、触电、物体打击、机械伤害、高处坠落、中毒**。以上六类事故在本章中将逐一进行 LEC 风险辨识与评估。

| 指标 | 含义 | 管控要求 |
|------|------|---------|
| 最高风险等级 | 重大风险（公司级管控） | 立即停工整改 |
| 较大风险 | D≥270（项目部级管控） | 制定专项措施 |
| 一般风险 | D＜270（项目部级管控） | 按常规安全制度执行 |

## 二、LEC 评价参数标准

### （一）L 值——事故发生的可能性

| L 值 | 含义 |
|------|------|
| 10 | 完全可以预料 |
| 6 | 相当可能 |
| 3 | 可能，但不经常 |
| 1 | 可能性小，完全意外 |
| 0.5 | 很不可能，可以设想 |
| 0.2 | 极不可能 |
| 0.1 | 实际不可能 |

### （二）E 值——人员暴露于危险环境的频繁程度

| E 值 | 含义 |
|------|------|
| 10 | 连续暴露 |
| 6 | 每天工作时间内暴露 |
| 3 | 每周一次或偶尔暴露 |
| 2 | 每月一次暴露 |
| 1 | 每年几次暴露 |
| 0.5 | 非常罕见暴露 |

### （三）C 值——事故后果的严重性

| C 值 | 后果描述 |
|------|---------|
| 100 | 10人以上死亡，或50人以上重伤，直接经济损失5000万以上 |
| 40 | 3人以上10人以下死亡，或10人以上50人以下重伤，直接经济损失1000万以上 |
| 15 | 3人以下死亡或10人以下重伤，直接经济损失100万以上 |
| 7 | 丧失劳动力、截肢、骨折、听力丧失、慢性病，直接经济损失10万以上 |
| 3 | 轻微受伤、间歇不舒服，直接经济损失1万以上 |
| 1 | 无伤亡，直接经济损失1万以下 |

### （四）D 值——风险值及分级

$$D = L \times E \times C$$

根据本工程施工特点及各分项工艺的实际暴露频率，结合已有量化数据推断，D 值风险等级划分如下：

| D 值范围 | 风险等级 | 管控层级 |
|----------|---------|---------|
| ≥320 | **重大风险** | 公司级管控 |
| 160～320 | **较大风险** | 项目部级管控 |
| 70～160 | **一般风险** | 班组级管控 |
| ＜70 | **低风险** | 日常巡查管理 |

> 注：D 值分级阈值引自行业通用标准，本项目原始资料中未列出具体数值区间，上述分级参照现行《建筑施工安全检查标准》执行。

## 四、风险分级管控

### （一）管控架构

本工程建立**公司级—项目部级—班组级**三级风险管控体系，具体职责划分如下：

| 管控层级 | 适用风险等级 | 对应 D 值范围 | 责任人 |
|---------|------------|-------------|-------|
| 公司级 | 重大风险 | ≥320 | 公司安全管理主管 |
| 项目部级 | 较大风险、一般风险 | 70～320 | 项目经理、专职安全员 |
| 班组级 | 一般风险、低风险 | ＜160（项目部级以外） | 班组长、兼职安全员 |

### （二）项目级安全管理小组编制

现场配置 **5名专职安全员**，组成安全管理小组，落实全天候旁站监督：

- **组长**（1人）：负责统筹项目级风险管控，对接公司级督导；
- **电工安全员**（1人）：专管临时供用电安全风险，重点检查三级配电两级保护执行情况；
- **动火监督员**（1人）：专管动火作业风险，监督防火隔离、灭火器配置及留守观察；
- **高空作业安全员**（1人）：专管脚手架搭拆、吊篮作业风险，风速监测与防坠落检查；
- **综合安全员**（1人）：负责物体打击、机械伤害、交通安全等日常巡查。

### （三）动态管控流程

```
危险源辨识 → LEC量化评分 → 定级分类 → 制定管控措施 → 交底落实 → 过程监督 → 复查更新
```

**管控流程节点说明：**

1. **辨识阶段**：开工前由项目部组织全员危险源辨识，覆盖全部五个分部工程及交叉作业面。
2. **量化评分**：对每项危险源给出 L、E、C 赋值，计算 D 值并确定风险等级。
3. **定级分类**：按 D 值划入四级风险矩阵，明确对应管控层级。
4. **措施制定**：针对较大及以上风险编制专项施工方案，报公司审批后实施。
5. **交底落实**：每一项风险管控措施必须落实到具体操作班组和个人。
6. **过程监督**：5人安全管理小组分片区包干，全程旁站。
7. **复查更新**：每周召开一次风险管控例会，根据施工进度动态调整风险清单。

## 五、隐患排查治理

### （一）隐患分级

依据 D 值量化结果，隐患分为四类：

| 类别 | D 值 | 处置时限 | 报告路径 |
|------|------|---------|---------|
| 重大隐患 | ≥320 | **立即停工** | 项目组 → 公司安委会 |
| 较大隐患 | 160～320 | 24小时内整改 | 项目总工 → 项目经理 |
| 一般隐患 | 70～160 | 72小时内整改 | 专职安全员 → 项目总工 |
| 轻微隐患 | ＜70 | 当日整改 | 班组长 → 专职安全员 |

### （二）排查频次

| 排查类型 | 频次 | 参与人员 | 重点内容 |
|---------|------|---------|---------|
| 每日巡查 | 每日2次 | 安全管理小组全员 | 当日作业面的风险管控措施落实情况 |
| 周全面检查 | 每周1次 | 项目经理带队，全体安全员 | 全工地风险点位复查 |
| 专项检查 | 按需触发 | 对应专业安全员 | 动火作业/临时用电/高处作业等专项 |

### （三）闭环管理要求

隐患整改须遵循 **"定人、定时、定措施"** 三定原则，整改完成后须经原检查人复查签字确认，形成从发现到销号的完整闭环记录。
