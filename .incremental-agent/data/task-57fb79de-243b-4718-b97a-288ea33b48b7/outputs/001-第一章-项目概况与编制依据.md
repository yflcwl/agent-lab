### 1.2 工程地址与现场条件

#### （1）地理位置及交通环境

本工程施工地点位于双流机场东消防站内，临近110kV羊航线1#杆塔。场地周边存在高压输电设施及地下管线分布，进场材料运输需服从机场整体交通调度安排。

#### （2）围挡与场地条件

- 拟采用 **2.5m高轻钢龙骨彩钢板** 对施工及影响区域进行全封闭打围，打围总长度约 **36m**。
- 围挡框架采用 **75型轻钢龙骨** 或 **40镀锌矩管** 搭设，面板为厚度 **12mm彩钢板**。
- 围挡四周与施工区域边界的距离控制在 **1.2m以内**，确保围挡高度不影响周边区域正常运行。
- 围挡外层须平整美观，不得有尖锐物凸出，不得影响人行道通行。

#### （3）施工条件现状

该项目为既有建筑综合维修性质，不涉及新建土建主体，无建筑物层数、建筑面积等传统工程概况要素。施工主要面向已有外立面、室内空间及附属构筑物的翻新改造，重点控制作业噪声、粉尘扩散及对机场日常运行的干扰。

## 三、工程特点与现场约束条件

### 3.1 现场封闭管理要求

| 管控要素 | 具体要求 |
|----------|----------|
| 围挡形式 | 2.5m高轻钢龙骨（或40镀锌矩管）彩钢板全封闭骨架 |
| 围挡长度 | 约36m |
| 信息栏设置 | 入口一侧离地1.7m处注明项目名称、施工单位、施工内容 |
| 警示标语 | "施工中，请勿靠近""必须佩戴安全帽""闲人免进""注意安全"等中英文标识 |
| 风险控制公示 | 《施工项目风险控制表》悬挂于围挡醒目位置 |
| 边界间距 | 围挡距施工区域边缘 ≤ 1.2m |
| 外观要求 | 围挡外层平整、美观，无尖锐物凸出，不得影响人行通道 |

### 3.2 地下管线保护约束

施工前须组织管线产权单位对挡土墙开挖范围内的现有地下管线进行确认及排障作业，并对开挖区域进行人工探沟开挖，探明管线走向及埋深后方可进入下一道工序。具体要求如下：

1. **探沟参数**：沿现有挡土墙边线人工开挖探沟，总长 **36m**，宽 **0.8m**，深 **1m**。
2. **开挖方式**：全程人工开挖，专人守护指挥；**严禁使用十字镐、钢钎** 等冲击工具；**禁止机械直挖**。
3. **管线确认**：挖探至基础底标高深度未发现管线后，方可进行下一步施工作业；发现管线异常立即停工上报，通知产权单位二次确认。
4. **裸露防护**：对已探明的裸露管线采取包裹、支托防护措施，确保运行安全。

> **风险等级提示**：根据LEC评价法，"地下管线不明导致管线破坏"判定为 **较大风险（D=270）**，属于施工全过程重点管控事项。专职安全员须旁站监督探沟开挖工序。

### 3.3 高压设施保护约束

施工区域紧邻110kV羊航线1#杆塔，作业过程中须严格遵守电力线路保护区管理规定，任何机械设备、人员及物料进出均不得侵入安全净空限距。塔杆周边不锈钢栏杆的拆除与利旧安装须由具备特种作业资质的操作人员实施，并由现场负责人全程监护。

### 3.4 环境与文明施工约束

1. 拆除作业产生的建筑垃圾须袋装化清运，不得露天堆放或随坡散落。
2. 真石漆喷涂、乳胶漆刷涂等涂装作业须选用符合国家 GB30981.1-2025 标准限量的环保型产品。
3. 施工作业产生的粉尘应采取洒水抑尘措施，避免影响相邻航空运行区的环境空气质量。
4. 工具、材料进退场执行清点销项制度，防止遗留杂物形成FOD（外来物损坏源）。
