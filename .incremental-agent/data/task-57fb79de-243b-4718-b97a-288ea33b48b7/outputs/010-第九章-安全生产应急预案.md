# 第九章 安全生产应急预案

## 第一节 总则

### 一、编制目的

为确保双流机场东消防站维修工程施工过程中一旦发生突发事件，能够迅速、有序、高效地开展应急救援行动，最大限度地减少人员伤亡和财产损失，保障机场正常运营秩序不受影响，依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》及本项目危险源识别结果，特制定本应急预案。

> **编制说明**：本章以第七章LEC评价法定量风险评估为基础，重点围绕 D≥270 的两项较大风险（动火作业火灾、地下管线破坏）编制应急处置方案；同时覆盖施工现场可能发生的六类典型事故。

### 二、编制依据

| 序号 | 名称 | 备注 |
|:---:|------|------|
| 1 | 《中华人民共和国安全生产法》 | 国家法律 |

| 3 | 《建设工程施工现场消防安全技术规范》GB50720-2011 | 消防安全 |

| 6 | 本项目安全保障措施（第六章） | 前置安全制度 |

### 三、工作原则

1. **以人为本，安全第一** — 发生事故时首要任务是抢救受伤人员，最大限度保障生命安全，随后才是财产保护和设备撤离。
2. **预防为主，常备不懈** — 加强对施工过程的安全管理，做好事故预防工作，建立健全应急救援体系，定期组织演练，做到有备无患。
3. **快速反应，协同应对** — 事故发生后立即启动应急预案，各应急小组迅速到位，形成统一指挥、协调联动、快速响应的救援机制。
4. **科学施救，依法处置** — 根据事故性质和严重程度采取针对性救援措施，严禁盲目施救导致二次伤害；全过程依法依规开展事故调查。

### 四、应急适用范围

本预案适用于施工过程中发生的以下类型突发事件：
- **火灾事故** — 真石漆材料库、动火作业点、JS防水涂料储存区引发的火情；
- **触电事故** — 临时用电线路漏电、短路导致的电击伤亡；
- **高处坠落事故** — 外墙翻新脚手架/吊篮作业中人员坠落；
- **物体打击事故** — 建筑物上构配件或工具掉落击中下方人员；
- **机械伤害事故** — 切割机、角磨机、电镐等设备操作不当致伤；
- **中毒窒息事故** — 密闭空间内涂料挥发性气体聚集引发中毒；
- **地下管线破坏事故** — 探挖区域发现未探明管线破裂造成水损、气损或电气故障。

## 第二节 应急组织机构及职责

### 一、应急救援领导小组

成立以项目经理为组长的应急救援领导小组，负责全面指挥和协调应急救援工作。

#### （一）领导小组组成

| 职务 | 人员 | 职责 |
|------|------|------|
| 组长 | 项目经理 | 全面负责应急救援工作的指挥和协调，组织制定和实施应急救援预案，及时向上级主管部门报告事故情况 |
| 副组长 | 生产经理 | 协助组长开展应急救援工作，负责现场调度协调和资源调配 |
| 副组长 | 技术负责人 | 提供技术方案支持，评估事故对结构安全和相邻设施的影响 |
| 副组长 | 安全负责人 | 负责现场安全管控，组织抢险救援组实施具体措施 |
| 成员 | 各部门负责人 | 按各自职责参与救援工作，保障信息传递畅通 |

> **注**：以上人员联系方式已在项目部内部通讯录备案，应急状态下确保通讯畅通。日常联系电话参见附表。

#### （二）组长核心职责
1. 接到事故报告后，立即决定是否启动应急预案；
2. 指挥各应急工作组分工协作，统筹调配现场资源；
3. 负责向公司值班领导、机场集团及行政综合部逐级上报事故情况；
4. 决定事故现场的停工范围、人员疏散方案和交通管制措施。

### 二、应急救援工作小组

领导小组下设四个专项工作小组，构成"一总四专"的应急执行体系。

#### （一）抢险救援组

| 项目 | 内容 |
|------|------|
| 组长 | 安全负责人 |
| 成员 | 专职安全员及各施工班组长 |
| 主要职责 | ①负责事故现场的抢险救援工作，组织实施抢险救援方案；②营救被困人员，转移受伤人员；③控制事故现场，防止事态进一步扩大；④配合相关职能部门进行事故现场勘查 |

#### （二）医疗救护组

| 项目 | 内容 |
|------|------|
| 组长 | 生产经理 |
| 成员 | 经过急救培训的兼职安全员、后勤人员 |
| 主要职责 | ①负责对受伤人员进行现场初步急救和医疗救护；②联系医疗机构并护送受伤人员就医；③维护现场秩序，设置警戒区域，防止无关人员进入事故现场；④建立伤亡人员登记表并及时向指挥部汇总 |

#### （三）后勤保障组

| 项目 | 内容 |
|------|------|
| 组长 | 项目部行政主管 |
| 成员 | 仓库管理员、车辆驾驶员、采购员 |
| 主要职责 | ①负责应急救援物资的采购、储备和管理，保障供应；②调配应急运输车辆，确保伤员转运通道畅通；③提供应急照明、通讯器材等基础设施保障；④负责事故善后处理的后勤保障工作 |

#### （四）事故调查组

| 项目 | 内容 |
|------|------|
| 组长 | 技术负责人 |
| 成员 | 专职安全员、质检员、相关专业技术人员 |
| 主要职责 | ①负责对事故进行调查和分析，查明事故原因；②认定事故责任，形成书面调查报告；③提出处理建议和防范措施；④对整改措施落实情况进行跟踪验证 |

## 第三节 分级响应与报告制度

### 一、应急响应分级

根据事故的严重程度、影响范围和可能造成的人员伤亡后果，将应急响应分为三级。

#### （一）一级响应（重大及以上事故）

**触发条件**：凡可能导致发生一般安全及以上事故、已造成人员死亡或严重伤害的事故、严重影响机场运行的不安全事件、各类社会安全事件和公共卫生事件。

**报告时限**：事发项目管理人员应在 **15分钟内** 将事情基本情况报送公司值班领导，公司值班领导收到消息后应立即报告机场集团并着手调查了解事件情况，持续跟踪事件发展动态，并在 **15分钟内** 将情况报送行政综合部，行政综合部收到消息后应立即报送公司应急指挥领导小组。

**处置权限**：由公司级应急指挥机构统一接管指挥权，项目层面全力配合；必要时请求外部消防、医疗等社会力量支援。

#### （二）二级响应（运行不安全事件或轻伤事故）

**触发条件**：凡可能导致发生运行不安全事件或者已经造成人员轻伤的轻微事故。

**报告时限**：事发项目管理人员应在 **30分钟内** 将事情基本情况报送公司值班领导，公司值班领导收到消息后立即着手调查了解事件情况，持续跟踪事件发展动态，并在 **30分钟内** 将情况报送行政综合部。

**处置权限**：由各事业部、项目部应急组织机构负责处置，公司安全管理部门督导整改落实情况。

#### （三）三级响应（后果较轻的其他情况）

**触发条件**：未造成人员伤亡且对机场运行影响极小的其他突发情况，如小型初期火情已被扑灭、轻微磕碰伤等。

**处置权限**：由项目负责人进行现场处置，事后形成书面记录并报项目部安全管理部门备案。

### 二、报告内容要求

无论哪一级响应，事故报告应包含以下内容：
- 事故发生的时间、地点、工程项目名称、施工单位名称；
- 事故简要经过、伤亡人数（含失踪人数）、直接经济损失初步估计；
- 事故原因的初步判断；
- 事故发生后已采取的措施及目前事故控制情况；
- 事故发展趋势预测及下一步处置建议。

### 三、响应启动程序

1. **接报确认** — 应急救援领导小组接到事故报告后，核实事故等级和类别；
2. **预案启动** — 按规定级别启动相应层级应急预案，通知各应急工作小组成员赶赴事故现场；
3. **现场研判** — 到达现场后迅速了解事故情况，制定针对性应急救援方案；
4. **组织实施** — 按救援方案组织实施应急救援措施；
5. **动态调整** — 在救援过程中及时向上一级主管部门报告救援进展情况，根据事故发展态势适时调整救援方案；
6. **响应终止** — 险情解除、受伤人员已全部救出、事故现场得到妥善控制后，由启动人宣布响应终止。

## 第四节 应急处置措施

本节针对施工现场可能发生的七类事故逐一规定现场处置措施，其中前四项对应第七章LEC量化评估中标识为较大风险（D=270）的重点隐患领域。

### 一、火灾事故处置措施

> **对应风险**：第七章 D=270（动火作业），第六章第二节防火管控体系延伸至本条。

1. 发现火情后，第一发现人应立即大声呼喊示警，按下附近手动火灾报警按钮（如有），并就近取用灭火器或消火栓进行初期扑救；
2. 火势较小且在可控范围内的，由抢险救援组使用现场配备的干粉灭火器（≥2具4A级8kg/每个动火点）及消防沙进行扑救；
3. 火势失控或无法控制的，**立即拨打 85205119 火警电话**，向消防部门报告火灾位置和燃烧物质；
4. 同步疏散现场所有施工人员沿既有安全通道撤离至集结点，清点人数确认是否有人员滞留；
5. 设置警戒区域，安排专人值守入口，禁止无关人员和车辆进入；
6. 后勤保障组立即切断起火区域电源（严格执行"一机一闸一漏一箱"断开程序），防止次生电气火灾；
7. 如为易燃材料库火灾，应同时报告机场消防支队调派专用泡沫灭火装备到场支援；
8. 火灾扑灭后，专人留守观察不少于 **30分钟**，确认无残留火种、无复燃可能后方可撤离。

> **注意**：真石漆喷涂作业期间若遇火情，严禁用水直接喷射真石漆未干燥区域，防止扩散蔓延。

### 二、触电事故处置措施

> **对应风险**：第七章 D=126（临时供用电），第四节临时用电安全管控延伸到本条。

1. 发现触电事故后，首先应**立即切断电源**，使触电者脱离带电体；严禁徒手拉拽触电人员以免施救者同时触电；
2. 电源无法立即切断时，使用绝缘良好的干燥木棒、竹竿等绝缘工具挑开电线或将触电者拖离带电部位；
3. 脱离电源后，迅速检查伤者意识、呼吸和心跳状况：
   - **若伤者尚有意识**：就地平躺休息，保持呼吸道通畅，密切观察生命体征直至医疗人员到达；
   - **若伤者无意识但仍有呼吸**：将其置于侧卧位（复苏体位），防止误吸，等待救援；
   - **若伤者无意识且无呼吸**：立即实施心肺复苏术（CPR），按压频率100~120次/分，深度5~6cm；有条件时联合使用自动体外除颤器（AED）；
4. **及时拨打 85205120 急救电话**，说明触电位置、伤者人数和伤情状况，请求120急救车到场；
5. 医疗救护组维持现场秩序，引导救护车驶入最近入口，开辟伤员转运通道；
6. 事故处理后，由电工对全现场电路进行全面排查，更换损坏开关箱和漏电保护器，修复合格并经安全负责人验收后方可恢复供电。

### 三、高处坠落事故处置措施

> **对应风险**：对应第六章第三节高空与临边作业防护体系的应急处置延伸。

1. 发现坠落事故后，立即停止邻近区域的所有高处作业，疏散围观人员，避免二次伤害发生；
2. 将受伤人员小心转移到平坦安全地带，移动过程严禁拖拽伤者肢体，应保持身体轴线一致平移；
3. 对受伤人员进行现场简易急救：
   - 有明显出血部位的，采用干净敷料压迫止血；
   - 疑似骨折部位的，利用现场木板或硬质材料进行临时固定包扎；
   - 头部外伤伴有呕吐的，将伤者头偏向一侧，防止呕吐物吸入呼吸道；
4. 对脊柱疑似损伤的伤者，必须采用硬担架整体搬运，头部颈部保持中立位置，绝对禁止抱背或使用软担架；
5. **及时拨打 85205120 急救电话**，详细说明伤者伤情高度和可能的损伤部位，以便急救人员携带专业设备到场；
6. 医疗救护组引导救护车直达伤员位置，完成交接后陪同前往就近医院治疗。

### 四、机械伤害事故处置措施

1. 立即切断故障设备的电源，按下急停按钮，停止设备运行；
2. 对受伤人员进行现场急救，如止血包扎、骨折固定等；
3. 被机械卷入或夹住无法自行脱困的，不得强行拉扯，应由专业维修人员拆卸设备部件后解救；
4. **及时拨打 85205120 急救电话**，将受伤人员送往医院治疗；
5. 组织相关人员对机械设备进行检查和维修，排除故障原因后方可重新投入使用。

### 五、物体打击事故处置措施

1. 立即停止相关拆除作业和上方立体交叉施工，组织现场人员检查受伤情况；
2. 对受伤人员进行现场急救和医疗救护，必要时 **及时拨打 85205120 急救电话**；
3. 清理事故现场的坠落物，消除安全隐患，对尚未固定的构件采取加固或隔离措施；
4. 检查受损建筑物的围挡、防护棚等设施完整性，必要时重新搭设安全防护。

### 六、中毒窒息事故处置措施

> **对应风险**：卫生间等密闭空间涂刷JS防水涂料、天棚翻新中使用涂料稀释剂等化学溶剂挥发的有毒可燃气体聚集。

1. 立即将中毒窒息人员转移到通风良好的地方，解开衣领、腰带等束缚物，保持呼吸道通畅；
2. 在确保救援人员自身安全的前提下（佩戴防毒面具或活性炭口罩），迅速打开门窗、开启强制排风设备进行通风换气；
3. 对中毒窒息人员进行人工呼吸、心肺复苏等急救措施；
4. 若因真石漆稀释剂或固化剂等化学品泄漏导致中毒，应立即撤离附近所有人员并用砂土围堵泄漏物防止扩散；
5. **及时拨打 85205120 急救电话**，将中毒窒息人员送往医院治疗，并告知医生可能的毒物种类；
6. 在未确认有害气体浓度降至安全值之前，严禁任何人员进入污染区域。

### 七、地下管线破坏事故处置措施

> **对应风险**：第七章 D=270（地下管线探挖）。挡土墙基坑开挖、车库环氧地面局部破损重浇施工阶段存在此风险。

1. 探挖过程中一旦发现土层颜色异常、出现未标注管线（给水管道、电缆沟槽、通信管井等），**立即停止一切机械和人工开挖作业**；
2. 保护事故现场原状，划定警戒半径不小于 5m 的区域，设置警戒带并安排专人看守，禁止非救援人员进入；
3. 如果为水管爆裂出水，应关闭上游阀门或在距离破裂点外适当位置封堵供水管；如为电力电缆破损冒火花，应立即联系供电单位断电；
4. **及时拨打 85205119 火警电话（如涉及电气火灾）** 及 **85205120 急救电话（如有人员受伤）**；
5. 同时将情况逐层上报至公司值班领导和机场集团运行指挥中心，不得擅自隐瞒；
6. 由机场相关部门指派专业人员到场处置破損管线，施工方配合提供管线走向示意及探挖区域平面图；
7. 管线修复后经现场安全负责人复核确认无误，方可恢复周边施工，并须重新按规范开挖至少一处探沟验证。

## 第六节 培训与演练

### 一、安全教育培训

#### （一）常规培训内容

1. 定期组织作业人员进行安全教育培训，提高作业人员的安全意识和应急处置能力；
2. 培训内容包括但不限于：本预案各章节处置要点、应急物资存放位置和使用方法、逃生路线及紧急集合点分布图；
3. 每次进场新工人的三级安全教育中须包含本应急预案的宣讲环节。

#### （二）应急救援专业培训

1. 对应急救援人员（特别是5人安全管理小组成员）进行专业培训，使其熟悉应急救援预案的内容和应急处置程序，掌握应急救援技能和方法；
2. 专业技能培训涵盖：消防器材实操使用、心肺复苏术（CPR）演练、担架搬运技巧、现场警戒布控流程；
3. 电工岗位人员额外接受电气火灾扑救专项培训及应急断电操作演练。

### 二、应急演练要求

#### （一）演练频次与计划

1. 定期组织应急演练，检验应急预案的科学性、有效性和可操作性，提高应急救援队伍的实战能力；
2. 开工前组织一次综合性桌面推演，模拟两起以上不同类型的突发事故（至少包含动火作业火灾和地下管线破坏两类高风险场景），由领导小组逐项审核应急响应流程是否畅通；
3. 施工中每季度至少组织一次专项实地演练（可择高处坠落或触电任一场景），全员参与，全程拍照录像留存档案；
4. 每半年进行一次全要素综合演练，模拟最不利情景（多事故并发、夜间施工时段、恶劣天气条件下），考核全部应急小组协同作战能力。

#### （二）演练效果评估

1. 演练结束后，对演练效果进行评估，总结经验教训；
2. 形成《应急演练评估报告》，内容包括：参演人数、演练用时、发现问题、改进措施和建议；
3. 针对存在的问题及时对应急预案进行修订和完善，确保预案始终保持现实适用性和操作有效性；
4. 修订后的预案应重新向全体施工人员宣贯交底并签字确认。

### 三、应急演练记录归档

每次培训和演练均应形成书面记录，内容包括日期、参加人员签到表、演练主题、演练过程描述、存在问题及整改计划、照片或视频资料，存入项目管理安全台账备查。

## 第七节 后期处置

### 一、善后处理

1. 安抚伤亡人员家属，按有关规定给予赔偿，协助办理工伤认定手续；
2. 清理恢复事故现场，修复损毁的设施设备，确保满足复工条件；
3. 对遭受心理冲击的施工人员进行适当的心理疏导和人文关怀。

### 二、事故调查

1. 成立事故调查组，查明事故原因，认定事故责任；
2. 出具正式《事故调查报告》，包含时间线还原、因果分析、直接损失核算、责任划分及处罚建议；
3. 事故处理结果向全体施工人员通报，形成警示教育案例纳入后续安全培训教材。

### 三、应急评估

1. 对本应急预案的执行情况和实际效果进行评估，总结经验和不足；
2. 根据评估结果对应急预案进行修订完善，提升其针对性和可操作性；
3. 更新应急物资库存台账，补充消耗品并淘汰到期产品。
