# 任务原始文档分析 & 资料概览包

## 一、参考文档写法分析

> **来源文档**：`reference/reference-document.md`  
> **文档标题**：《C滑行道沥青段及315-317机位区域改造工程不停航施工组织管理方案》

### 1.1 结构组织特征

| 层级 | 说明 | 示例 |
|------|------|------|
| **一级标题**（汉字数字+顿号） | 二十个章节，覆盖不停航施工全要素 | `一、编制目的与依据` → `二十、各相关部门、单位的职责和检查的要求` |
| **二级标题**（阿拉伯数字+点） | 逐级细化至小节 | `1.1 编制目的` → `2.2.1 四川场道负责实施` |
| **三级标题**（阿拉伯数字+点+括号序号） | 进一步拆解到措施条目 | `9.1.1 开工前，提质办配合…` |
| **表格嵌入** | 机械/人员配置表穿插正文 | 表2（26项设备）、表3（30项工具） |
| **附件群** | 平面示意图、运行保障方案、联络通讯录等 | 附件1～附件11 |

### 1.2 行文风格

* **公文式陈述语体**——"为确保……特制定本方案"；"负责……"；"不得……"。
* **指令性句式为主**，高频使用"应""须""严禁""不得"等约束词。
* **数据先行**——先列工程量、数量，再配文字描述，便于审批人快速抓取参数。
* **段落短平快**——每段≤5行，避免长复合句；每条控制措施独立成段或独立编号。

### 1.3 篇幅与格式

| 指标 | 数值 |
|------|------|
| 总页数（含附图） | ≈48页 |
| 总字符量 | ~37,079字 |
| 目录层级深度 | 三级（如 2.2.1） |
| 图纸/附件数 | 附11件（含4张施工区域图、进出路线图等） |

### 1.4 技术表达方式

* **量化参数优先**：桩长 `8-12m`、桩径 `0.5m`、换填厚度 `0.3m/0.6m`、围挡高度 `2m`、净空限高 `40m/23m` 等全部以具体数值呈现。
* **分区分阶段表达**：四个施工区域各自有编号、关闭范围图、进出路线。
* **对照清单法**：风险评价采用 L×S→风险等级矩阵（A-E × Ⅰ-Ⅳ）。

### 1.5 安全管理框架特点

| 模块 | 内容要点 |
|------|----------|
| **FOD防控** | 十二节专章，涵盖FOD自检、清扫区设置、松散物密目网覆盖、尾车跟踪清扫等10项措施 |
| **净空保护** | 七节：明确净空限高、物料堆放高度≤1.5m、不遮挡灯光 |
| **动火许可** | 十五节：提前办理许可证、备案消防支队、每个动火点5m内配置2具4kg灭火器 |
| **人员培训** | 十八节：安全协调会、微信群通报、现场每日安全教育 |
