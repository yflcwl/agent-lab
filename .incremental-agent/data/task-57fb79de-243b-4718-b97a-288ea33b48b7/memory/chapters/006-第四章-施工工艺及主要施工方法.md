# 第四章 施工工艺及主要施工方法 章节记忆

## 摘要
重写后的第四章以完整工程量清单数据为基础，涵盖五大分部工程：杆塔挡土墙修复（含探沟开挖、C20垫层、Mu15页岩砖砌筑、C20地圈梁φ8@200箍筋加密、C30预制沟盖板）、外墙翻新（16个子项1789.62㎡真石漆饰面、三涂一布聚合物丙烯酸聚氨酯2.0mm挑檐防水、铝塑板60×3镀锌矩管骨架）、车库环氧地面（758㎡固化地坪）、卫生间翻新（18个子项JS防水1.5mmⅡ型闭水24h、PPR DN25给水管暗敷100m、蹲便器利旧7组+新装3组）和天棚墙面翻新（4902㎡乳胶漆先顶后墙）。新增编制依据规范列表（10部GB/JGJ标准）。

## 术语/参数基准
- 真石漆喷涂压力：0.6—0.8MPa，喷枪口径6—8mm
- JS防水涂料厚度：1.5mmⅡ型（地面+墙面均1.5mm）
- C30预制沟盖板规格：100×500×1000mm，φ12@150单层双向
- 铝塑板幕墙钢骨架：60×3镀锌矩管，双向间距600mm
- 铝合金扣板吊顶拆安：135㎡
- 防爆膜贴膜面积：46.5㎡
