# 第七章 风险管控（LEC评价法）- 章节记忆

## 摘要
本章围绕 LEC 评价法构建了完整的风险量化评估体系，包含 L/E/C 参数赋值标准、5项已量化风险清单（含2项较大风险）、三级管控架构、5人安全管理小组编制及隐患排查闭环管理流程。延伸至五大修缮板块各工序的风险辨识表，为后续应急预案编制提供量化依据。

## 关键参数
- **LEC公式**: D = L × E × C
- **D值分级**: ≥320(重大)/160~320(较大)/70~160(一般)/＜70(低) — 引自行业通用标准
- **已量化风险清单**:
  - 临时供用电: L=3,E=6,C=7,D=126(一般风险,项目部级)
  - 动火作业: L=3,E=6,C=15,D=270(**较大风险**,项目部级)
  - 机械施工作业: L=3,E=2,C=15,D=90(一般风险,项目部级)
  - 拆除作业: L=3,E=6,C=7,D=126(一般风险,项目部级)
  - 地下管线探挖: L=3,E=6,C=15,D=270(**较大风险**,项目部级)
- **施工方案编审** (A-E/Ⅰ-Ⅳ双评级): 未编制/未审批 = B级×Ⅱ级 = **重大风险**(公司级)
- **安全管理小组**: 5人专职安全员(组长+电工安全员+动火监督员+高空作业安全员+综合安全员)
- **应急电话**: 火警85205119 / 急救85205120
- **三定原则**: 隐患整改须定人、定时、定措施

## 术语定义
- **LEC评价法**: 风险值D=L×E×C定量评估方法,L为可能性,E为暴露频率,C为后果严重度
- **A-E评级系统**: 另有一套可能性评级(A很可能发生→E极不可能发生),与LEC并行使用于施工方案编审环节
- **Ⅰ-Ⅳ严重度分级**: 灾难(Ⅰ)→严重(Ⅱ)→轻度(Ⅲ)→轻微(Ⅳ)
- **大风险**: D≥320,需公司级管控并立即停工整改
