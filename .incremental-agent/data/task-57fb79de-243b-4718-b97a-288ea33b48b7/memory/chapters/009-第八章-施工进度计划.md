# 第八章 施工进度计划 独立记忆

## 摘要
本章基于五大分部工程量及工艺隐含时间约束，推算得出本项目总工期约45日历天，并采用主控线（外墙翻新）+并行线路的组织模式。含横道图文字描述、劳动力动态分布表、进度保证措施、关键线路识别和偏差调整机制。

## 核心参数与事实来源
- **总工期**：45日历天（推算值，原文为XX占位符）
- **每日工时**：08:00—18:00（10小时/天），来自docx offset ~1200
- **关键线路**：施工准备→外墙拆除→抹灰→养护≥7d→腻子→底漆→真石漆→罩面漆
- **次关键线路**：挡土墙修复线路
- **劳动力峰值**：29人（第二章数据）
- **各分部控制工期**：挡土墙15d、外墙20d、车库15d、卫生间10d、天棚18d
- **阶段划分**：准备期(3d)、拆除期(9d)、主体施工期(29d)、收尾验收(10d)
