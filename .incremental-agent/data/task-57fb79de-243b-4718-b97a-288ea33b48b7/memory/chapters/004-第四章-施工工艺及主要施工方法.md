# 第四章记忆——施工工艺及主要施工方法

## 摘要
本章覆盖五大分部工程的详细施工工艺：杆塔挡土墙修复（基槽→垫层→M10砂浆砌页岩砖→地圈梁C20→细石砼地坪→外立面装饰）、外墙翻新（拆除→25mm干混砂浆抹灰→抗裂层4mm→1.5mmⅡ型JS涂膜防水→真石漆饰面）、挑檐屋面防水（2.0mm三涂一布聚合物丙烯酸聚氨酯防水涂料）、车库地面翻新（铲除758㎡→破损处C30混凝土修补~250mm厚→固化地坪五遍研磨渗透三次抛光）、卫生间翻新（拆除→JS防水1.5mm十字交叉法→闭水24h→地砖铺贴→PPR DN25暗敷管热熔+打压试验→铝合金扣板吊顶恢复）、天棚墙面翻新（铲除4902㎡→抹灰500㎡→腻子2遍→乳胶漆先顶后墙两遍）。
