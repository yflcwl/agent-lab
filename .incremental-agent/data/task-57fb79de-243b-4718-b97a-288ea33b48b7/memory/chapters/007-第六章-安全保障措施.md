# 第六章 安全保障措施 - 章节记忆

## 摘要
本章围绕消防安全管理、高空临边防护、临时用电安全、个人防护装备配置、安全防护设施设置、安全检查与隐患排查治理六大模块展开，构建了从制度框架到具体技术措施的完整保障体系。针对原文档中安全措施描述相对简略的特点，大量引用了国家现行安全技术标准作为依据支撑。

## 关键参数
- **动火审批**：三级动火（一级公司级/二级项目部/三级班组），5m清除可燃物，2具灭火器/点，30min留守观察
- **脚手架**：两步三跨连墙件，外侧密目网+水平安全网，风速＞10.8m/s（6级）停止吊篮作业
- **基坑通行**：使用防护梯上下，禁止攀爬坑壁或跳入
- **临时用电**：三级配电两级保护，总漏电动作≤100mA/≤0.1s，末级≤30mA/≤0.1s，潮湿场所≤15mA
- **电缆敷设**：架空≥6m（机动车道）/≥4.5m（非机动车道）/≥2.5m（沿墙）；埋地≥0.7m
- **PPE**：安全帽GB2811、安全带GB6095、防尘口罩KN95及以上
- **检查频次**：每日巡查+每周全面检查+专项检查
- **应急电话**：火警85205119

## 术语定义
- **三级动火**：按火灾危险性划分的动火作业等级，从高到低分一、二、三级
- **三级配电两级保护**：总配电箱→分配电箱→开关箱 + 总漏保+末级漏保
- **LEC评价法**：风险值D=L×E×C，将在第七章详细展开
