# 第五章质量保证措施 - 章节记忆

## 摘要
本章系统阐述了本工程的质量管理目标、组织架构、控制制度、分项质量控制要点、检验批验收管理及成品保护措施。核心围绕一次验收合格率100%的目标，依托原文中的质量管理框架和砖砌体等关键量化指标展开编制。

## 事实来源
- **质量管理架构**：项目经理（第一责任人）→生产经理→技术负责人（方案/交底）→专职质量员（检查）→施工员→班组长；所有人员来自《施工方案-背景资料.docx》offset ~6261及~6988
- **三检制度**：自检→互检→交接检，确保工程检查验收一次通过
- **材料控制**：进场材料符合设计要求和质量标准，涂装材料须符合GB30981.1-2025有害物质限量标准
- **砖砌体质量指标**：水平灰缝饱满度≥80%，砖柱竖向灰缝≥90%，灰缝厚度8~12mm宜10mm，每检验批抽查不少于5处，砂浆试块每15万块一批抽一组
- **混凝土养护**：养护时间不少于7天，严格控制水灰比和配合比
- **防水闭水试验**：蓄水深度不小于20mm，持续观察不少于24h
- **抹灰施工**：分层施工防空鼓开裂，阴阳角顺直方正
- **成品保护**：避免重型设备移动、减少交叉作业、值班巡检制度、动态监控修补

## 术语与参数
- 一次验收合格率 100%
- 灰缝饱满度：水平≥80%/砖柱≥90%
- 灰缝宽度：8~12mm宜10mm
- 混凝土养护≥7天
- JS涂膜防水闭水试验≥24h
- GB 30981.1-2025 有害物质限量标准
- GB 50300-2013 统一标准
