# 第九章 安全生产应急预案 - 章节记忆

## 摘要
本章为施工组织设计最后一章，以第七章LEC评价法中两项D≥270较大风险（动火作业火灾D=270、地下管线破坏D=270）为核心触发条件，结合第六章安全保障措施框架和原文档"九·安全生产应急预案"全部内容编排而成。共设八节：总则、应急组织机构及职责、分级响应与报告制度、应急处置措施、应急保障、培训与演练、后期处置、附则。

## 关键参数
- **应急组织机构**："一总四专"架构——项目经理任组长的领导小组 + 抢险救援组/医疗救护组/后勤保障组/事故调查组四大工作小组；原文档联系人均为"XXX"占位符
- **三级响应机制**：一级15分钟（重大及以上）、二级30分钟（运行不安全事件或轻伤）、三级项目负责人自行处置
- **事故报告内容**：时间地点工程名称施工单位/简要经过伤亡人数直接经济损失初步估计/原因初步判断/已采取措施和控制情况/发展趋势预测
- **应急电话**：急救85205120 / 火警85205119（原文档），同时保留当地120/119备用渠道
- **应急物资清单**：12项（基于原文笼统提及+现行GB50720-2011补充细化）——干粉灭火器8kg ABC类(≥4A级)≥6具、消防沙1袋、水带2条、急救药箱1套、绝缘手套2双、绝缘靴2双、应急照明灯2盏、对讲机4台、硬担架1副、警戒带2盘、防毒面具4个、安全带1副
- **演练频次**：开工前综合桌面推演→每季度专项实地演练→每半年全要素综合演练
- **全员应急属性**：29名施工人员均为义务应急救援队成员，5人安全管理小组为重点救援力量

## 术语定义
- **一总四专**：一个应急救援领导小组统筹指挥 + 四个专项工作小组分别执行
- **三级响应**：按事故严重程度分为一级(15min)/二级(30min)/三级(自行处置)的分级报告制度
- **CPR**：心肺复苏术（Cardiopulmonary Resuscitation），按压频率100~120次/分，深度5~6cm
