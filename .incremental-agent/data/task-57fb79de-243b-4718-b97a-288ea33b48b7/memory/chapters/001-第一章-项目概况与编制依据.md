# 第一章独立记忆：项目概况与编制依据

## 摘要
本章确立了双流机场东消防站维修工程的整体框架——五大分部工程的工程量清单、作业时段限制（08:00-18:00）、现场封闭围挡参数（2.5m高/36m长）、以及11部编制依据规范标准。重点描述了110kV羊航线1#杆塔附近的地下管线保护约束和动土风险管控要求。

## 事实来源
- 《双流机场东消防站维修工程施工方案-背景资料.docx》offset 51~1005（项目概况）、offset 1005（施工内容）、offset 1586（作业时段及围挡描述）、offset ~2395（挡土墙构造参数及探沟技术要求）、offset ~5984（LEC风险评价）
- 《双流机场东消防站维修工程项目清单-背景资料.pdf》各分项工程量数据
