# 第三章 施工平面布置及现场管理 — 章节记忆

## 摘要
本章围绕施工现场平面布置原则展开，涵盖四个子节：(1)施工区域划分与总体布置原则；(2)围挡与封闭管理（75型轻钢龙骨/40镀锌矩管+12mm彩钢板，2m高，注水水马）；(3)临时设施搭建与管理（仓库/加工房设在公司集中加工库房，减少现场加工，内设值守岗亭和移动式厕所）；(4)环境保护与文明施工（散料密目网覆盖、物料堆放≤1.5m、垃圾封装每日清理带出、车辆出入口设清扫区）。地下管线保护（探沟36m×0.8m×1m，人工开挖，严禁机械直挖）作为重点管控内容单列详述。材料防潮与存放标准：易潮材料垫层100mm木方+木工板，零散材料金属货架。消防配置：施工区域每50㎡或15m半径≥2具3A级5KG干粉灭火器，库房每15㎡2具，动火点2具4A级8KG。引用规范包括GB50194-2014、JGJ/T 46-2024等。
