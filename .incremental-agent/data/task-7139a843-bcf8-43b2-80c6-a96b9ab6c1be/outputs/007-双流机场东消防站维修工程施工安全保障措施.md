# 双流机场东消防站维修工程施工安全保障措施

## 一、施工安全总体防范措施

施工过程中主要防范高空作业、有限空间作业、用电安全、配件遗留、施工用品工具及建渣坠入地面等安全风险，需对施工范围进行有效封闭，防止人员进入，并及时清理卫生。

### 1.1 安全技术交底

施工入场前对本次做法工艺、施工安全要点等进行安全技术交底。施工人员由正式引领人员带入，在施工区域专职安全员做好施工区域加强旁站，施工人员工具、材料配件进退场清点销项。

### 1.2 安全防护措施

| 防护措施 | 具体实施要求 |
|---------|------------|
| 围挡封闭 | 采用2.5m轻钢龙骨彩钢板全封闭打围，围挡上张贴明显施工信息和安全警示标志："施工中请勿靠近"、"必须佩戴安全帽"、"闲人免进"等 |
| 个人防护 | 作业人员正确穿戴劳动防护用品（安全帽、反光背心等） |
| 高处防护 | 搭设符合规范的脚手架或登高作业车，设置防护栏杆和安全网 |
| 封闭管理 | 划定危险区域设置封闭围挡和醒目的安全警示标志并派人看守 |
| 动火审批 | 严格执行动火作业审批制度，办理动火作业许可证 |

## 二、安全管理组织和职责

### 2.1 安全管理组织体系

| 序号 | 职务 | 岗位职责 |
|------|------|---------|
| 1 | 项目经理 | 统筹安排施工事宜，全面负责施工安全管理 |
| 2 | 生产经理 | 现场组织和管理工作，协调施工与安全的统筹 |
| 3 | 技术负责人 | 编制相关方案并进行技术交底 |
| 4 | 安全负责人 | 进行隐患排查，确保施工安全 |
| 5 | 施工员 | 落实施工方案，协调相关事宜 |

### 2.2 专职安全管理人员配置

配备专职安全人员进行全天候旁站监督，对施工作业全过程进行安全检查，发现安全隐患立即责令整改。

## 三、动火作业安全保障措施

### 3.1 作业前准备

1. **动火审批制度**：严格执行动火作业审批制度，办理动火作业许可证，明确动火等级、地点、时间、人员及安全措施，未经审批严禁作业。
2. **清除易燃物**：作业前清理动火点10米范围内易燃易爆物品，无法移除的采用防火毯、石棉板等彻底隔离覆盖。
3. **消防设施配备**：检查作业区域消防设施，配备足量合格灭火器、消防沙、消防水带，确保完好有效。
4. **专项安全技术交底**：对作业人员进行专项安全技术交底，明确作业风险、应急措施，特种作业人员必须持证上岗。
5. **可燃气体检测**：检测作业区域可燃气体浓度，合格后方可动火，在受限空间、密闭场所动火需持续监测。

### 3.2 作业中管控

1. **专人监护**：动火作业实行专人监护，监护人全程在岗不得擅自离岗，发现异常立即停止作业。
2. **防护用品穿戴**：作业人员按规定穿戴阻燃防护服、防护眼镜、防护手套等劳动防护用品。
3. **动火设备管理**：动火工具、设备完好无损，气瓶直立固定间距不小于5米，距动火点不小于10米，严禁暴晒倾倒。
4. **严格动火范围**：严格控制动火范围与时间，严禁擅自扩大作业区域、延长动火时长，中途停歇复工前重新检查确认。
5. **高处动火防护**：高处动火采取接火盆、防火毯等防火花飞溅措施，防止引燃下方可燃物。

### 3.3 作业后收尾

1. **共同检查**：作业结束后，动火人、监护人共同检查现场，彻底熄灭火源清理残留火星焊渣。
2. **留守监护**：留守监护30分钟以上，确认无复燃、无隐患后方可离开现场。
3. **关闭许可**：关闭动火作业许可，做好作业记录，发现隐患及时上报处理。

## 四、临时用电作业安全保障措施

### 4.1 作业前准备

1. **临时用电许可**：办理临时用电作业许可，明确接线方式、负荷、防护措施，严禁私拉乱接。
2. **持证电工操作**：作业人员为持证电工，对电缆、开关、漏电保护器、配电箱等设备进行全面检查，严禁使用破损老化不合格电器。
3. **"一机一闸一漏一箱"**：临时用电系统必须安装漏电保护器做到"一机一闸一漏一箱"，接地接零保护规范可靠。
4. **安全电压使用**：现场设置明显用电警示标志潮湿受限空间等危险区域使用安全电压（≤36V，特别潮湿≤12V）。

### 4.2 作业中管控

1. **电缆敷设管理**：电缆架空敷设或穿管保护，严禁碾压拖拽浸泡水中穿越通道采取防破损措施。
2. **配电箱管理**：配电箱上锁管理防雨防潮防尘，非专业人员严禁操作。
3. **金属外壳接地**：用电设备金属外壳可靠接地移动电器使用绝缘完好的软橡胶电缆。
4. **停电作业制度**：严禁带电接线拆线检修停电作业执行"停电—验电—挂牌—上锁"制度。
5. **险情应急处置**：发现漏电短路触电等险情立即切断电源严禁带电处置。

### 4.3 三级配电箱部署

本次施工用电配备三级配电箱。

## 五、动土作业安全保障措施

### 5.1 作业前准备

1. **管线确认排障**：组织相关管线产权单位对施工范围内现有地下管线进行管线确认及排障作业。
2. **安全技术交底**：根据管线确认单对工长及班组长、工人进行安全技术交底，明确可能涉及的管线种类及走向。同时对工人进行心理疏导，降低急躁施工情绪，确保人工开挖管线万无一失。

### 5.2 作业中管控

1. **探沟永临结合开挖**：结合地下管线图采用永临结合方式沿原有挡土墙边线开挖探沟，探沟长36m宽0.8m深1m，指派专人全程指挥跟进。
2. **有效管线防护**：开挖作业时应对各类地下管线进行有效防护防止管线挖断损坏导致漏水漏电等保证作业人员及周边人员的人身安全。
3. **发现管线确认**：在施工期间人工开挖若发现管线应确认其位置做好标记通知产权单位对管线进行二次确认经同意后确保施工按管线保护要求实施。
4. **受损管线处置**：施工过程中一旦出现导致各类管线受损情况发现人第一时间向项目负责人报告并向动能部项目负责人报告由动能部联系涉及管线的所属单位进行排查确认及时恢复损坏管线。

### 5.3 禁止事项

- 开挖时禁止使用十字镐、钢钎开挖探沟。
- 发现异常情况及时停止开挖作业，轻轻扩宽范围探明管线种类规格根数走向和深度并作标记影像留底和书面作记录，经监管人员进行确认通知产权单位对管线进行二次确认。
- 严禁机械开挖破坏管线，对裸露管线采取包裹支托防护措施。

## 六、其他作业安全保障措施

### 6.1 高处作业安全保障

1. **脚手架搭设**：搭设符合规范的脚手架或满堂支架，经验收合格后方可投入使用。脚手架满铺脚手板设置防护栏杆（≥1.2m高）和安全网。
2. **登高作业车**：使用登高作业车进行外墙真石漆喷涂等高处作业，操作人员持证上岗。
3. **安全带使用**：高处作业人员必须正确佩戴安全带，坚持高挂低用原则。
4. **洞口临边防护**：屋面边缘、楼层周边等临边洞口设置牢固可靠的防护栏杆和安全平网。

### 6.2 有限空间作业安全保障

1. **强制通风**：地下室、管沟等有限空间作业前强制通风，确保空气流通。
2. **气体检测**：检测作业区域内氧气含量及有害气体浓度，合格后方可进入。
3. **连续监测**：作业过程中持续监测气体变化，发现异常立即撤离人员。
4. **专人监护**：有限空间入口安排专人监护，保持内外通信畅通。

### 6.3 拆除作业安全保障

1. **自上而下逐层拆除**：旧挡墙拆除须自上而下逐层拆砖，避免墙体突然坍塌。
2. **硬质封闭围挡**：拆除作业区域设置硬质封闭围挡和安全警示标志未实行封闭管理。
3. **碎片飞溅控制**：拆除过程中采取遮挡措施防止碎料飞溅伤人。
4. **垃圾集中清运**：混凝土碎渣分类回收废渣随建筑垃圾一并外运不得随意抛洒。

### 6.4 机械操作安全保障

1. **持证上岗**：特种设备操作人员须持有相应有效的资质证书。
2. **安全技术交底**：进出场前施工单位安全员对施工人员进行安全技术交底，加强人员安全教育。
3. **设备巡检**：定期对设备进行排查检修，避免设备故障引发事故。
4. **防护装置**：切割机旋转或运动部件必须设置安全防护罩操作人员佩戴防护手套等防护用品。
5. **现场监管**：施工期间配备现场安全员进行安全监管。

### 6.5 配件及建渣坠落防范

1. **工具清点销项**：施工人员工具、材料配件进退场清点销项，严防遗漏坠落。
2. **物料堆放固定**：库房材料应堆放整齐板材水泥石膏腻子等易受潮材料堆放时地面采用100mm高木方做基础木方上铺设木工板材料放置于木工板上。
3. **施工现场清洁**：及时清理施工区域内废料杂物，保持场地整洁。

## 八、应急预案衔接

本工程的安全生产应急管理与已编制的《双流机场东消防站维修工程安全生产应急预案》相衔接，各安全管理环节中发现的紧急险情应立即启动相应的应急处置程序：

1. **一般险情**：现场安全员先行处置，同步报告项目部。
2. **较大险情**：立即停工撤出人员，启动预案中的二级响应程序。
3. **重大险情**：立即启动一级响应程序，向上级主管部门报告，同时组织抢救。

具体应急处置流程、组织架构、响应级别划分及各项事故的处置措施详见《安全生产应急预案》。
