# 双流机场东消防站维修工程文明施工与环境保护专项方案

## 一、编制目的

为有效规范双流机场东消防站维修工程施工现场的文明施工行为，严格控制施工过程中产生的扬尘、噪声、固体废弃物及水污染，杜绝物料乱堆乱放和现场脏乱差现象，保护周边自然环境与景观风貌，特制定本文明施工与环境保护专项方案。

## 二、施工现场围挡与形象标准

### 2.1 全封闭打围设置

本项目采用轻钢龙骨彩钢板对施工区域进行全封闭硬隔离，具体要求如下：

| 控制要素 | 标准要求 |
|---------|---------|
| **围挡高度** | 全封闭打围高度2.5m，确保人员与车辆无法随意穿行 |
| **打围长度** | 约36m，四周与施工区域边界距离控制在1.2m以内 |
| **框架材质** | 75型轻钢龙骨或40mm镀锌矩管，骨架连接牢固，抗风防倒伏 |
| **面板材质** | 厚度12mm彩钢板，外立面平整美观，无尖锐物凸出伤人隐患 |
| **稳固性要求** | 地基夯实固定，防止大风暴雨导致坍塌，且不得阻碍旁边人行道正常通行 |

#### 围挡信息栏与安全标识

围挡入口一侧离地1.7m高处统一设置喷涂或粘贴式的施工信息栏与安全警示标志：

1. **信息公示**：项目名称、施工单位全称、施工主要内容，以及施工现场负责人姓名。
2. **安全警示**：“施工中，请勿靠近”、“必须佩戴安全帽”、“闲人免进”、“注意安全”等中英文双语标语。
3. **风险管控公示**：张贴《施工项目风险控制表》，明确本区域重大及较大危险源清单。

## 三、材料仓库与加工区部署

为尽量减少现场加工带来的粉尘与废料污染，本工程所有材料及半成品尽量在集中加工库房内完成预加工。现场设立标准化材料仓库，具体要求如下：

1. **堆放整齐原则**：所有进场材料必须分类分区码放，挂设标牌注明名称、规格、产地及检验状态。
2. **防潮垫层处理**：板材、袋装水泥、石膏腻子等易受潮材料在库房内堆放时，地面采用100mm高木方做防潮基础，木方之上铺设木工板，严禁材料直接接触泥地。
3. **零星材料货架化**：小型五金配件、辅材设置金属货架分层摆放，避免散落在地难以清理。
4. **危险品专库管理**：油漆、稀释剂等易燃易爆化学品单独设置禁火库房，配置沙箱、干粉灭火器和明显的“严禁烟火”标志。

## 四、扬尘防治与大气污染防治措施

1. **人工清表优先**：场地杂草清除、腐殖土翻挖、旧墙体破碎一律采用人工或小微型电动工具作业，禁止使用高压气枪吹扫浮灰，防止粉尘弥漫。
2. **土方作业湿法管控**：沟槽土方开挖及回填夯实期间，安排专人适时洒水湿润作业面，抑制起尘；裸露土方及时覆盖密目网或土工布。
3. **建筑垃圾封闭清运**：拆除产生的碎砖渣石、混凝土块须装袋密封后统一外运，运输途中采用篷布遮盖防止沿途遗撒。
4. **切割降噪防尘**：墙面砂浆铲除及地砖切割尽量安排在通风良好的开放面，配备移动式雾炮机同步喷雾降尘。

## 五、噪声控制与振动防护措施

1. **限时作业规定**：严格遵循每日8:00-18:00的作业时段限制，中午午休时间暂停电镐敲击等高噪施工作业。
2. **设备选用低噪型**：优先选用带隔音罩的低噪空压机、振动棒等机械设备；切割机加装减震胶垫以降低机身共振。
3. **吊装平稳操作**：预制沟盖板吊装作业时由专职信号工统一指挥，缓慢起降，减少钢丝绳摆动撞击构件产生的刺耳尖啸声。
4. **防振隔声屏障**：对于贴近既有建筑的部位进行打孔植筋作业时，提前在临建侧搭设简易隔音棚，避免振动波过度传导至建筑物主体。

## 六、水污染防治与环境卫生管理

1. **泥浆沉淀排放**：现场搅拌砌筑砂浆及抹灰所溢出的废浆水，统一导入三级沉淀池沉淀净化后方可排入市政管网，严禁直排雨水篦子堵塞下水道。
2. **轮胎冲洗设施**：在施工出入口硬化道路上设置简易洗车槽或配备高压水枪，运输车辆离场前必须冲洗干净轮胎附着泥土，杜绝污染场内道路。
3. **生活卫生保洁**：施工现场配备移动式环保厕所，指定专职保洁人员每日定时打扫冲刷，保证无异味散发；生活垃圾投放于带盖垃圾桶内实行日产日清。

## 七、消防安全与应急配套部署

| 适用区域 | 消防器材配置标准 | 附加管理要求 |
|---------|----------------|-------------|
| **施工作业区** | 每50㎡或每15米半径内配备不少于两具3A级5kg干粉灭火器（本次约36㎡配置2具） | 禁止吸烟，三级配电箱旁悬挂操作规程，落实巡检记录 |
| **材料库房** | 每15㎡设置2具3A级5kg干粉灭火器 | 醒目张贴“严禁烟火”标志，易燃涂料独立存放，实行双人双锁制度 |
| **临时动火点** | 作业点配备2具4A级8kg干粉灭火器 | 动火前办理审批手续，派专人协同看管监护，完毕后留守观察30分钟 |

## 八、文明施工监督考核机制

1. **值班巡检制度**：项目部建立全天候值班巡查组，重点检查围挡完整性、物料归类情况、垃圾清运频次及消防通道畅通状况。
2. **违规惩处条例**：现场发现随地大小便、乱丢烟头、材料未垫防潮板擅自落地等现象，一经发现立即勒令停工整改并对责任人处以经济处罚。
3. **动态维护要求**：施工完毕后若有不慎损坏围挡或污损公共地坪的部位，必须在24小时内修复恢复原貌，经监理验收合格方可视为完工移交。
