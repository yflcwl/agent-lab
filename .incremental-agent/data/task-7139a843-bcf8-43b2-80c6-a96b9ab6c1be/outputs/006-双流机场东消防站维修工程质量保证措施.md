# 双流机场东消防站维修工程质量保证措施

## 一、质量目标

本工程质量管理目标为：所有分部分项工程质量一次性验收合格，实体检评抽检合格率100%，确保工程检查验收一次通过。各分部工程质量标准如下：

| 分部工程 | 质量标准 | 验收要求 |
|---------|---------|---------|
| 挡土墙修复工程 | 合格 | 砌体砂浆饱满度≥80%，混凝土强度等级符合设计要求 |
| 外墙翻新工程 | 合格 | 抹灰无空鼓开裂，真石漆色泽均匀，防水层无渗漏 |
| 天棚及墙面翻新工程 | 合格 | 乳胶漆涂装平整无流挂，石膏板吊顶牢固顺直 |
| 车库环氧地面工程 | 合格 | 固化地坪研磨遍数达标，表面平整光洁 |
| 卫生间翻新工程 | 合格 | 防水闭水试验合格，排水坡度准确无积水 |

## 二、质量管理制度

### 2.1 质量控制原则

1. 所有进场的材料（含辅材）必须符合设计要求和相关质量标准，严禁使用不合格材料。
2. 在施工人员进场前做好技术教育，并在施工中确定专职质量员，落实质量检查措施。
3. 施工前对施工人员进行施工技术交底，严格工程工序管理，注重落实，奖罚分明。
4. 施工前必须在基层面满足要求才能施工，上道工序经验收合格后方可进入下道工序。
5. 特别是针对改造翻新对施工质量的影响，在施工过程中出现的技术问题要及时处理。
6. 加强对特殊部位的施工控制，认真执行自检、互检、交接检及工序检查等制度。以确保工程检查验收一次通过。
7. 制定值班和巡检制度，施工现场发现有不慎损坏的部位，要及时标识并立即通知相关值班施工人员进行修补。施工完毕后应有专人检查修补情况并做记录。
8. 施工完毕后施行动态监控，应及时进行修补。
9. 应避免移动重型机械设备，尽可能避免交叉作业以防其他人员破坏，注意成品保护措施。
10. 按照施工方案的要求作业，严格按图施工不得擅自变更。

### 2.2 三检制执行情况

| 检查类型 | 执行人 | 检查要点 | 记录要求 |
|---------|--------|---------|---------|
| 自检 | 作业班组 | 每道工序完成后自行检查，确认符合技术要求 | 填写自检记录表 |
| 互检 | 相邻班组/质检员 | 不同班组之间相互检验交接面质量 | 填写互检记录表 |
| 交接检 | 质检工程师 | 上道工序验收合格后签署交接确认单 | 填写交接检验记录 |

## 三、砖砌体工程检验批质量验收

### 3.1 主控项目

#### 3.1.1 砖和砂浆强度等级

- **标准要求**：砖和砂浆的强度等级必须符合设计要求。
- **抽检数量**：每一生产厂家，烧结普通砖、混凝土实心砖每15万块为一验收批，不足上述数量时按1批计；抽检数量为1组。
- **检验方法**：查砖和砂浆试块试验报告。

#### 3.1.2 砌体灰缝砂浆密实饱满度

- **标准要求**：
  - 砖墙水平灰缝的砂浆饱满度不得低于80%。
  - 砖柱水平灰缝和竖向灰缝饱满度不得低于90%。
- **抽检数量**：每检验批抽查不应少于5处。
- **检验方法**：用百格网检查砖底面与砂浆的粘结痕迹面积，每处检测3块砖取平均值。

#### 3.1.3 转角处和交接处同时砌筑

- **标准要求**：砖砌体的转角处和交接处应同时砌筑，严禁无可靠措施的内外墙分砌施工。在抗震设防烈度为8度及8度以上地区，对不能同时砌筑而又必须留置的临时间断处应砌成斜槎：
  - 普通砖砌体斜槎水平投影长度不应小于高度的2/3。
  - 多孔砖砌体的斜槎长高比不应小于1/2。
  - 斜槎高度不得超过一步脚手架的高度。
- **抽检数量**：每检验批抽查不应少于5处。
- **检验方法**：观察检查。

#### 3.1.4 临时间断处留槎处理

- **标准要求**：非抗震设防及抗震设防烈度为6度、7度地区的临时间断处当不能留斜槎时，除转角处外可留直槎但必须做成凸槎且应加设拉结钢筋：
  - 每120mm墙厚放置1Φ6拉结钢筋（120mm厚墙应放置2Φ6拉结钢筋）。
  - 间距沿墙高不应超过500mm，且竖向间距偏差不应超过100mm。
  - 埋入长度从留槎处算起每边均不应小于500mm，对抗震设防烈度6度、7度的地区不应小于1000mm。
- **抽检数量**：每检验批抽查不应少于5处。
- **检验方法**：观察和尺量检查。

### 3.2 一般项目

#### 3.2.1 砖砌体组砌方法

- **标准要求**：组砌方法应正确，内外搭砌上、下错缝。清水墙、窗间墙无通缝，混水墙中不得有长度大于300mm的通缝，长度200mm~300mm的通缝每间不超过3处且不得位于同一面墙体上，砖柱不得采用包心砌法。
- **抽检数量**：每检验批抽查不应少于5处。
- **检验方法**：观察检查。砌体组砌方法抽检每处应3m~5m。

#### 3.2.2 灰缝厚度均匀

- **标准要求**：灰缝应横平竖直，厚薄均匀。水平灰缝厚度及竖向灰缝宽度宜为10mm，但不应小于8mm也不应大于12mm。
- **抽检数量**：每检验批抽查不应少于5处。
- **检验方法**：水平灰缝厚度用尺量10皮砖砌体高度折算，竖向灰缝宽度用尺量2m砌体长度折算。

#### 3.2.3 尺寸位置允许偏差

- **标准要求**：砖砌体尺寸、位置的允许偏差应符合规范要求。
- **检验方法**：按规范标准逐项测量检查。

## 四、各分部工程质量控制要点

| 回填土压实度 | 分层夯实，每层厚度不大于300mm，压实度满足要求 | 环刀法取样测试 |

## 五、成品保护措施

### 5.1 各工序成品保护要求

1. **挡土墙砌体**：砌筑完成后及时覆盖养护，避免碰撞受损；养护期间禁止踩踏和堆载。
2. **环氧固化地坪**：养护期间封闭施工区域，设置警示标识，防止人员和车辆进入造成划伤污染。
3. **室内墙面涂料**：涂料施工过程中不得开窗通风导致干燥过快产生裂缝；涂刷完成后关闭门窗自然阴干。
4. **卫生间防水层**：防水层施工完成并通过闭水试验后，立即可铺设水泥砂浆保护层，后续瓷砖铺贴过程注意保护防水层不被破坏。
5. **铝塑板幕墙**：安装完成后撕去保护膜，防止阳光暴晒导致胶条老化；清洁时使用中性清洁剂不得用腐蚀性溶剂。
6. **不锈钢护栏利旧安装**：搬运和安装过程中采取软质隔离包裹措施，防止变形和表面划伤。

### 5.2 交叉作业协调措施

1. 合理安排施工顺序，尽量避免垂直方向上的交叉作业。
2. 确实无法避免交叉作业时，下层作业须搭设防护棚或遮挡措施。
3. 各工序之间做好交接检验手续，发现成品受损由责任方负责修补并承担费用。
4. 贵重材料和易损成品堆放于专用库房或指定安全区域，设专人看管。

## 六、质量验收程序

### 6.1 验收组织

| 验收阶段 | 参与单位 | 验收内容 |
|---------|---------|---------|
| 材料进场验收 | 施工单位、监理单位 | 材料规格型号、合格证、检测报告 |
| 隐蔽工程验收 | 施工单位、监理单位、建设单位 | 基底处理、钢筋绑扎、管线敷设、防水层 |
| 检验批验收 | 施工单位、监理单位 | 各分项工程的实测实量数据 |
| 分项工程验收 | 施工单位、监理单位、建设单位 | 整体工程质量评估 |
| 竣工验收 | 建设、施工、监理、设计等单位 | 全面验收、功能性测试、资料移交 |

### 6.2 验收流程

1. **报验申请**：施工单位在完成一个检验批或分项工程后提交验收申请表。
2. **现场检查**：监理（建设）单位组织相关人员到施工现场进行现场检验。
3. **实测实量**：按规范规定的抽样方法和数量进行检测。
4. **结果判定**：根据检测结果判定是否合格，对不合格项提出整改要求。
5. **复验确认**：整改完成后重新组织验收直至合格。
6. **签字确认**：各方验收合格后签署验收文件归档保存。
