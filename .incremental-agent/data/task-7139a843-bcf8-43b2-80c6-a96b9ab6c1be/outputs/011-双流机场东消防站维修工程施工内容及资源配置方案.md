# 双流机场东消防站维修工程施工内容及资源配置方案

## 一、工程概述与施工范围

本项目为双流机场东消防站整体修缮改造工程，地点紧邻110kV羊航线1#杆塔区域。由于项目地处受限场地内且临近高压设施与既有建筑主体，施工环境复杂、工序交错密集。总体施工内容包括四大板块：

### 1.1 外墙翻新工程
主要对室外立面进行剥离刷新及局部改造，涉及保温层拆除、旧砂浆面铲除、新做抹灰及防水涂层喷涂。同时涵盖屋面挑檐部位的聚合物丙烯酸防水涂料涂刷，以及金属门窗翻新补漆、铝塑板幕墙骨架加固安装等工作量。

### 1.2 天棚及墙面翻新工程
针对室内顶棚及四面墙壁实施全面翻新处理。包含原乳胶漆饰面剥离、混合水泥砂浆面铲除找平后重新批刮腻子并涂装底面乳胶漆，此外还包括玻璃防爆膜粘贴及少量新墙体抹灰作业。

### 1.3 车库环氧地面翻新工程
对内部地坪进行全面破除重建。原有环氧层铲除清理后，在破损部位重浇C30细石混凝土结构层；随后采用机械研磨渗透工艺施工密封固化剂地坪，恢复其耐磨耐压性能。

### 1.4 二楼卫生间综合翻新工程
属于隐蔽管线改造的重点区域，重点解决楼面与墙面的二次防水涂布防漏问题。涉及旧有地砖及瓷砖全部起除、PPR给水暗管铺设打压检测、洁具设备及灯具保护性利旧拆装安装等环节。

## 二、施工组织管理体系与人员配置

为确保各施工环节有序衔接并能保质保量推进，项目部下设专业班组协同运转，实行项目经理负责制下的统筹调度机制。具体管理及作业人员安排如下：

### 2.1 项目管理组织表

| 序号 | 职务 | 岗位职责说明 |
|:---:|------|-------------|
| 1 | 项目经理 | 统筹安排施工事宜，协调内外关系，对工程进度质量安全负总责 |
| 2 | 生产经理 | 现场组织和管理工作，调度人力物力资源，确保每日产值目标达成 |
| 3 | 技术负责人 | 编制相关施工方案并进行三级安全技术交底，解决技术难题 |
| 4 | 安全负责人 | 进行日常隐患排查治理，监督安全制度落实，确保安全零事故 |
| 5 | 施工员 | 落实施工方案，协调交叉作业冲突，把控细部节点实施质量 |
| 6 | 班组长 | 监督、组织一线工人按图施工，传达管理层指令 |

### 2.2 一线作业队伍配置

根据本工程规模及工期要求，拟投入各类型专业人员形成流水线作业模式：

| 工种类别 | 人数 | 主要工作内容 |
|---------|------|------------|
| **泥工班** | 4人 | 基槽开挖、新旧墙体砌筑、内外墙抹灰找平、块料铺贴 |
| **木工班** | 4人 | 支拆各类钢模木模、预制盖板模具组装制作、吊顶龙骨架设 |
| **水电工班** | 6人 | PPR给排水管道热熔连接切割、电气照明线路敷设、电器设备安装调试 |
| **安装工** | 8人 | 外立面龙骨安装、金属门窗框架固定、护栏保护性修复利旧 |
| **混凝土工** | 5人 | 浇筑振捣养护、沟槽排水井砌筑、地面收光压纹平整度控制 |
| **拆除搬运班** | 若干 | 垃圾清运装车、废旧材料分类拆解堆放、重型器械辅助搬运移动 |
