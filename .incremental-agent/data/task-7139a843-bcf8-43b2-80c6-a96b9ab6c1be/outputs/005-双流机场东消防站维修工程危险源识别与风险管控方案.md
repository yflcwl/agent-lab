# 双流机场东消防站维修工程危险源识别与风险管控方案

## 一、编制目的

为有效识别和评估双流机场东消防站维修工程施工过程中存在的各类危险源，科学分析风险等级，制定针对性控制措施，建立健全安全风险分级管控机制，防止生产安全事故发生，保障施工人员的生命安全和身体健康，特制定本危险源识别与风险管控方案。

## 二、危险源辨识与评价方法

本工程采用LEC评价法进行风险等级划分，公式为：D = L × E × C

| 参数 | 分值含义 |
|------|---------|
| L（事故发生的可能性） | 10—完全可以预料；6—相当可能；3—可能，但不经常；1—可能性小，完全意外；0.5—很不可能，可以设想；0.2—极不可能；0.1—实际不可能 |
| E（人员暴露的频繁程度） | 10—连续暴露；6—每天工作时间内暴露；3—每周一次或偶尔暴露；2—每月一次暴露；1—每年几次暴露；0.5—非常罕见暴露 |
| C（事故后果的严重性） | 100—10人以上死亡或50人以上重伤或直接经济损失5000万以上；40—3人以上10人以下死亡或10人以上50人以下重伤或直接经济损失1000万以上；15—3人以下死亡或10人以下重伤或直接经济损失100万以上；7—丧失劳动力、截肢、骨折、听力丧失、慢性病或直接经济损失10万以上；3—轻微受伤、间歇不舒服或直接经济损失1万以上；1—无伤亡，直接经济损失1万以下 |

**风险等级划分标准：**
- **重大风险**：D≥320，由公司级管控。
- **较大风险**：160≤D<320，由项目部级管控。
- **一般风险**：D<160，由项目部级或班组级管控。

## 六、风险管控措施总结

### 6.1 组织管控措施

1. **公司级管控**：施工方案编审风险，由项目部负责编制施工方案并组织技术负责人、专业工程师等审核，开工前报公司审批。
2. **项目部级管控**：各施工作业活动的风险管控由项目部安全管理人员负责，实施每日巡查和重点监督。
3. **班组级管控**：一线作业人员严格执行操作规程，发现隐患立即报告班组长或安全员。

### 6.2 技术管控措施

1. **临电管理**：采用TN-S接零保护系统，三级配电两级保护，做到"一机一闸一漏一箱"。
2. **动火管理**：严格执行动火作业审批制度，清除动火点周围10m内可燃物，配置灭火器材并安排专人监护。
3. **管线保护**：施工前完成地下管线排障，沿原有挡土墙边线人工开挖探沟（长36m×宽0.8m×深1m），确认无管线后方可施工。
4. **高处作业管理**：搭设符合规范的脚手架，验收合格后投入使用，作业人员正确佩戴安全带。
5. **有限空间管理**：地下室、管沟等有限空间作业前强制通风，检测气体浓度合格后方可进入。

### 6.3 应急管理措施

1. 建立风险超标/管控失效的停工预警制度，发现重大隐患立即停工整改。
2. 发生事故响应须立即撤离危险区并逐级上报，严禁瞒报、漏报、迟报。
3. 定期组织应急演练，提高全员应急处置能力。
