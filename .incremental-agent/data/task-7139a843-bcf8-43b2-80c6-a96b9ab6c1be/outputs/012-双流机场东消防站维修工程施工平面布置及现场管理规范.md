# 双流机场东消防站维修工程施工平面布置及现场管理规范

## 一、施工现场围挡设置方案

### 1.1 打围原则与区域划分

本项目属于既有建筑修缮改造性质，场地紧邻110kV羊航线1#杆塔，周边环境复杂敏感。为确保施工期间不影响周边正常运行秩序并保障作业人员安全，必须采取封闭式硬隔离措施：

| 控制要素 | 标准要求 |
|---------|---------|
| **打围高度** | 全封闭打围高度2.5m，确保人员与车辆无法随意穿行 |
| **打围长度** | 约36m，四周与施工区域边界距离控制在1.2m以内 |
| **框架材质** | 75型轻钢龙骨或40mm镀锌矩管，骨架连接牢固，抗风防倒伏 |
| **面板材质** | 厚度12mm彩钢板，外立面平整美观，无尖锐物凸出伤人隐患 |
| **稳固性要求** | 地基夯实固定，防止大风暴雨导致坍塌，且不得阻碍旁边人行道正常通行 |

### 1.2 围挡信息栏与安全标识

施工信息栏集中设置于围挡入口一侧、离地高度1.7m处，采用喷涂或粘贴形式展示以下内容：

1. **基本信息公示**：项目名称、施工单位全称、施工主要内容，以及施工现场负责人姓名和联系电话。
2. **安全风险管控**：张贴《施工项目风险控制表》，明确本区域重大及较大危险源清单。
3. **安全警示标语**（中英文双语）：
   - "施工中，请勿靠近"（Under Construction, Do Not Approach）
   - "必须佩戴安全帽"（Safety Helmet Required）
   - "闲人免进"（Restricted Area）
   - "注意安全"（Caution: Safety First）

### 1.3 围挡外观维护要求

每日安排专人巡查围挡表面洁净度，发现污损、褪色或标识脱落须及时修补重绘；围挡外侧不得悬挂任何非审批物品或擅自张贴广告海报。

## 二、材料仓库与加工区部署

为尽量减少现场加工带来的粉尘与废料污染，本工程所有材料及半成品尽量在集中加工库房内完成预加工。现场设立标准化材料仓库，具体要求如下：

### 2.1 材料堆放管理规定

| 材料类别 | 存放方式 | 特殊防护要求 |
|---------|---------|------------|
| **板材类**（石膏板、木工板等） | 地面铺设100mm高木方基础，其上再铺木工板 | 严禁直接接触泥地受潮变形 |
| **袋装粉体**（水泥、腻子等） | 入库储存或搭建防雨防尘棚架 | 分层码放不超过10层，底层垫木板防潮 |
| **零星辅材**（五金配件、密封胶等） | 金属货架分层摆放，标签清晰可见 | 按规格型号分类标识，方便取用盘点 |
| **危险化学品**（油漆、稀释剂等） | 独立禁火库房单独存放，实行双人双锁管理制度 | 墙面防渗处理，配备沙箱和干粉灭火器 |

### 2.2 工具房管理要求

所有小型机具使用后统一归位至工具房内存放，做到定置管理、账物相符。易燃易爆物品严禁留在施工面上过夜，必须当日退场时一并带离飞行区并向道口执勤人员申报核销。

## 三、地下管线保护与探沟开挖技术

### 3.1 管线确认与排障程序

施工前，组织相关管线产权单位对施工区域、挡土墙开挖范围现有地下管线进行管线确认及排障作业，并对拆除开挖区域进行探沟开挖，探坑深度不得小于需求深度，进一步探明管线走向及埋深，指派专人全程指挥、跟进，确保施工按管线保护要求实施，确保拆除开挖作业不损坏已有管线正常运行，做好标记，严禁机械开挖破坏管线。

### 3.2 人工探沟开挖技术要求

本次探沟采用挖探永临结合的方式，沿现有挡土墙边线人工开挖探沟，具体参数如下：

| 工序步骤 | 操作要点 | 控制指标 |
|---------|---------|---------|
| **总体尺寸** | 探沟开挖总长36米，宽0.8米，深1米 | 沿挡土墙轴线方向延伸贯穿全场 |
| **开挖方式** | 纯人工手持工具挖掘，禁用十字镐、钢钎强行破岩 | 避免冲击振动损伤邻近既有管线 |
| **过程监护** | 专人守护盯防，发现异常立即停止作业 | 保持与管线产权单位通讯畅通 |
| **管线识别** | 轻轻扩宽范围，探明管线的种类、规格、根数、走向和深度并作标记，影像留底和书面作记录 | 经监管人员进行二次确认 |

### 3.3 管线保护措施

若开挖过程中发现未知管线：
1. 立即停止该区域全部施工作业；
2. 组织相关单位再次到现场确认是否为在用管线；
3. 若确属在用管线，按要求采取包裹、支托防护措施后方可继续施工；
4. 通知产权单位对管线进行二次确认，签署书面保护协议。

## 四、现场临时用电管理系统

### 4.1 配电箱配置标准

施工现场临时用电系统必须安装漏电保护器，做到"一机一闸一漏一箱"原则。各级配电箱应满足以下基本要求：

- **一级配电箱**（总配电柜）：位于供电入口处，容量满足全場峰值负荷需求，内设总断路器和分流支路开关。
- **二级分配电箱**：分布于各主要作业面附近，便于就近接引动力电源。
- **三级开关箱**：每台用电设备专属配置，距被控设备水平距离≤3m，垂直高差≤0.5m。

### 4.2 电缆敷设规范

1. 电缆架空敷设或穿管保护，严禁碾压、拖拽、浸泡水中，穿越通道采取防破损措施。
2. 配电箱上锁管理，防雨、防潮、防尘，非专业人员严禁操作。
3. 移动电器使用绝缘完好的软橡胶电缆，接头处采用防水接线盒密封。
4. 严禁带电接线、拆线、检修，停电作业执行"停电—验电—挂牌—上锁"制度。

### 4.3 安全电压应用

在潮湿环境、受限空间等危险区域使用安全电压供电（≤36V，特别潮湿场所≤12V），由变压器降压转换提供，二次侧不设接地以确保人身安全保障。
