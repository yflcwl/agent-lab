# 第四章 施工组织部署

## 一、施工管理组织架构

本工程实行项目负责人制管理，建立以项目经理为核心的层级化管理体系，确保施工组织高效有序推进。项目管理组织机构及各岗位职责如下：

| 职务 | 职责 |
|------|------|
| **项目经理** | 统筹安排施工事宜，对工程进度、质量、安全和成本进行全面负责，协调业主方、监理方及参建各方关系 |
| **生产经理** | 负责现场组织和管理工作，统筹各工种间交叉作业协调、现场调度、安全生产督促及日常施工管理 |
| **技术负责人** | 编制相关专项施工方案和技术措施，组织技术交底和图纸会审，解决施工中遇到的技术难题和质量问题 |
| **安全负责人** | 进行安全隐患排查治理，落实安全教育培训和安全技术交底制度，监督施工现场安全防护措施到位，确保施工全过程安全可控 |
| **施工员** | 落实施工方案和技术要求，协调处理现场各工种间的配合事宜，跟踪检查施工质量和进度 |
| **班组长** | 监督和指挥现场工人按规范和工艺要求进行施工，做好班组内部安全管理和质量监督，及时上报异常情况 |

### （一）应急管理组织架构

为保障突发安全事故的有效应对，本项目同时设立应急救援领导小组：

- **组长**：项目经理（全面领导应急工作）
- **副组长**：生产经理、技术负责人、安全负责人
- **抢险救援组**：由施工员带领一线施工人员组成，负责事故现场的紧急处置和抢险救援
- **医疗救护组**：负责伤员的临时救治和转运协调
- **后勤保障组**：负责应急物资供应、车辆调度和现场秩序维护
- **事故调查组**：由技术负责人牵头，负责对事故原因进行分析调查，提出整改防范措施

## 二、施工阶段划分

根据本次维修工程四大核心项目的工艺要求和相互之间的逻辑顺序，结合机场110kV羊航线杆塔旁作业环境的特殊限制，将工程施工划分为四个阶段有序推进：

### （一）第一阶段：施工准备与围挡搭设

主要工作内容：
- 办理机场控制区施工审批手续，完成进场备案和安全培训教育
- 施工打围，搭建2.5米高轻钢龙骨彩钢板全封闭围挡（长度约36米），设置出入口及安全警示标志
- 组织管线产权单位对施工区域进行地下管线现场确认，人工开挖探沟（总长36米、宽0.8米、深1米），查明既有管线分布情况并实施包裹支托防护
- 材料仓库及加工房布置于我司集中加工库房（非施工现场），减少现场加工作业量；易受潮材料（板材、水泥等）地面垫高100毫米木方+木工板隔潮存放，零星材料设置金属货架分类码放
- 施工入场前进行做法工艺及安全要点安全技术交底，施工人员由正式引领人员带入

### （二）第二阶段：拆除清理阶段

主要工作内容：
- 人工清表，清除施工区域内可回收废弃物及松散面层
- 外墙保温层铲除（1,361.78平方米）
- 外墙抹灰涂料层及原有真石漆拆除（1,789.62平方米）
- 外墙块料饰面拆除（约196.62平方米）
- 室内天棚涂料层铲除（4,902.38平方米）
- 卫生间原有防水层及块料饰面拆除
- 车库环氧地坪铲除（758.56平方米）
- 不锈钢护栏局部利旧拆除及门窗五金拆卸
- 拆除垃圾装车外运至指定消纳场地

**注意**：卫生间灯具、热水器及蹲便器部分器具需妥善拆卸后进行利旧保护安装，不得损坏；空调移机需联系专业人员进行制冷剂回收后拆卸。

### （三）第三阶段：土建与装饰施工阶段

主要工作内容（按工艺流水顺序）：

#### 1. 外墙翻新工程
- JS防水涂料Ⅱ型1.5毫米厚涂刷（1,789.62平方米）——作为真石漆基层防水
- 新做铝塑板幕墙（基层60×3镀锌矩管双层双向间距600mm骨架）
- 新做真石漆喷涂（水性封闭底漆一道→真石漆喷涂→罩面保护漆一道，1,789.62平方米）

#### 2. 天棚及室内墙面翻新工程
- 原有抹灰层裂缝修补、空鼓部位凿除重新批嵌
- 室内乳胶漆重涂（4,902.38平方米）——分两遍满刮腻子，一遍底漆，两遍面漆
- 卫生间区域JS防水涂料重做（201.56平方米，墙面1.8米高）
- 石膏板吊顶修复与新做（135.45平方米，规格600×600毫米）
- 卫生间及其他功能房间防爆膜贴覆

#### 3. 车库地面翻新工程
- C30混凝土坑洞局部浇筑修复（112立方米）
- 整体固化地坪施工（758.56平方米）——混凝土密封固化剂五次固化研磨加三次抛光后撒抛光剂

#### 4. 卫生间翻新工程
- 排水管道更换（100米）
- 防水层闭水试验合格后进下一步工序
- 块料饰面铺贴（157.72平方米）
- 器具利旧复位安装（灯具10套、热水器10台、蹲便器7组利旧）

#### 5. 附属配套工程
- 塑钢窗密封胶更换（288平方米）
- 金属门油漆翻新（106.20平方米）
- 空调系统移机及加氟补液
- 室内外排水管更换（182.40米）

### （四）第四阶段：收尾安装与竣工验收

主要工作内容：
- 成品保护措施落地（应避免移动重型机械设备，尽可能避免交叉作业以防成品破坏）
- 各分项工程质量自检、互检、专检
- 协助监理单位及建设单位进行中间验收
- 清理施工现场建筑垃圾，撤除施工围挡
- 整理竣工资料，移交建设单位

## 三、施工总体部署

### （一）施工原则

1. **安全第一、质量为本**：鉴于施工区域位于机场运营区内，紧邻110kV羊航线杆塔塔基，所有高空作业、有限空间作业和临时用电作业必须严格执行国家现行规范标准（GB 50300-2013、JGJ 46-2005等11项国标），杜绝各类安全事故发生。
2. **分段流水、穿插作业**：在保障施工安全和成品保护的前提下，合理组织各工种间穿插作业，提高施工效率。拆除完成后立即进入基础防水和新做饰面工序，形成连续流水作业。
3. **工厂预制、现场安装**：材料仓库及加工房设置在公司集中加工库房，尽量减少现场加工量和噪音粉尘污染；现场仅完成组装、拼接和固定作业。
4. **限时施工、降噪减排**：施工作业时段严格控制在每日8:00至18:00范围内，避开夜间施工扰民；拆除和切割等高噪声工序优先安排在白天允许时段内实施。

### （二）施工区域边界与安全管控

- 施工围挡与施工区域边界距离控制在1.2米以内，围挡入口处一侧距地1.7米位置张贴施工单位简介、工程名称、施工许可证号及安全标语
- 施工区域外围醒目处悬挂"施工重地 闲人免进""注意安全"等警示标志
- 围挡采用2.5米高全封闭轻钢龙骨彩钢板结构，确保施工区域与外界完全隔离

### （三）消防设施部署

| 区域 | 灭火器配置标准 | 数量/要求 |
|------|-------------|---------|
| 施工区域 | 每50㎡或每15米半径内不少于2具3A级5KG干粉灭火器 | 面积约36㎡配备2具以上 |
| 材料库房 | 每15㎡设2具3A级5KG干粉灭火器 | 门口悬挂"严禁烟火"标志 |
| 临时动火点 | 每动火点2具4A级8KG干粉灭火器 | 配备专职看火员 |

施工区域按规范要求配置三级配电箱，实行"一机一闸一漏一箱"制度。

## 五、施工准备工作安排

### （一）技术准备
- 组织项目部全体人员进行图纸会审，领会设计意图和施工技术要求
- 编制专项施工方案并报监理审批，重点针对外墙高空作业、卫生间防水施工、固化地坪施工工艺编制专项技术措施
- 对全体施工人员进行三级安全教育（公司级、项目部级、班组级）和安全技术交底
- 熟悉机场控制区施工管理规定和110kV高压线路安全防护要求

### （二）现场准备
- 施工打围全封闭完成，出入口设置专人值守
- 地下管线人工探挖确认完毕并实施防护措施
- 施工用水、用电接通至三级配电箱，满足施工需求
- 施工道路及材料运输通道勘察通畅

### （三）材料准备
- 真石漆品牌颜色待提交样品经业主确认后方可批量采购
- JS防水涂料Ⅱ型、聚氨酯防水涂料、混凝土密封固化剂等核心防水材料须从业主或设计单位推荐合格供应商名录中选择
- 铝塑板幕墙型材、石膏板等主要建材按计划分批进场，做好入库检验和存放保管
- 卫生间利旧器具（灯具、热水器、部分蹲便器）拆下后集中编号存放，防止丢失损坏

### （四）手续准备
- 向机场管理方办理施工进场审批手续
- 临近高压线路施工作业的安全方案报电力部门备案
- 涉及占道或影响机场正常运行区域的施工提前报备
