# 第六章 质量管理体系与保证措施

## 6.1 概述

本章围绕"确保工程检查验收一次通过"的总体质量目标，结合双流机场东消防站维修工程的具体特点，系统构建质量管理体系、质量责任制、质量控制程序和保障措施。本工程属于既有建筑改造翻新类型，施工质量不仅涉及新建部位的工艺质量，还大量涉及利旧设备安装、原有基层处理与新旧界面衔接等关键环节，因此质量控制体系需覆盖从材料进场到竣工验收的全生命周期管理。

本工程质量管理体系的建立和执行均以上述11项国家现行规范标准为依据，详见第一章编制依据列表。本章所规定的质量控制点、检验要求和验收程序不得随意降低或省略。

## 6.2 质量目标

### 6.2.1 总体目标

**工程检查验收一次通过。**

即在本工程全部施工内容完成后，由建设单位组织设计、监理和施工单位进行的竣工验收，一次性达到规范要求并签署合格验收意见。若验收中发现问题，须在整改复验前完成全部缺陷修补。

### 6.2.2 质量目标分解

将总体目标分解至各专业分项工程层面，形成可量化、可考核的分项质量指标：

| 分项工程类别 | 分项质量目标 | 检验方式 |
|-------------|------------|---------|
| 外墙翻新 | 真石漆色泽均匀、无接茬色差；防水层无渗漏痕迹 | 目测观察 + 淋水/蓄水试验 |
| 天棚及室内墙面翻新 | 乳胶漆面平整光滑、无色差流坠；石膏板吊顶牢固平整 | 靠尺测量 + 目测 |
| 车库地面翻新 | 固化地坪镜面光泽均匀、无起砂粉化；新浇C30强度达标 | 回弹仪抽检 + 目测 |
| 卫生间翻新 | 闭水试验24 h无渗漏；块料铺贴空鼓率≤3% | 闭水试验 + 空鼓锤检测 |
| 管道更换 | 水压试验压降≤0.05 MPa/h、接口无渗漏 | 压力表监测 |
| 排水管更换 | 灌水试验通球畅通、接口无渗漏 | 通球试验 + 灌水试验 |
| 空调移机加氟 | 制冷制热效果达标、冷凝水排放正常 | 试运行检测 |
| 利旧卫生洁具 | 蹲便器排污通畅、热水器绝缘电阻≥0.5 MΩ | 冲水试验 + 绝缘测试 |
| 铝塑板幕墙 | 骨架牢固、板块接缝严密、耐候胶饱满顺直 | 拉拔试验 + 目测 |
| 金属门油漆翻新 | 防锈彻底、漆膜均匀无流挂 | 目测 + 附着力测试 |
| 塑钢窗打胶密封 | 胶缝连续饱满、无气泡断点 | 目测 |

> **说明**：上述分项质量目标中未明确量化参数的项目（如真石漆粘砂率、聚氨酯防水涂料延伸率等），其检测项目和限值参照对应国家标准的通用检验规则执行。

## 6.4 质量管理基本制度

### 6.4.1 三检制度

严格执行**自检、互检、交接检**制度，每道工序完成后须按以下顺序进行检查：

1. **自检**：操作班组在完成本道工序后，由班组长组织全员进行自检。自检合格后填写自检记录表，报施工员和专职质量员复查。自检重点包括：尺寸偏差、外观质量、工艺符合性等方面。

2. **互检**：相邻班组之间或同工种不同班组之间进行互相检查。例如外墙抹灰完成后，下一道防水工序班组可对基层平整度进行互检确认；室内乳胶漆涂装班组可对腻子基层的干燥程度和平整度进行互检。

3. **交接检**：上道工序完工并经自检和互检合格后，由施工员组织下道工序班组进行现场交接检查。双方共同确认上道工序质量状态，签字后方可进入下道工序施工。对不符合要求的部位，上道工序班组须返修直至合格。

**交接检关键节点清单：**

| 交接检节点 | 上道工序 → 下道工序 | 核心检查内容 |
|-----------|-------------------|------------|
| 外墙基层 → JS防水层 | 抹灰层/涂层拆除 + 基层找平 | 基层含水率≤8%、无松动浮灰、阴阳角圆弧过渡 |
| JS防水层 → 薄抹面层 | 涂膜干燥固化 | 厚度≥1.5 mm、无漏涂起泡 |
| 薄抹面层 → 真石漆底漆 | 抗裂砂浆网格布层 | 平整度≤3 mm/2m、完全干燥 |
| 屋面找平层 → 聚氨酯防水 | 水泥砂浆找平层 | 无空壳起砂、干燥、坡度正确 |
| 防水层 → 保护层/贴砖 | 防水闭水试验 | 24 h闭水无渗漏、闭水记录完整 |
| 腻子层 → 乳胶漆 | 三遍腻子打磨完毕 | 表面平滑无砂痕、粉尘清理干净 |
| C30混凝土 → 固化地坪 | 新浇混凝土养护期满 | 强度达标、表面无起砂开裂 |
| 管道安装 → 隐蔽封槽 | 水压试验合格 | 0.6 MPa稳压1 h压降≤0.05 MPa |
| 块料铺贴 → 勾缝养护 | 瓷砖粘贴完毕 | 空鼓率≤3%、缝隙宽度一致 |

### 6.4.2 技术交底制度

- 施工前由技术负责人向全体施工人员作**施工组织设计层面的总交底**，明确工程整体质量标准、关键工序要求、质量目标分解等内容。
- 各分项工程施工前由专业工长或施工员向作业班组进行**分部分项工程技术交底**，以书面形式下发交底记录，内容包括：施工步骤、操作要点、质量验收标准、安全注意事项等。
- 交底须履行签字手续，接受交底的作业人员本人签字确认。未接受交底的人员不得上岗作业。
- 对于新材料、新工艺（如固化地坪的五次研磨工艺），由技术负责人专门编制专项交底文件。

### 6.4.3 值班和巡检制度

- 施工现场安排专人值班，每日对已施工部位进行质量巡检。
- 发现有不慎损坏的部位，要及时标识并立即通知相关值班施工人员进行修补。
- 施工完毕后，应有专人检查修补情况，并做记录。
- 施行动态监控机制，对关键工序全程跟踪监督，及时发现并纠正偏差。

### 6.4.4 奖罚制度

- 对施工质量优良、达到或超出质量目标的班组和个人给予经济奖励。
- 对违反施工工艺要求、造成质量缺陷或返工的，追究相关责任人和班组的赔偿责任，并进行相应的经济处罚。
- 奖罚细则在施工前由项目管理团队制定并发放至各班组。

## 6.5 各分项工程质量控制要点

### 6.5.4 卫生间翻新工程质量控制

#### （1）JS防水涂料重做（地面1.5 mm / 墙面1.5 mm）

| 控制项目 | 控制要求 | 检验方法 |
|---------|---------|---------|

## 6.6 砖砌体工程专项质量控制（如涉及）

本工程涉及的少量砖砌体工程（工程量20 m²），其质量控制除遵循前述通用管理体系外，还须严格执行以下检验批质量控制要求：

### 6.6.1 主控项目

| 序号 | 控制要求 | 检验方法 |
|------|---------|---------|
| 1 | 砖和砂浆强度等级必须符合设计要求。抽检数量：每一生产厂家，烧结普通砖/混凝土实心砖每15万块为一验收批，烧结多孔砖/混凝土多孔砖/蒸压灰砂砖及蒸压粉煤灰砖每10万块为一验收批，不足上述数量时按1批计，抽检1组。 | 查砖和砂浆试块试验报告 |

### 6.6.2 一般项目

| 序号 | 控制要求 | 检验方法 |
|------|---------|---------|
| 1 | 清水墙、窗间墙无通缝；混水墙中不得有长度大于300 mm的通缝，长度200~300 mm的通缝每间不超过3处，且不得位于同一面墙体上。砖柱不得采用包心砌法。 | 观察检查 |

## 6.7 材料进场检验与复检管理

### 6.7.1 进场检验基本要求

所有进场的材料（含主材和辅材）须满足以下要求：

1. **证件齐全**：每批次材料必须有出厂合格证、质量证明文件和产品检测报告。
2. **现场抽样复检**：按规定进行现场抽样复检，复检合格的方可投入使用。复检不合格的须双倍取样复验，仍不合格的该批次材料一律退场。
3. **标识管理**：进场材料须按品种、规格、批次进行分类存放和标识，标识牌注明材料名称、规格型号、生产厂家、进场日期、复检状态等信息。

## 6.9 质量问题处理与闭环管理

### 6.9.1 质量问题分级

| 等级 | 定义 | 处理权限 |
|------|------|---------|
| **一般质量问题** | 不影响结构安全和主要使用功能，可通过返修消除缺陷的质量偏差 | 施工员/专职质量员现场处理 |
| **较重质量问题** | 可能影响使用功能或观感质量，需一定返工或技术处理的缺陷 | 技术负责人组织处理 |
| **重大质量问题** | 涉及结构安全或严重影响使用功能的缺陷 | 项目经理牵头，报建设单位和设计单位共同协商解决 |

### 6.9.2 质量问题处理流程

```
发现质量问题 → 记录并标识 → 分析原因 → 制定处理方案 → 实施整改 → 复查验收 → 记录归档
```

1. **发现与记录**：专职质量员或值班人员在巡检中发现质量问题，立即在现场做好标识并在质量检查台账中登记。
2. **原因分析**：由技术负责人牵头，会同相关班组和施工员分析质量问题产生的原因。
3. **方案制定**：根据问题性质和严重程度，由技术负责人编制返修或补强技术方案，必要时征求设计单位意见。
4. **整改实施**：指定专人负责整改工作，严格按技术方案执行。
5. **复查验收**：整改完成后由专职质量员复查，必要时组织相关方联合验收。
6. **记录归档**：全过程形成书面记录存入工程档案。

### 6.9.3 常见质量问题预防措施

| 常见问题 | 产生原因 | 预防对策 |
|---------|---------|---------|
| 真石漆色差 | 喷涂不均匀、接茬处理不当、天气环境影响 | 同一墙面连续施工；严格样板先行制度；避开大风雨天施工 |
| 外墙抹灰空鼓开裂 | 基层处理不净、分层厚度不当、养护不足 | 不同材料交接处挂钢丝网；严格控制分层厚度；充分养护 |
| 防水层渗漏 | 基层不平整、涂膜厚度不足、细部处理不到位 | 加强细部增强层；厚度逐段抽检；24 h闭水试验必做 |
| 地砖空鼓 | 粘结层不实、砖材未充分湿润、铺贴后未养护 | 干硬性砂浆充分揉压；砖材提前浸湿；闭水养护3 d |
| 固化地坪起砂 | 基层强度不足、固化剂涂刷不均、研磨不足 | 基层强度先检测；固化剂均匀泼洒保持湿润；严格按目数序列研磨 |
| 乳胶漆流坠 | 涂层过厚、稀释不当、环境湿度过大 | 薄涂多遍；严格按比例稀释；适宜温湿度条件下施工 |

## 6.11 本章小结

本章从质量目标设定、组织责任体系、基本管理制度、各分项工程质量控制要点、材料检验管理、成品保护、质量问题处理和质量资料管理等十个方面构建了本项目完整的质量管理体系。体系的核心特征是：以国家现行规范标准为法律依据、以"三检制度"为日常管控手段、以专职质量员和值班巡检为现场保障、以闭环管理为问题处置路径。各分项工程质量控制要点紧扣第5章施工工艺，确保每道工序有标准、每道关口有人管，从根本上保障"工程检查验收一次通过"的质量目标实现。
