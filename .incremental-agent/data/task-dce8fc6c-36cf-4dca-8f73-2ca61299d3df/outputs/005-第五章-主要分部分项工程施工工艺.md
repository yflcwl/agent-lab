# 第五章 主要分部分项工程施工工艺

## 5.1 编制说明

本章依据《双流机场东消防站维修工程项目清单》中各项分部分项工程的"项目特征"要求，以及第4章所述四阶段施工组织部署的整体顺序，逐项展开五大类维修工程的具体施工工艺和操作要点。

所有涉及品牌选型的材料（真石漆、JS防水涂料、混凝土密封固化剂、聚氨酯防水材料等），施工中须提交样品经业主或设计单位确认后大面积实施；真石漆的颜色亦需按业主需求事先确认。卫生间灯具、热水器为利旧安装而非更换新品，施工过程中须注意电气安全检测。

本章各分项工程的验收均以上述11项国家现行规范标准为依据，详见第一章编制依据列表。

## 5.2 外墙翻新施工工艺

### 5.2.1 保温层拆除

**工程范围：** 外墙聚苯乙烯泡沫塑料板保温层拆除，面积 1,361.78 m²。

**施工步骤：**
1. **搭设脚手架**：采用满堂扣件式钢管脚手架，作业面满铺脚手板并张挂密目安全网，同步在围挡外侧设置防护。脚手架经验收合格后方可投入使用。
2. **保温板剥离**：由上至下逐块铲除原有聚苯乙烯泡沫塑料板，严禁暴力撬拆以免损伤墙体基层。对已空鼓、粉化严重的保温层可采取机械辅助剥离。
3. **粘结层清除**：保温板拆除后，对残留于墙面的粘贴砂浆进行凿除清理，确保基层表面平整无松动物。
4. **垃圾清运**：拆除下的聚苯板及碎屑集中装袋，通过垂直运输通道运送至地面指定堆放区，日产日清。

**安全控制：** 高空作业人员须佩戴安全带、安全帽，风力达到五级及以上时停止高处拆除作业。

### 5.2.2 抹灰涂料层拆除

**工程范围：** 外立面抹灰及涂料层整体拆除，面积 1,789.62 m²。

**施工步骤：**
1. **基层检查**：利用铲刀和钢丝刷全面检查墙面抹灰层附着力，标记空鼓、脱落区域以便后续重点处理。
2. **涂层铲除**：对附着力差的原有涂料层和抹灰层整体铲除，使用电动铲墙机配合人工剔凿，自上而下分段推进。
3. **基层修复前处理**：铲除完成后用水冲洗墙面，检查结构基层是否有裂缝、孔洞；如有局部结构性损伤，及时记录并报监理确认修复方案。
4. **废料清运**：拆除废料分类打包运至场外堆放点，严禁从高空抛掷。

### 5.2.3 JS防水涂料Ⅱ型施工（1.5 mm 厚）

**适用范围：** 外墙防水涂膜，面积 1,789.62 m²。
**材料要求：** JS防水涂料Ⅱ型，配套增强网及抗裂防水砂浆（标准网格布，薄抹面层厚 4 mm）。

**施工步骤：**
1. **基层处理**：将拆除后的基层清理干净，用扫帚或吸尘器去除浮灰、油污；基层含水率控制在 8% 以内。对凹凸不平处采用水泥砂浆找平修补。
2. **细部增强**：在阴阳角、穿墙管根部、窗框周边等薄弱部位先做增强附加层，铺设标准网格布并涂刮一遍涂料。
3. **第一道涂膜**：将 JS 防水涂料均匀搅拌后，用橡胶刮板或滚筒在基层上薄涂一层，用量约 0.6～0.8 kg/m²，确保不露底。
4. **第二道涂膜**：第一道涂层表干（约 4～6 h，视气温而定）后进行第二道涂刮，方向与第一道垂直交叉，以确保覆盖均匀，总厚度达到 1.5 mm。
5. **薄抹面层**：防水层养护干燥后，在其表面涂抹抗裂砂浆并压入标准网格布，形成 4 mm 厚的薄抹面层，起到加强防水与保温复合体的作用。
6. **蓄水试验**：必要时对关键节点进行淋水或蓄水检验，确认无渗漏后进入下一道工序。

**质量检验：** 防水层厚度采用针刺法抽检，平均厚度不得小于设计值 1.5 mm，任一位置不得有低于设计值 85% 的薄弱点。

### 5.2.4 真石漆喷涂施工

**工程范围：** 外墙面真石漆，面积 1,789.62 m²。
**工序框架：** 界面剂 → 耐水腻子两道 → 水性封闭底漆一道 → 真石漆喷涂 → 罩面保护漆一道。

**施工步骤：**
1. **基面检查与修补**：薄抹面层完全干燥后，检查平整度并用靠尺测量，局部偏差超过 3 mm/2m 的区域重新批刮找平砂浆修补。
2. **涂刷界面剂**：在基层表面均匀滚涂界面剂一道，增强腻子和基层之间的粘结力。
3. **耐水腻子批刮（两道）**：选用成品腻子膏（耐水型），分两遍批刮，每遍厚度约 1～2 mm。第一遍腻子干燥后打磨修整，再进行第二遍批刮。最终表面应平整光滑、无砂眼和裂纹。
4. **喷涂水性封闭底漆**：腻子层完全干燥后（一般需 24 h），均匀喷涂水性封闭底漆一道，封固腻子层、均匀吸水率。
5. **弹线分格（如需）**：按设计要求进行弹线分格，粘贴美纹纸胶带做好分隔。
6. **真石漆喷涂**：使用专用喷枪进行真石漆喷涂，喷距 300～400 mm，气压稳定，匀速移动以保证色泽均匀、厚度一致。同一墙面须连续施工完成，避免接茬色差。真石漆颜色按业主确认的样品执行。
7. **撕除分格条 / 罩面漆**：真石漆表干后及时撕除美纹纸，涂刷罩面保护漆一道，形成防水、防污、抗紫外线保护层。

**成品保护：** 喷涂过程中注意遮挡相邻门窗框和构件，若沾染真石漆应立即用清水擦除。

### 5.2.5 铝塑板幕墙新做

**工程范围：** 带钢骨架铝塑板幕墙，工程量 88.32 m²。
**构造组成：** 60×3 镀锌矩管钢架（双向间距 600 mm）、4 厚 40 丝铝塑板（外墙耐候型）、耐候胶嵌缝密封。

**施工步骤：**
1. **测量放线**：根据设计图纸和建筑实际尺寸，在外墙面上弹出幕墙龙骨骨架的纵横控制线，包括水平标高线和竖向分格线。
2. **预埋件检查和补埋**：核对原结构预埋件位置和数量，缺失或偏移的预埋件须采用化学螺栓补埋，锚固深度满足规范要求。
3. **骨架安装**：
   - 焊接或螺栓连接竖向主龙骨（60×3 镀锌矩管），竖管间距不大于 1,200 mm。
   - 焊接或卡扣连接横向次龙骨（60×3 镀锌矩管），横管间距 600 mm（双向间距）。
   - 骨架焊接完成后，清除焊渣并按防锈要求涂刷两遍防锈漆。
   - 龙骨安装完毕后进行垂直度和平整度检查，误差控制在允许范围内。
4. **铝塑板安装**：
   - 按现场实测尺寸裁切铝塑板（4 mm 厚、40 μm 氟碳涂层），色面向外。
   - 采用外墙耐候结构胶将铝塑板粘贴固定在龙骨骨架上，同时使用不锈钢拉铆钉辅以固定，铆钉间距不大于 300 mm。
   - 板块之间预留 5～10 mm 缝隙用于嵌缝。
5. **嵌缝密封**：板块拼接缝采用塑料胶条背衬填充，外侧打注中性耐候硅酮密封胶，确保防水密封性能，胶缝应顺直、饱满、平整。
6. **颜色确认**：铝塑板的颜色和光泽度须按业主确认的样品执行。

## 5.3 天棚及室内墙面翻新施工工艺

### 5.3.1 室内涂料铲除

**工程范围：** 室内天棚及墙面涂料层拆除，面积 4,902.38 m²。

**施工步骤：**
1. **室内清空准备**：施工前将房间内的家具、设备搬迁至 unaffected 区域或移至其他楼层，地面及已有不需保留的装饰面做好覆盖保护。
2. **洒水湿润**：使用喷雾器向待铲除的天棚及墙面均匀喷洒清水，使原有涂料层充分吸水软化，静置 15～30 min。
3. **铲墙操作**：采用电动铲墙机或手工铲刀沿墙面从上至下、从左至右逐步铲除，对于附着力较强的区域可使用小锤轻击后再铲。铲除深度应至基层抹灰层为止。
4. **基层整修**：铲除完成后检查基层抹灰层的强度和空鼓情况，剔除空鼓部位，对蜂窝麻面、裂缝等进行修补。
5. **粉尘清理**：使用工业吸尘器对铲除后的墙面和天棚进行吸尘清理，保持无尘状态以备后续腻子施工。

### 5.3.2 墙面抹灰修补

**工程范围：** 内外墙一般抹灰修补，工程量 500 m²。
**材料参数：** 刷素水泥浆一遍（含胶水），干混抹灰砂浆，抹灰厚度 13 mm。

**施工步骤：**
1. **基层处理**：清扫墙面尘土，提前一天浇水润湿基层。对不同材料交接处（如混凝土墙与加气砌块交接处）铺设钢丝网，宽度不小于 200 mm，防止后期开裂。
2. **冲筋做饼**：根据修补部位的实际平整度要求，在墙面上做灰饼（markers）和冲筋（strip guides），作为抹灰厚度的控制标志，灰饼间距不大于 1.5 m。
3. **素水泥浆甩毛**：在抹灰前，墙面涂刷一遍掺胶水的素水泥浆作为粘结层，随刷随抹。
4. **分层抹灰**：
   - 底层抹灰：使用干混抹灰砂浆打底，厚度约 7～8 mm，用力压实保证与基层粘结牢固。
   - 中层抹灰：底层初凝后（约 6～12 h）进行中间层抹灰，继续找平。
   - 面层抹灰：最后一遍抹灰厚度约 3～5 mm，用刮杠和铁抹子收光，总厚度控制在 13 mm。
5. **养护**：抹灰层终凝后洒水养护不少于 7 d，防止砂浆收缩开裂。

### 5.3.3 石膏板吊顶新做

**工程范围：** 石膏板吊顶面层，面积 135.45 m²。
**材料规格：** 600×600 mm 石膏板，厚度同原有石膏板。

**施工步骤：**
1. **测量放线**：按设计标高在天棚上弹出吊顶顶棚标高控制线，在墙面上弹出龙骨分格线。
2. **吊杆安装**：在原结构楼板上钻孔植筋或采用膨胀螺栓固定吊杆（Φ8 圆钢），吊杆间距不大于 1,200 mm。吊杆长度可调，调整至设计标高后固定。
3. **主龙骨安装**：安装吊挂件和主龙骨（UC38 或 UC50 型），主龙骨间距不大于 1,200 mm，起拱高度按房间短跨的 1/200～1/300 设置。
4. **副龙骨安装**：在主龙骨下方安装副龙骨（UC24 型），副龙骨间距 600 mm，与主龙骨垂直布置，形成 600×600 mm 的方格网络。
5. **边龙骨安装**：沿墙面四周固定 L 形边龙骨，作为吊顶边缘的支撑。
6. **石膏板安装**：
   - 石膏板自重大于 3 kg/m² 时应增设附加吊杆。
   - 石膏板沿副龙骨方向铺设，板边应对准龙骨中心，使用自攻螺钉固定，钉头略嵌入板面但不破坏纸面，钉距 150～200 mm。
   - 两块石膏板之间预留 2～3 mm 伸缩缝，接缝处后续用嵌缝石膏和嵌缝带处理。
7. **接缝处理**：板缝间用嵌缝石膏填实，贴嵌缝纸带或纤维网格布，再做两遍腻子覆盖，打磨平整后涂刷面漆。

### 5.3.4 乳胶漆重涂

**工程范围：** 墙面天棚乳胶漆饰面，面积 4,902.38 m²。
**工序框架：** 界面剂一道 → 满刮成品腻子 → 底漆一遍 → 面漆两遍。

**施工步骤：**
1. **界面剂涂刷**：在基层表面均匀涂刷界面剂一道，增强腻子层附着力。
2. **满刮成品腻子（三遍）**：
   - 第一遍腻子：主要目的是找平基层缺陷，厚度可适当增大，干透后用砂纸打磨。
   - 第二遍腻子：进一步细化找平，消除第一遍留下的砂痕和不平整。
   - 第三遍腻子：精细修饰，要求表面极其平滑，无明显批刮痕迹。
   - 每遍腻子干燥后均需打磨一次，使用 200 目以上砂纸，打磨后彻底清扫浮灰。
3. **底漆涂刷**：腻子层完全干燥并经打磨清洁后，滚涂或喷涂底漆一遍，封闭腻子层孔隙、提高面漆附着力。
4. **面漆涂刷（两遍）**：
   - 第一遍面漆：底漆干燥后立即涂刷第一遍面漆，要求涂刷均匀、无流坠、无色差。
   - 第二遍面漆：第一遍面漆表干后（一般 2～4 h）涂刷第二遍面漆，方向与第一遍垂直。
5. **成品保护**：涂装完成后挂牌保护，禁止触碰，养护期间关闭门窗防止空气流动引起开裂。

### 5.3.5 玻璃贴防爆膜

**工程范围：** 玻璃贴防爆膜，面积 46.5 m²。

**施工步骤：**
1. **基层清洁**：拆除原有贴膜残留物，使用玻璃清洁剂和刮水器彻底清洗玻璃表面，去除灰尘、油渍和旧胶残留。
2. **裁剪防爆膜**：根据玻璃实际尺寸裁切防爆膜，四周预留 5～10 mm 余量。
3. **喷水贴膜**：将裁好的防爆膜展开放置在喷有水溶液的清洁玻璃上，用刮板由中心向四周赶出水分和气泡。
4. **修边压实**：用美工刀沿玻璃边框修去多余部分，再用刮板反复压实边缘，确保粘接牢固、不起泡、无翘边。
5. **养护**：贴膜完成后 48 h 内不得开启或碰撞相关窗户。

## 5.4 车库环氧地面翻新施工工艺

### 5.4.1 原有涂层铲除

**工程范围：** 楼地面环氧地坪铲除，面积 758.56 m²。

**施工步骤：**
1. **设备进场**：使用大功率地坪铲削机（带有金刚石刀片）或手持电镐对原有环氧涂层进行大面积铲除。
2. **分区分段作业**：将车库划分为若干施工段，每个段落面积约 50～100 m²，逐段铲除。铲除过程中随时观察混凝土基层状况，如发现结构层面的裂缝、坑洞立即标记记录。
3. **边角处理**：靠近墙边、柱脚等机械设备无法到达的部位，采用手持电镐或小铲刀人工铲除。
4. **废料收集**：铲除下来的环氧涂层碎片及时清扫装车，运出场外指定消纳场所。

### 5.4.2 混凝土地面坑洞修补

**工程范围：** 混凝土地面开挖与破损修补（含拆除 28 m³）。

**施工步骤：**
1. **缺陷排查**：全车行仔细检查地面，对所有坑洞、裂缝、松散区域进行划线标记。
2. **扩缝剔凿**：用切割机沿裂缝两侧各切 50～100 mm，然后用风镐剔凿出 V 形槽，槽深至坚实混凝土层，并将槽内碎石、粉尘彻底清除。
3. **坑洞浇筑**：对深度较大的坑洞，先填入适量级配碎石作为垫层夯实，再浇筑 C30 商品混凝土填补平整。小面积坑洞直接使用聚合物修补砂浆。
4. **养护**：修补部位洒水养护不少于 7 d，确保强度达标后再进入后续固化地坪施工。

### 5.4.3 C30 混凝土新浇捣

**工程范围：** 混凝土楼地面新浇筑，工程量 112 m²，C30 商品混凝土，厚度 250 mm。

**施工步骤：**
1. **支模**：按设计厚度和坡度安装侧模板，模板内侧涂刷脱模剂。模板加固牢靠，截面尺寸符合设计要求。
2. **基层处理**：浇筑前将基层清理干净，提前一天浇水润湿，但浇筑时表面不得有积水。
3. **混凝土泵送**：由商混站供应 C30 商品混凝土，罐车运至现场后通过泵送入模。浇筑前测定混凝土坍落度（控制范围 160～180 mm），每工作班至少抽查两次。
4. **分层浇筑振捣**：
   - 每次浇筑厚度不超过 500 mm，采用插入式振动棒（Φ50 或 Φ35）逐点振捣，插点间距不大于 400 mm，每点振捣时间 20～30 s，以混凝土表面不再下沉且泛出浆液为准。
   - 注意避开钢筋和预埋件，防止过振导致离析。
5. **刮平压光**：混凝土初凝前用铝合金刮杠刮平表面，随后用木抹子搓平、铁抹子压光，确保地面平整度满足固化地坪施工的基层要求。
6. **养护**：浇筑完成后 12 h 内覆盖薄膜或土工布并洒水养护，养护期不少于 14 d。

### 5.4.4 固化地坪施工

**工程范围：** 混凝土地面固化地坪处理，面积 758.56 m²。
**工序框架：** 清理基层 → 打磨地面两遍 → 坑洞修补 → 平整度点补 → 吸尘清理 → 混凝土密封固化剂五次固化研磨 → 三次抛光 → 撒抛光剂。

**施工步骤：**
1. **基层清理**：使用大型扫地机或吹风机将已硬化修补完毕的混凝土地面彻底清扫干净，确保无任何浮灰、沙粒和松散物质。
2. **粗磨（第一遍打磨）**：
   - 使用加重型地坪研磨机配备 30 目树脂金钢石磨片进行整体粗磨，去除地面的浮浆层、污染层和微小起伏。
   - 研磨速度控制在每分钟 30～40 米，研磨后用地坪吸尘机即时吸除泥浆和粉尘。
3. **细磨（第二遍打磨）**：
   - 换用 50 目或 100 目树脂磨片进行中度细磨，使地面更加平整光滑，消除粗磨留下的划痕。
4. **坑洞修补和平整度点补**：在细磨后全面检查地面，对有坑洼、低洼处使用环氧树脂砂浆或专用自流平砂浆进行局部填补，再次打磨至与周边地面齐平。
5. **第一次吸尘清理**：全面吸尘确保地面完全无尘。
6. **混凝土密封固化剂施工——五次固化研磨**：
   - **第一次涂刷固化剂**：将混凝土密封固化剂均匀泼洒于地面，用量约为 0.3～0.4 kg/m²，用软毛刷或滚刷将其推匀渗透，保持地面湿润状态 20～30 min。
   - **第一遍研磨**：使用 200 目树脂磨片进行研磨，加速固化剂的渗透反应并去除表面泛白，研磨后吸尘。
   - **第二次涂刷固化剂**：在已经反应的表面上再次均匀涂刷固化剂，用量相同。
   - **第二遍研磨**：换用 400 目树脂磨片研磨，使表面更加致密细腻。
   - **第三次涂刷固化剂 + 第三遍研磨**：重复上述涂刷→研磨循环，研磨磨片升级为 800 目。
   - **第四次涂刷固化剂 + 第四遍研磨**：换用 1,500 目镜面磨片研磨，此时地面已呈现出初步光泽。
   - **第五次涂刷固化剂 + 第五遍研磨**：换用 3,000 目抛光磨片进行最终研磨，地面呈现镜面般光泽效果。
7. **三次抛光**：
   - 使用高速抛光机（转速 1,500～2,000 rpm）配合百洁垫进行三次整体抛光，进一步提升表面的光泽度和耐磨性。
8. **撒布抛光剂**：
   - 在抛光完成后，在地面均匀撒布专用液态或粉状抛光剂，继续用抛光机低速研磨至抛光剂完全吸收。
   - 抛光剂的作用是进一步增强光泽度和抗污能力，使固化地坪表面持久光亮。
9. **最终养护**：施工完成后封闭施工区域，养护 24 h 后方可投入使用。

## 5.5 卫生间翻新施工工艺

### 5.5.1 防水层重做

**工程范围：**
- 卫生间地面涂膜防水（1.5 mm，JS 防水涂料Ⅱ型）：35.72 m²
- 卫生间墙面涂膜防水（1.5 mm，JS 防水涂料Ⅱ型）：165.84 m²

**施工步骤：**
1. **旧防水层拆除**：铲除原有失效的防水层和找平层，直至露出坚实的结构基层。
2. **管根、地漏周边处理**：将所有穿楼板的管道周围剔凿出 20×20 mm 的凹槽，填入聚氨酯密封膏或遇水膨胀止水条；地漏口周边同样做密封加强处理。
3. **找平层施工**：在卫生间地面浇筑 20 mm 厚 1:3 水泥砂浆找平层，找坡 1% 坡向地漏口，最薄处 20 mm。找平层表面应平整、无明显凹凸和起砂。墙面与地面交界处做成圆弧形倒角。
4. **JS 防水涂料第一道**：将 JS 防水涂料甲、乙组分按比例搅拌均匀后，在基层上均匀涂刷第一遍涂料，重点加强对管根、地漏周边的涂覆。每遍涂刷方向相互垂直交叉。
5. **JS 防水涂料第二道**：待第一道涂层实干（手指触摸不粘手）后，涂刷第二道涂料，总涂刷方向与第一道呈 90° 交叉，确保涂膜厚度达到 1.5 mm 的设计要求。
6. **墙面防水施工**：墙面防水涂刷高度不低于 1,800 mm，地面防水向上翻边 300 mm。管根部位上下各延伸 200 mm 做加强层。
7. **闭水试验**：防水层完全干燥后（一般需 48～72 h），封堵地漏口并向卫生间注入清水，水深不小于 20 mm，蓄水时间为 24 h。之后到楼下房间（一楼）对应位置检查天花板有无渗漏痕迹。如发现渗漏，须在干燥后重新修补防水层并再次进行闭水试验，直至合格。
8. **防水保护层**：闭水试验合格后，在防水层上方浇筑 20 mm 厚水泥砂浆保护层，保护防水层不受后续施工破坏。

**质量要点：** 防水材料的品种、型号必须符合设计要求，进场时必须出具产品合格证和质量检测报告，并进行抽样复检。

### 5.5.2 块料铺贴

**工程范围：**
- 块料楼地面：300×300 防滑地砖，12 mm 厚，水泥砂浆粘接层 20 mm 厚，地面 35.72 m²。
- 块料墙面：300×600 内墙面砖，10 mm 厚，1:2.5 干硬性水泥砂浆结合层 25 mm 厚，干混砂浆找平层 13 mm 厚，墙面 122 m²。

**施工步骤：**
1. **砖材挑选和预排**：施工前对进场瓷砖进行外观检查，挑出缺棱掉角、变形不合格的砖。按实际空间尺寸进行预排砖，确定最佳切割位置，力求非整砖均匀分布在次要部位或不显眼处。
2. **地面铺贴**：
   - 在基层上洒水湿润并刷素水泥浆一道。
   - 按预定排砖方案从里向外铺贴，采用 20 mm 厚 1:3 干硬性水泥砂浆作为粘结层。
   - 将瓷砖置于砂浆上，用橡皮锤轻轻敲击使其密实平整，同时用水平尺和拉线随时校正砖面平整度和缝隙宽度。
   - 砖缝宜留 1～2 mm，使用十字定位器保持缝宽一致。
3. **墙面铺贴**：
   - 墙面基层处理完毕并充分湿润后，涂刷水泥浆结合层。
   - 自下而上逐层铺贴，底部先用木枋作临时支撑托底，防止瓷砖下滑。
   - 每贴完一行即用靠尺检查平整度与垂直度。
   - 墙地砖交接处应注意对缝协调，优先保证阳角的完整性。
4. **勾缝处理**：铺贴完成 24 h 后开始勾缝，采用专用彩色防水勾缝剂填缝，勾缝应密实饱满、表面光滑。勾缝完成后及时擦拭干净砖面残余砂浆。
5. **养护**：铺贴完成后闭水养护 3 d，期间禁止踩踏和施加荷载。

### 5.5.3 管道更换

**工程范围：** 卫生间给排水管道更新，DN25 PPR 给水管，拆除 100 m，新装 100 m。

**施工步骤：**
1. **停水和排水措施**：施工前联系物业切断供水主管阀门，打开最低处排水管泄空管内存水，防止拆卸时喷溅。
2. **旧管拆除**：
   - 使用专用割管器或锯条切断旧 PPR 管道，先将管件端部断开，再逐段卸下旧管。
   - 拆除后的废弃管材分类堆放，统一清运出场。
   - 拆卸过程中注意保护既有管线和卫生器具，尤其是需要利旧安装的蹲便器、淋浴器等。
3. **新管定位放线**：按照改造后的平面布局，用墨线弹出 DN25 PPR 管的走向和支架安装位置。
4. **PPR 管热熔连接**：
   - 使用专用 PPR 热熔焊机进行管道连接，加热温度和熔接时间严格按管材规格设定（DN25 管材一般加热 5～7 s，保压冷却 2～3 min）。
   - 管道安装时设置活动支架和固定支架，支架间距不大于 600 mm（水平）和 1,500 mm（立管）。
5. **水压试验**：管道安装完毕后进行水压试验，试验压力应为工作压力的 1.5 倍且不小于 0.6 MPa，稳压 1 h 压降不超过 0.05 MPa，然后降至工作压力检查各接口无渗漏为合格。
6. **隐蔽前验收**：管道隐蔽封槽之前须经监理和建设单位共同验收签字后方可封闭。

### 5.5.4 利旧卫生洁具安装

**工程范围：**
- 蹲式大便器利旧安装：7 组
- 蹲式大便器全新安装（瓷蹲式大便器含水箱及配件）：3 组
- 淋浴器利旧安装（电热水器挂式 RS50 型）：10 套
- 热水器利旧安装：10 套
- 普通灯具利旧安装（吸顶灯）：10 套

**施工步骤及注意事项：**
1. **拆卸前的标识**：对所有利旧设备的拆卸位置进行拍照记录并在设备上编号标注，防止回装时错位。
2. **利旧拆卸**：小心拆除原有蹲便器、热水器、灯具等利旧物品，特别注意电线、水管接头的断离，不得使用蛮力以免损坏设备本体。
3. **利旧检测**：
   - **蹲便器**：检查排污口是否完好、水箱配件功能是否正常、釉面有无裂痕。
   - **电热水器 RS50 型**：必须请专业电工检测绝缘电阻和接地可靠性，检查加热管、温控器和安全阀的功能是否完好，漏电保护器是否动作灵敏。如有故障应及时更换配件而非整机更换。
   - **吸顶灯具**：检查灯具外壳、灯罩、镇流器（如是荧光灯）和接线端子，排除线路老化问题。
4. **利旧安装**：
   - 蹲便器采用水泥砂浆座浆安装，排污管对接严密，四周用水泥砂浆密封防臭。
   - 电热水器挂墙安装须使用专用膨胀螺栓固定，承重须满足热水器的满载重量要求（RS50 型满载约 100 kg），出水口加装泄压阀和止回阀。
   - 灯具回装时注意电线连接牢固，使用接线端子或绞接焊锡处理，外层包绝缘胶带，接入前须确认断电操作。
5. **全新蹲便器安装**：按照同利旧材料规格的新品蹲便器安装方式执行，含水箱及配件完整组装。安装完成后进行冲水试验，验证冲水力度和排污顺畅度。

## 5.6 附属配套施工工艺

### 5.6.1 塑钢窗打胶维修

**工程范围：** 原有门窗清洁维护，清理切割耐候胶、打耐候胶密封处理，面积 288 m²。

**施工步骤：**
1. **旧胶清理**：使用美工刀和专用开胶工具剔除原有老化的耐候胶，将窗框与窗扇、窗框与墙体之间缝隙中的旧胶清除至深度 5～8 mm 的 V 形槽口。
2. **基面清洁**：用酒精或专用清洁剂擦拭缝隙两侧，确保基材表面洁净干燥、无灰尘和油污。
3. **填塞背衬条**：在较深的缝隙内填入聚乙烯泡沫背衬条（圆形绳），控制打胶的深度（一般为缝隙宽度的一半），防止三面粘连影响胶体弹性。
4. **打注耐候胶**：使用耐候硅酮密封胶从缝隙一端向另一端匀速挤注，确保胶体连续、饱满，无气泡和断点。
5. **刮平修整**：打胶后立即用刮板将胶面刮平整形，使胶缝与窗框表面齐平且线条顺直。刮平后 30 min 内不得触动胶缝。
6. **养护**：打胶完成后 24 h 内不得接触水和受力。

### 5.6.2 金属门油漆翻新

**工程范围：** 金属门油漆翻新，面积 106.20 m²。
**工序框架：** 手工除锈 → 红丹防锈漆一遍 → 醇酸磁漆三遍。

**施工步骤：**
1. **表面清理**：清除金属门表面的灰尘、油污和附着松动的旧漆皮。
2. **手工除锈**：使用钢丝刷、砂纸等手工工具对金属门表面进行全面除锈，将锈蚀部位打磨至 St2 级（彻底的手工和动力工具除锈），露出金属光泽。对严重锈蚀穿孔的门扇须报设计单位评估是否局部加焊钢板修补。
3. **底漆涂刷**：除锈完成后清扫浮尘，涂刷红丹防锈漆一遍。涂刷时应均匀无漏涂，重点关照焊缝、角部和不易发现的隐蔽面。
4. **面漆涂刷（三遍醇酸磁漆）**：
   - 第一遍面漆：底漆干燥后涂刷第一遍醇酸磁漆，要求漆膜均匀。
   - 第二遍面漆：待第一遍面漆表干后进行，可采用不同方向的涂刷手法确保覆盖无遗漏。
   - 第三遍面漆：最后一遍面漆，要求光泽度一致、无流挂、无色差、无颗粒。
5. **五金复装**：油漆全部干燥后，将门锁、合页、拉手等五金件复位安装调试。

### 5.6.3 空调移机和支架更换

**工程范围：**
- 空调外机移机（现有空调外机，型号综合）：23 台
- 空调外机恢复安装（利旧）：23 台
- 空调外机支架更换（镀锌角钢支架）：10 台
- 空调机加氟（加满至满足要求）：23 台

**施工步骤：**
1. **收氟排液**：由专业空调维修人员操作，启动空调制冷模式，使用专用扳手关闭高压阀和低压阀，停机后将制冷剂回收至室外机压缩机内。如系统老化无法回收，须使用真空泵抽取冷媒至密闭钢瓶中，杜绝大气排放。
2. **拆卸铜管及电源线**：逐个拆卸室内外机连接的铜管和电源信号线，接头用胶带封口防尘防潮。铜管弯曲半径不宜过小，防止折扁影响制冷剂流通。
3. **拆除旧外机支架**：用气割或螺丝卸除原有的锈蚀支架，拆除过程中注意防止工具坠落伤人，下方设置警戒区和警示标识。
4. **新支架安装**：
   - 更换 10 台所需的老化支架，使用热镀锌角钢制作新支架（规格不小于 ∠50×50×5 mm），膨胀螺栓固定在建筑实体墙上。
   - 支架安装须水平稳固，倾斜角度朝向室外利于排水，承重能力经过核算满足外机重量。
   - 其余 13 台支架如完好则可保留继续使用，但也须做防锈处理。
5. **外机回装**：
   - 将 23 台外机搬回原位，安装到新支架上并紧固螺栓。
   - 连接铜管和电源线，用压力表检测系统有无泄漏。
6. **抽真空和加氟**：
   - 使用真空泵对空调系统进行抽真空，抽真空时间不应少于 15 min。
   - 打开制冷剂阀门，根据铭牌标示的制冷剂种类和充注量加氟至规定量，开机运行检测制冷效果是否符合出厂标准。
7. **试机验收**：每台空调分别进行制冷和制热试运行，检查出风口温度、噪音和冷凝水排出情况，确保运行正常后签字确认。

### 5.6.4 墙上排水管更换

**工程范围：** 墙上排水管拆除与新装，塑料管 DN110，工程量 182.40 m。

**施工步骤：**
1. **拆除旧管**：自上而下逐层截断并卸下原有旧排水管（如为 PVC 管可用管剪切割，如为铸铁管用气割），注意不要损坏墙面和楼板洞口处的结构。
2. **洞口清理**：清除预留洞口内的杂物和残渣，检查管洞四周是否存在裂缝或渗水隐患。如有结构性缺陷先行修补。
3. **新管测量下料**：按实际层高和楼层累计高度测量 DN110 PVC-U 排水管的下料尺寸，每节管长度适当缩短以预留承插口插入深度（一般插入深度为管径的 1～1.5 倍）。
4. **胶粘连接安装**：
   - 使用 PVC 专用粘合剂进行承插粘接。粘接前将管口和承口的污垢清除干净，均匀涂刷粘合剂后迅速插入到位并保持 30 s 以防止脱开。
   - 立管每层设一个伸缩节，横管按设计坡度（不小于 1%）安装，便于污水自然排泄。
5. **支架固定**：立管每层设一个管卡固定（层高大于 5 m 时加设两个），横管间距不大于 1.5 m，确保管道稳固不晃动。
6. **通球和水试验**：排水管安装完成后进行灌水试验和通球试验，验证管道畅通无堵塞、接口无渗漏。

## 5.7 施工顺序及交叉作业协调

### 5.7.1 总体施工顺序

按照第4章确定的四阶段施工划分，本工程主要分部分项工程的总体施工顺序如下：

**第一阶段（拆除）→ 第二阶段（土建装饰）→ 第三阶段（收尾）**

具体分项逻辑关系：
1. **拆除阶段**：保温层/抹灰涂料/内饰涂料铲除 → 环氧地坪铲除 → 卫生间旧管道/洁具拆卸 → 塑钢窗旧胶清理 → 空调外机收氟拆卸 → 排水管旧管拆除。
2. **土建装饰阶段（大项按外墙→室内→地面→卫生的顺序交叉推进）**：
   - 外墙：保温层拆除 → 抹灰涂料拆除 → JS 防水涂料 → 真石漆喷涂 → 铝塑板幕墙（可与真石漆并行施工不同立面）。
   - 室内：涂料铲除 → 抹灰修补 → 腻子批刮 → 乳胶漆涂装 → 石膏板吊顶。
   - 车库：环氧地坪铲除 → 坑洞修补/C30 新浇 → 固化地坪全流程（打磨→固化剂五次研磨→抛光→撒抛光剂）。
   - 卫生间：防水重做→闭水试验合格→块料铺贴→管道更换→洁具利旧/新装→吊顶安装。
3. **收尾阶段**：附属配套（塑钢窗打胶→金属门油漆→空调回装加氟→排水管新装）穿插在上述主体工程中同步实施。

### 5.7.2 交叉作业协调

1. **室内外流水段划分**：外墙施工与室内施工原则上分流水段平行作业，但在同一立面附近时须错开高空作业时段，避免立体交叉作业带来的安全隐患。
2. **卫生间工序衔接**：防水→闭水试验→贴砖→管道→洁具，每道工序必须完成验收后方可进入下道工序，不得颠倒顺序。
3. **机电安装与土建装饰的配合**：水电管线预埋应在抹灰、吊顶封闭之前完成，隐蔽工程经验收签字后方可封闭。
4. **空调移机时间安排**：空调拆除应在室内装修基本完成前进行，待室内外装修基本结束时再进行回装和加氟调试，以避免空调设备在施工现场被污染或损坏。
5. **成品保护贯穿全程**：各分项工程完工后应及时做好覆盖保护膜、张贴警示标识等成品保护措施，下道工序施工时不得污染或损坏已完成的成品。

## 5.8 成品保护措施

1. **门窗保护**：施工期间的门窗采用塑料薄膜或彩条布全覆盖包裹，防止涂料飞溅和砂浆污染。
2. **地面保护**：已完成的固化地坪和块料铺贴地面，在后续工序施工期间采用多层板或纤维板满铺覆盖，严禁直接在成品地面上拌和砂浆或堆放尖锐重物。
3. **墙面保护**：乳胶漆涂刷完毕的房间须封闭管理，张贴"请勿触碰"警示牌；未涂刷区域在邻近工序施工时应用塑料薄膜隔离。
4. **设备保护**：利旧的空调外机、热水器、灯具等在拆卸前和安装后均应做好防尘防磕碰措施。
5. **护栏及构筑物**：护栏拆除后妥善保管，利旧安装时确保其牢固性和顺直度；临时围挡保持完整直至工程全部竣工撤除。

## 5.9 材料进场检验要求

1. **进场检验制度**：所有进场的材料（含主材和辅材）必须有出厂合格证、质量证明文件和检测报告，并按规定进行现场抽样复检。
2. **重点材料复检项目**：
   - JS 防水涂料：抽检固体含量、拉伸强度、断裂伸长率和不透水性。
   - 真石漆：抽检粘砂率、耐冻融性、耐沾污性和色差。
   - 混凝土密封固化剂：抽检密度、pH 值和渗透深度。
   - PVC 排水管：抽检环刚度、冲击强度和维卡软化温度。
   - 石膏板：抽检面纸强度、含水量和抗弯负荷。
3. **材料储存**：材料进场后应按类别分区存放，水泥、砂浆等易潮材料须入库防雨防潮；易燃材料（油漆、稀释剂、固化剂等）单独存放于通风阴凉处，配备灭火器材。
