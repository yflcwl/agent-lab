## 🔑 关键术语
- **真石漆**：外墙装饰涂层材料，本工程外墙采用抹灰面真石漆及腻子工艺
- **环氧地坪**：车库地面翻新采用的树脂类地坪涂料
- **防爆膜**：玻璃贴防爆膜，用于部分窗户的安全防护
- **铝塑板带钢骨架幕墙**：外墙局部饰面新做工艺
- **定额人工费**：269,726.48元（占总价约38.4%）
