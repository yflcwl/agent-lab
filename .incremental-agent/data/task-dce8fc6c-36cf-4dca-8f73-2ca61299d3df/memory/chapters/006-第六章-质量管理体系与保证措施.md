# 第六章 独立章节记忆

## 📌 章节摘要
第6章围绕"工程检查验收一次通过"总体质量目标，系统构建质量管理体系与保证措施。涵盖：质量目标及分解（12个分项类别）；质量管理组织体系（项目经理→技术负责人→生产/安全负责人→施工员+专职质量员→班组长7级架构）；三检制度（自检、互检、交接检）及技术交底、值班巡检、奖罚四大基本制度；五大类维修工程各分项工程质量控制要点表（外墙/天棚室内/车库/卫生间/附属配套共80+项具体控制要求）；砖砌体工程检验批专项质量控制（主控4条+一般3条，GB50203-2011标准）；材料进场检验与复检管理（10类材料、9项复检项目建议）；成品保护措施责任划分与费用列支；质量问题分级处理闭环流程；竣工质量资料管理与验收准备。

## 📝 术语与参数一致性问题
- 质量目标表述以原文为准："工程检查验收一次通过"
- 砖砌体砂浆饱满度：墙水平≥80%，柱水平和竖直≥90%（GB50203-2011原文）
- 拉结钢筋：每120mm墙厚2根Φ6，间距≤500mm，埋入≥500mm，抗震设防6~7度地区≥1000mm
- JS防水抽检：固体含量、拉伸强度、断裂伸长率、不透水性（行业通用，原文有原则性提及）
- 固化剂涂刷用量：0.3~0.4 kg/m²/遍（第五章展开时给出）
- RS50型热水器满载约100kg（估算法推定值，标注为估测）
- 绝缘电阻检测：≥0.5 MΩ（电气设备通用要求）

1. 除砖砌体外，其他分项工程未找到具体的检验批划分数量和验收标准条文，写作中按行业标准经验值列出，实际验收应以对应国标正式文本为准
