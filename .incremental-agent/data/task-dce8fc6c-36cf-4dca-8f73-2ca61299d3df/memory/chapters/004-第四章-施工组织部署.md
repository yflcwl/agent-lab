# 第4章《施工组织部署》章节记忆

## 📖 摘要
本章对双流机场东消防站维修工程的全局施工组织进行了系统部署，包括管理组织架构（6岗+应急架构）、四阶段施工划分（准备→拆除→土建装饰→收尾验收）、总体部署原则与安全管控措施、资源配置计划（人员/车辆/机具）及施工准备工作安排。为后续第五章施工工艺展开提供组织保障框架。

## 📌 关键事实
1. **管理岗位6人**：项目经理、生产经理、技术负责人、安全负责人、施工员、班组长
2. **专业工种总计**：安装工8人+水电工6人+混凝土工5人+木工4人+泥工4人 = **27人一线**，加上管理6人共**33人**
3. **车辆6辆**：7座面包3辆+皮卡2辆+自卸1辆
4. **主要机具17项**：登高作业车1辆(租赁)、切割机4把、电镐4把、焊机1台、冲击钻3把、空压机1台、振动棒1把等
5. **四阶段**：准备打围→拆除清表→土建装饰→收尾验收
6. **设施部署**：每50㎡≥2具3A级5KG干粉灭火器；库房每15㎡配2具；动火点每点2具4A级8KG
7. **围挡参数**：2.5米高轻钢龙骨彩钢板，全封闭约36米宽，边界距施工区≤1.2米
