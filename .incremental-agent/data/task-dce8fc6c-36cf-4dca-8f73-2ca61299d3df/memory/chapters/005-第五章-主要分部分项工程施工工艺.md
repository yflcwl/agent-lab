# 第五章 主要分部分项工程施工工艺 - 章节记忆

## 📝 摘要
本章按第4章四阶段施工部署的顺序逐项展开五大类维修工程的具体施工工艺和操作要点，涵盖外墙翻新（保温层拆除、抹灰涂料拆除、JS防水涂料真石漆、铝塑板幕墙）、天棚及室内墙面翻新（涂料铲除、抹灰修补、石膏板吊顶、乳胶漆重涂、防爆膜）、车库环氧地面翻新（涂层铲除、坑洞修补、C30混凝土新浇、固化地坪全流程）、卫生间翻新（防水重做闭水试验、块料铺贴、管道更换、洁具利旧安装）以及附属配套施工（塑钢窗打胶、金属门油漆翻新、空调移机加氟支架更换、排水管更换）。同时明确了各分项间的总体施工顺序、交叉作业协调原则、成品保护措施和材料进场检验要求。

## ✅ 事实来源

- 《双流机场东消防站维修工程施工方案-背景资料.docx》：chunk 2编制依据11项国标规范；chunk 8质量控制要点（成品保护）；chunk 14质量保证措施（材料进场检验原则）；chunk 4施工作业流程（挡土墙施工参考）

## 🔑 关键术语/工艺框架
- JS防水涂料Ⅱ型：1.5mm厚，两道涂刷，配套网格布+抗裂砂浆薄抹面层4mm
- 真石漆工序：界面剂→耐水腻子两道→水性封闭底漆一道→真石漆喷涂→罩面保护漆一道
- 固化地坪工序：清理→打磨两遍→坑洞修补→吸尘→固化剂五次研磨→三次抛光→撒抛光剂
- 乳胶漆工序：界面剂→满刮成品腻子三遍→底漆一遍→面漆两遍
- 金属门油漆：手工除锈→红丹防锈漆一遍→醇酸磁漆三遍
- 卫生间防水：找平层20mm(1%坡向地漏,最薄处20mm)→JS涂膜1.5mm→闭水试验24h→保护层20mm
- C30混凝土新浇：厚度250mm,商品混凝土,泵送
