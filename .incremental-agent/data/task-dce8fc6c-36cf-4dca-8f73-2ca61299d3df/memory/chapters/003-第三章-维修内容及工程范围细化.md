### 关键材料规格
- JS防水涂料Ⅱ型：1.5 mm厚（外墙、卫生间均用此规格）
- 聚氨酯防水聚合物丙烯酸防水涂料：3涂一布，2.0 mm厚（挑檐屋面）
- 真石漆：水性封闭底漆一道→真石漆喷涂→罩面保护漆一道
- 固化地坪：混凝土密封固化剂处理五次固化研磨+三次抛光后撒抛光剂
- 铝塑板幕墙：60×3镀锌矩管双层双向间距600mm+4厚40丝铝塑板+耐候结构胶
