# 第一章 工程概况

## 一、项目基本信息

| 项目 | 内容 |
|------|------|
| 工程名称 | 双流机场东消防站维修工程 |
| 编制单位 | 成都空港建设开发服务有限公司 |
| 编制日期 | 2026年7月 |
| 项目地址 | 双流机场东消防站 |

本项目位于四川省成都市双流国际机场区域内，主要对东消防站现有建筑物及附属设施进行综合性维修改造。因现有资料中标注的建筑基本参数（总建筑面积、建筑结构形式、楼层数、檐口高度等）均以"详设计"表示，本节暂不展开详细数值；具体的建筑技术经济指标以最终设计文件为准。

## 二、维修改造范围与工程内容

根据项目工程量清单及施工方案，本次维修工程共包含四大类施工内容：

### （一）外墙翻新工程

外墙翻新是本次维修工程中体量最大的分项之一，涉及外立面全貌的拆除、翻新与保护，工程量合计约16个清单子目。主要内容涵盖：

1. **既有饰面层拆除**
   - 外墙柱面保温层拆除：1,361㎡
   - 外立面抹灰及涂料拆除：1,789㎡
   - 外立面水泥砂浆粘结层拆除：106㎡
   - 入户处墙柱面龙骨及饰面拆除：88㎡
   - 墙面字体拆除：52个
   - 挑檐屋面找平层拆除：100㎡

2. **空调系统相关维修**
   - 空调外机移机后利旧安装、空调机加氟：23台
   - 空调外机支架更换：10台

3. **排水及门窗局部修复**
   - 墙上排水管拆除及恢复：182m
   - 塑钢窗打胶维修：288㎡
   - 金属门油漆翻新：106㎡

4. **新饰面层施工**
   - 墙面一般抹灰：1,789㎡
   - 墙面涂膜防水：1,789㎡
   - 抹灰面真石漆及腻子：1,789㎡
   - 铝塑板带钢骨架幕墙：88㎡
   - 挑檐屋面聚合物丙烯酸防水涂料及找平层：100㎡

上述施工将按"先拆后做、先防后饰"的顺序推进，在确保防水层一次性验收合格的前提下进行真石漆面层的施工。

### （二）天棚及墙面翻新工程

天棚及墙面翻新覆盖面积较大，总计约4,902㎡，主要包括以下工作：

1. 天棚及墙面涂料拆除：4,902㎡
2. 墙柱面铲除（混合、水泥砂浆面）：500㎡
3. 墙面一般抹灰：500㎡
4. 抹灰面乳胶漆及腻子：4,902㎡
5. 玻璃贴防爆膜：46.5㎡

该分项工程的特点是作业面广、高空临边作业较多，施工中需重点做好成品保护和作业人员安全防护。

### （三）车库环氧地面翻新工程

车库区域原有环氧地坪老化破损严重，需整体铲除并重新施作固化地坪，工程量如下：

1. 铲除原环氧地坪：758㎡
2. 混凝土地面拆除：28m³
3. 混凝土楼地面：112㎡
4. 混凝土地面固化地坪：758㎡

### （四）二楼战斗员宿舍卫生间翻新工程

二楼战斗员宿舍卫生间涉及多处管线更新、防水重做和饰面翻新，工程量清单共18个子目，主要内容包括：

1. **既有饰面和管线拆除**
   - 地砖拆除：36㎡
   - 墙砖拆除：166㎡
   - 铝合金扣板吊顶拆除：36㎡
   - 墙面防水及找平层拆除：166㎡
   - 地面防水及找平层拆除：36㎡
   - 管道拆除（DN25给水管）：100m
   - 蹲便器、灯具、热水器、淋浴器拆除：10套

2. **新建及恢复工程**
   - 平面砂浆找平层：36㎡
   - 楼地面涂膜防水：36㎡
   - 楼地面300×300防滑地砖铺设：36㎡
   - 墙面找平及防水保护层：332㎡
   - 墙面JS涂膜防水：166㎡
   - 墙面10厚300×600内墙面砖铺设：122㎡
   - 铝合金扣板吊顶拆安：135㎡
   - 管道新安（DN25给水管暗埋）：100m
   - 灯具、热水器、淋浴器拆除利旧安装：10套
   - 蹲便器利旧安装：7组
   - 蹲便器新安：3组

卫生间翻新工程须严格遵循"先管线后饰面、先防水后贴砖"的施工顺序，防水层完工后必须按规定完成闭水试验方可进入下道工序。

## 四、工程特点与分析

综合以上工程内容，本维修工程具有以下显著特点：

1. **体量大、面广。** 外墙翻新涉及近1,800㎡的外立面处理，天棚及墙面翻新面积约4,900㎡，整体维修规模大，施工资源投入量大。
2. **多专业交叉作业。** 外墙翻新、室内墙面翻新、车库地坪翻新、卫生间改造四个大类同时或交替施工，各专业间协调管理要求高。
3. **高空作业风险突出。** 外立面拆除与涂装作业需使用高处吊篮或脚手架作业，高空坠落和物体打击是主要的风险源。
4. **防水工程为质量控制重点。** 外墙涂膜防水、卫生间楼地面及墙面JS涂膜防水均属隐蔽工程，防水质量直接关系交付后的使用安全与耐久性。
5. **利旧安装比例较高。** 空调外机、卫生洁具、灯具热水器等多数设备采用拆除后利旧安装的方式，既降低材料成本又减少建筑垃圾，但对成品保护提出了更高要求。

## 五、场地及周边条件简述

本项目位于双流机场区域内，周边设施包括机场运行基础设施。根据现有资料显示，施工现场临近110kV羊航线1#杆塔区域，施工中需注意对既有电力设施的保护，并做好与机场动力能源部门的沟通协调。围挡采用2.5m高轻钢龙骨彩钢板进行全封闭设置，长度约36m，施工作业时段限定为每日8:00至18:00。
