# 第七章 天棚及墙面翻新施工方法

## 7.1 施工总体流程

天棚及墙面翻新工程涵盖室内天棚乳胶漆面层的铲除与重做、室内墙面铲除及抹灰找平、石膏板吊顶修补安装、玻璃贴防爆膜等内容。该分部工程的施工作业在前期的室内涂料及抹灰层拆除完成后进入。整体施工顺序遵循"先顶后墙、由粗到细"的原则：天棚及墙面基层铲除 → 墙面抹灰找平（如需要）→ 界面剂处理 → 满挂成品腻子 → 底漆涂刷 → 乳胶漆面层喷涂/滚涂 → 石膏板吊顶补装 → 玻璃防爆膜粘贴。

```
天棚墙面涂料铲除 → 墙面铲除混合/水泥砂浆面 → 
墙面一般抹灰(13mm干混砂浆) → 界面剂一道 → 
满挂成品腻子 → 底漆一遍面漆两遍 → 
石膏板吊顶补装 → 玻璃贴防爆膜
```

上述主工序完成后，同步穿插实施铝合金扣板吊顶的拆除与恢复安装。各工序之间严格执行干燥养护间歇要求，前一道工序未充分干燥固化不得转入下一道。

## 7.2 天棚及墙面涂料铲除工程

### 7.2.1 工程概况

| 项目 | 参数 |
|------|------|
| 天棚及墙面涂料拆除工程量 | 4,902 ㎡ |
| 墙柱面铲除混合/水泥砂浆面 | 500 ㎡ |
| 铲除对象 | 既有老化饰面涂层、空鼓起皮的真石漆/乳胶漆层 |

### 7.2.2 施工工艺

1. **天棚乳胶漆铲除**（工程量 4,902 ㎡）
   - 采用电动剔铲配合手工铲刀的方式，将天棚表面老化的乳胶漆饰面层彻底剔除至坚实基层。
   - 天棚铲除作业应搭设移动式操作平台或利用现有脚手架进行，作业人员须佩戴护目镜及防尘口罩。
   - 铲除过程注意保护既有管线预埋件及灯具固定座周围区域，避免不必要的损伤。

2. **墙面及柱面铲除**（工程量 500 ㎡）
   - 铲除范围为墙面及柱面混合砂浆面和水泥砂浆面上的老化饰面层。
   - 人工配合电动工具自上而下逐步铲除，对顽固附着层可先用热水浸润软化后再行剔除。
   - 铲除过程中如发现基层存在大面积空鼓、酥松现象，应将空鼓层一并凿除至坚实部位并记录备案。

3. **垃圾清运**
   - 铲除产生的废旧涂层碎屑应及时装袋，通过指定垂直运输通道运至地面建筑垃圾临时堆放点集中分类处置。
   - 严禁高空抛掷铲除废料，室内作业区域设置专用废弃物收集容器，日产日清。

4. **基层验收**
   - 铲除完成后全面检查基层状况，形成隐蔽验收记录。对残留的浮灰、松散颗粒采用钢丝刷或高压气枪清理。
   - 需后续抹灰找平的墙面区域做好标记，明确具体范围及厚度要求。

## 7.3 墙面一般抹灰工程

### 7.3.1 工程概况

| 项目 | 参数 |
|------|------|
| 抹灰面积 | 500 ㎡ |
| 抹灰厚度 | 13 mm |
| 材料种类 | 干混砂浆 |
| 适用部位 | 室内墙面（局部需要重新抹灰找平区域） |

### 7.3.2 材料要求

1. **干混砂浆进场检验**
   - 所用干混砂浆应具备出厂合格证、型式检验报告，进场后按批次抽样复检，合格后方可用于本工程。
   - 砂浆储存应置于干燥通风的室内环境，防止受潮结块。超过出厂日期超过三个月的产品不得直接使用。

2. **配合比控制**
   - 干混砂浆为预拌产品，施工时仅需按要求加水搅拌即可。加水量按产品说明书确定，不得随意增减。
   > **说明：** 原方案中对室内抹灰干混砂浆的具体强度等级、水灰比等参数未予明确标注，施工中应按产品技术文件执行。

### 7.3.3 施工工艺

1. **基层浇水湿润**
   - 抹灰施工前一天对墙面均匀浇水湿润，使基层含水率达到抹灰工艺要求（通常为 8%～12%），施工时基面无明水积存。

2. **吊直、套方、规矩**
   - 依据设计标高和抹灰厚度设定控制线，在墙面四角、门窗洞口边缘等处弹出垂线和水平线，作为抹灰厚度控制基准。

3. **冲筋打饼**
   - 距墙面两侧约 200 mm 处分别抹制灰饼，灰饼尺寸约 50 × 50 mm，厚度以垂直度和平整度双控标准确定。
   - 上下灰饼之间做竖向冲筋，筋条间距不大于 1.5 m，作为分层抹灰的厚度参照。

4. **底层抹灰**
   - 第一遍抹灰厚度控制在 6～7 mm，用刮杠初步找平。底层砂浆应稍糙以保证与中层的良好粘结。
   - 底层抹灰完成后适当拉毛处理，增加层间附着力。

5. **中层及面层抹灰**
   - 待底层抹灰达到七八成干后进行第二遍抹灰，总厚度控制在 13 mm（±2 mm）。
   - 第二遍抹灰以找平为主，用铁抹子压光收面，确保表面平整密实。

6. **养护**
   - 抹灰层终凝后洒水养护不少于 3 天，防止水分蒸发过快造成收缩开裂。

### 7.3.4 质量要求

- 抹灰表面应平整、洁净、无接槎痕迹，颜色一致。
- 平整度偏差：用 2 m 靠尺检查，偏差不超过 4 mm。
- 立面垂直度偏差不超过 4 mm。
- 阴阳角方正偏差不超过 4 mm。
- 分格条（缝）宽度、深度均匀，边缘整齐。
- 抹灰层不得有裂缝、空鼓、脱层、爆灰等现象。

## 7.4 界面剂涂刷及满挂成品腻子

### 7.4.1 界面剂涂刷

1. **涂刷时机**
   - 抹灰层完成并经 3 天以上养护期后，确认基层含水率低于 10%、表面坚实平整，方可进行界面剂涂刷。

2. **涂刷方法**
   - 采用滚筒均匀涂刷，涂刷方向宜一致，不漏刷、不堆积。对于吸水性较强的基层可适当增加涂刷遍数以增强封闭效果。
   - 涂刷完成后自然干燥 2～4 小时（视环境温湿度而定），形成一层均匀的粗糙面。

### 7.4.2 成品腻子批刮

| 项目 | 参数 |
|------|------|
| 腻子类型 | 成品耐水型腻子膏（满挂） |
| 施工遍数 | 2 遍 |
| 单遍厚度 | 约 0.5～1.0 mm |
| 干燥时间 | 常温下约 12～24 小时/遍 |

**工艺流程：** 调配 → 首遍批刮 → 干燥 → 打磨 → 二遍批刮 → 干燥 → 精细打磨 → 除尘

**具体操作步骤：**

1. **腻子调配**
   - 成品腻子膏如需加水调稀，按产品说明书规定的比例加入清水，使用电动搅拌器搅拌均匀，静置 5～10 min 后二次搅拌再使用。
   - 配好的腻子应在规定时间内用完，一般不超过 3 小时，不得隔夜重复使用。

2. **首遍批刮**
   - 使用不锈钢刮刀自上而下满刮第一遍腻子，厚度约为 0.5～1.0 mm。首遍主要目的在于大面积找平和覆盖底层面缺陷。
   - 阴阳角部位采用专用刮角工具修直，门窗洞口周边保持顺直。

3. **打磨**
   - 首遍腻子完全干燥后用 200～300 目砂纸进行打磨，重点消除刮痕、凸起点和不平整处。
   - 打磨后清扫浮尘，必要时采用吸尘器辅助清理。

4. **二遍批刮**
   - 第二遍腻子在首遍打磨后施加，厚度略薄于首遍，主要目的为精细找平和消除细微瑕疵。
   - 二遍批刮后再次打磨，直至表面平滑细腻、无明显刮痕和凹凸点。

5. **腻子层质量要求**
   - 表面平整光滑、色泽一致，无起粉、起皮、掉粉现象。
   - 平整度偏差 ≤ 3 mm/2 m。
   - 不得有裂缝、气泡、砂眼等外观缺陷。

## 7.5 乳胶漆涂刷工程

### 7.5.1 工程概况

| 项目 | 参数 |
|------|------|
| 工程名称 | 抹灰面乳胶漆及腻子（天棚 + 墙面） |
| 工程量 | 4,902 ㎡ |
| 构造层次 | 界面剂一道 → 满挂成品腻子（2 遍）→ 底漆 1 遍 → 面漆 2 遍 |
| 涂料体系 | 水性环保型内墙乳胶漆 |

### 7.5.2 底漆施工

1. **功能定位**
   - 底漆的主要作用为封闭腻子层的吸水率和碱性，增强面漆的附着力和平滑性，减少面漆用量并提高装饰效果。

2. **施工条件**
   - 腻子层经最终打磨除尘后，表面平整度、光洁度达到验收标准方可涂刷底漆。
   - 环境温度宜在 5～35 ℃之间，空气相对湿度低于 85%，天气晴朗或有良好的通风条件。

3. **施工方法**
   - 使用前将底漆搅拌均匀，必要时可根据产品说明加入少量清水（一般不超过 10%）调节稠度。
   - 采用优质滚筒手工滚涂，也可辅以喷涂。涂刷方向统一，均匀不留痕迹。
   - 底漆涂刷一遍即完成，不应漏涂或在同一部位反复来回涂刷造成流挂。

4. **干燥间隔**
   - 底漆表干后（常温约 1～2 小时）方可进行面漆施工。具体时间应参照产品说明书并根据现场温湿度调整。

### 7.5.3 面漆施工（二遍）

1. **第一遍面漆**
   - 底漆完全干燥后涂刷第一遍面漆。施工方法与底漆相同，采用滚筒滚涂为主。
   - 第一遍面漆不必追求绝对遮盖，重点是均匀着色并为第二遍打底。

2. **第二遍面漆**
   - 第一遍面漆干燥至少 4 小时后进行第二遍面漆施工。
   - 第二遍面漆涂刷时应注意与前一道漆膜方向的交接，避免产生色差或条纹。
   - 涂刷完成后应保持室内良好通风，加速漆膜干燥固化。

3. **质量要求**
   - 涂装层色泽一致、无透底、流坠、起皮、反碱咬色等缺陷。
   - 涂膜表面光滑、手感细腻，无明显辊痕和接茬痕迹。
   - 装饰线条清晰顺直，门窗、踢脚线等交接部位无污染。

4. **成品保护**
   - 漆膜干燥期间（一般至少 24 小时）应设置专人巡视，防止人为触碰、淋水污染。
   - 后续交叉作业时，应对已完成的乳胶漆饰面采取塑料薄膜、彩条布等材料进行遮蔽保护。

## 7.6 石膏板吊顶工程

### 7.6.1 工程概况

| 项目 | 参数 |
|------|------|
| 工程名称 | 石膏板吊顶面层新做 |
| 工程量 | 135.45 ㎡ |
| 面板规格 | 600 × 600 mm 石膏板 |
| 面板厚度 | 同原有石膏板厚度 |
| 龙骨形式 | 轻钢龙骨骨架 |

### 7.6.2 施工准备

1. 核实吊顶标高、位置是否符合设计要求，复核建筑净空尺寸。
2. 检查原有吊顶龙骨是否满足继续使用条件，对锈蚀严重、变形超限的龙骨予以更换。
3. 准备符合规格的 600 × 600 mm 石膏板，板材外观完整无破损、边角无损缺，进场后堆码整齐防潮存放。

### 7.6.3 施工工艺

1. **弹线定位**
   - 根据设计标高在四周墙体上弹放水平控制线。
   - 在地面和墙面弹出主龙骨、副龙骨的位置线，确定吊杆位置和吊杆长度。

2. **吊杆及边龙骨安装**
   - 吊杆间距一般为 900～1,200 mm，采用 φ8 及以上膨胀螺栓或化学锚栓固定。吊杆端部螺纹外露长度不小于 50 mm。
   - 沿周边墙体安装 L 形或 U 形边龙骨，用射钉或膨胀螺栓固定于墙体，间距不大于 600 mm。

3. **主龙骨及副龙骨安装**
   - 主龙骨间距 900～1,200 mm，通过吊挂件悬挂在主龙骨上的吊杆上，并用主龙骨连接件接长。
   - 副龙骨（横撑龙骨）间距根据石膏板模数确定（600 mm），通过挂件挂在主龙骨下方。
   - 龙骨安装完毕后校正水平度，整体平整度偏差不大于 3 mm。

4. **石膏板安装**
   - 采用自攻螺钉将 600 × 600 mm 石膏板固定于副龙骨上，螺钉间距为 150～170 mm，钉头深入板面 0.5～1.0 mm，并做好防锈处理。
   - 相邻板块之间的接缝应错开排列，避免十字通缝。板与板之间留 3～5 mm 缝隙供嵌缝处理。
   - 遇灯具、风口等设备开口位置，应提前预留或切割准确，开口边缘整齐。

5. **嵌缝及接缝处理**
   - 石膏板铺设完成后对所有板缝采用专用嵌缝石膏和玻璃纤维网格带进行接缝处理，防止后期开裂。
   - 嵌缝膏饱满填满缝隙，网格带紧贴板缝铺平，随后再批刮薄层嵌缝石膏覆盖。

6. **质量要求**
   - 吊顶龙骨安装牢固，间距符合设计要求，无明显挠曲变形。
   - 石膏板表面平整、无破损、翘曲，接缝顺直严密。
   - 吊杆、龙骨及紧固件均经防锈处理。

## 7.7 铝合金扣板吊顶拆安工程

### 7.7.1 工程概况

| 项目 | 参数 |
|------|------|
| 工程名称 | 卫生间内铝合金扣板吊顶拆除及安装 |
| 拆除工程量 | 135 ㎡ |
| 安装工程量 | 4 ㎡（利旧回装） |
| 适用部位 | 卫生间内部 |

### 7.7.2 施工工艺

1. **铝合金扣板拆除**（135 ㎡）
   - 从一面墙角起板逐块拆卸，注意保护好龙骨骨架完整性以备后续回用。
   - 拆除过程中如遇龙骨锈蚀严重或变形的情况，单独记录并上报处理。
   - 拆下的扣板和龙骨分类码放，标识完好件和报废件，便于清点统计。

2. **龙骨检查及修复**
   - 对回收的三角龙骨或C型龙骨逐一检查，去除锈蚀、变形严重的部件并补充更换。
   - 安装新的边龙骨于四周墙体，间距 600 mm。

3. **扣板重新安装**（4 ㎡）
   - 在安装修复后的龙骨骨架上重新拼装铝合金扣板，拼缝均匀、板面平整。
   - 注意预留检修口、灯具口及设备接口位置。

> **说明：** 原方案对铝合金扣板吊顶的具体材质型号、防火等级等技术参数未予明确标注。施工中应根据设计图纸和厂家技术资料选定相应等级的扣板产品。

## 7.8 玻璃贴防爆膜工程

### 7.8.1 工程概况

| 项目 | 参数 |
|------|------|
| 工程名称 | 玻璃贴防爆膜 |
| 工程量 | 46.5 ㎡ |
| 适用范围 | 公共区域及临街面玻璃窗 |

### 7.8.2 施工工艺

1. **测量放线**
   - 实测每一块玻璃的尺寸并制作加工大样图，按照实际尺寸裁切防爆膜，预留每边 20～30 mm 的粘贴余量。

2. **玻璃基层处理**
   - 清除玻璃表面灰尘、油污和旧胶残留，用中性清洁剂清洗后晾干或擦拭干净。
   - 检查玻璃是否有裂纹或缺损，发现结构性破损应先更换或加固后再贴膜。

3. **防爆膜裁切与预贴**
   - 将裁切好的防爆膜按预定尺寸展开平铺于地面，正面朝上喷洒适量稀释皂液便于后续调整定位。
   - 撕除离型纸后立即将防爆膜对准玻璃表面贴上，利用喷雾器继续喷射安装液润滑以减少气泡生成。

4. **刮板排气、整平**
   - 用橡胶刮板从中心向四周逐步排尽膜内空气及液体，确保膜体与玻璃紧密贴合、无大气泡和折皱。
   - 对于转角部位仔细修剪多余部分，用热风枪轻微加热以增加柔性便于弯折。

5. **收边处理**
   - 用锋利美工刀沿玻璃边框修整多余防爆膜，使切口整齐美观。
   - 在边框处可使用透明结构胶固定膜边，防止后期翘边脱落。

6. **成品保护与验收**
   - 贴覆完成后 24 小时内不得启闭窗户或接触水汽，以便胶层充分固化。
   - 完工后逐扇检查有无气泡、翘边、划伤、异物夹杂等缺陷，不合格处立即返工修补。

> **说明：** 原方案中仅列出了玻璃贴防爆膜作为清单项和工程量（46.5 ㎡），但未提供具体的防爆膜材料规格、品牌型号、粘贴胶水品种及施工环境温湿控制要求。施工中应选用具备国家认证的合格产品并按照产品技术文件和相关规范细化执行。

## 7.9 质量控制要点汇总

结合原施工方案提出的质量控制要求，天棚及墙面翻新各工序的关键管控要点归纳如下：

| 序号 | 工序 | 质量控制要点 |
|:---:|------|-------------|
| 1 | 涂料铲除 | 铲除彻底至坚实基层；保护既有管线和固定件 |
| 2 | 墙面抹灰 | 13 mm 干混砂浆分层施工；平整度偏差 ≤ 4 mm |
| 3 | 界面剂 | 满涂不漏；形成均匀粗糙面 |
| 4 | 腻子批刮 | 满挂成品腻子 2 遍；打磨平整无刮痕 |
| 5 | 乳胶漆 | 底漆 1 遍 + 面漆 2 遍；涂层均匀无透底、流坠 |
| 6 | 石膏板吊顶 | 600×600 mm 同原厚；龙骨间距≤1.2 m；板缝错开 |
| 7 | 铝合金扣板 | 拆除保护龙骨；利旧回装平整度达标 |
| 8 | 玻璃防爆膜 | 基层清洁；刮气排尽气泡；收边整齐 |
