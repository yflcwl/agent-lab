## 三、施工总体安排

### （一）总体施工顺序

根据工程施工特点及各分项作业的逻辑关系，本工程的总体施工顺序为：

**施工打围 → 地下管线排障 → 不锈钢护栏拆除 → 人工清表 → 拆除杆塔挡土墙内地坪 → 拆除杆塔挡土墙外混凝土地坪 → 塌陷砖砌挡土墙拆除 → 挡土墙沟槽土方挖运 → 修边捡底 → 100厚C20垫层混凝土浇筑 → M10水泥砂浆370厚Mu15页岩砖砌筑基础砖 → M10水泥砂浆240厚Mu15页岩砖砌筑杆塔挡土墙 → 基础土方回填 → 杆塔内土方平整、夯实 → 地圈梁钢筋制安 → 地圈梁模板制安 → C20钢筋混凝土地圈梁浇筑 → 杆塔内100厚C20混凝土浇筑 → C30混凝土预制沟盖板制安 → 抹灰 → 外墙腻子+乳胶漆 → 黄黑警示油漆 → 不锈钢护栏利旧安装**

上述流程覆盖了从现场围挡设置到收尾安装的全链条工序，其中杆塔区域施工可能与主体消防站维修工程分开实施，具体按实际施工包划分执行。

### （二）各分项工程施工穿插原则

在杆塔区域之外的主体维修工程中，四大类施工内容的穿插遵循以下原则：

1. **先室外后室内**：外墙翻新及天棚墙面翻新优先展开，避免后续室内外交叉作业造成重复搭设和高空作业风险叠加。
2. **先隐蔽后饰面**：卫生间改造严格遵循"先管线后饰面、先防水后贴砖"的原则，防水层完工并闭水试验合格后进入地砖铺设和墙面饰面工序。
3. **先拆除后重建**：环氧地坪翻新须先完成原环氧层及混凝土楼地面的整体铲除，再进行固化地坪施工。
4. **利旧设施集中保管**：空调外机、卫生洁具、灯具热水器等设备统一编号拆卸后分类存放于材料仓库，待新饰面完成后统一安排利旧安装，减少二次搬运和损坏风险。

### （三）场地布置简述

施工现场采用 **2.5m 高轻钢龙骨彩钢板全封闭打围**，打围长度约 **36m**，对施工区域及周边影响范围进行有效隔离。围挡外观、材质及安全性能满足机场区域内的安全管理要求。材料仓库及加工房设于集中加工库房，板材、水泥、石膏腻子等易受潮材料做好防潮堆放措施。

施工区域内按每 **50㎡** 配备不少于两具 **3A级5KG干粉灭火器** 的标准设置消防设施，施工用电配备三级配电箱并落实用电安全防护。

## 四、质量保证要点

施工过程中严格执行以下质量保证措施：

1. **材料进场检验**。所有进场的材料（含辅材）必须符合设计要求和相关质量标准，未经检验或检验不合格的材料严禁使用。
2. **技术教育与交底**。施工人员进场前开展技术教育，确定专职质量员；施工前对各工种进行施工技术交底，明确工艺要求和质量控制标准。
3. **质量检查制度**。落实自检、互检、交接检及工序检查制度，严格工程工序管理，上道工序验收合格后方可进入下道工序。
4. **砖砌体工程质量控制**。如需涉及砖砌体工程，水平灰缝砂浆饱满度不得低于 **80%**，砖柱水平灰缝和竖向灰缝饱满度不得低于 **90%**；砖砌体的转角处和交接处应同时砌筑，抗震设防烈度为 **8度** 及以上地区严禁留直槎。
5. **质量验收要求**。确保工程检查验收一次通过。

## 五、安全生产管理

### （一）安全目标

施工全过程贯彻"安全第一、预防为主、综合治理"的方针，杜绝重大安全事故发生。针对本工程高空作业风险突出、多专业交叉作业频繁的特点，重点加强动火作业、临时用电作业和动土作业的安全管控。

### （二）三大危险作业保障

#### 1. 动火作业

- 严格执行动火作业审批制度，办理动火作业许可证，明确动火等级、地点、时间、人员及安全措施，未经审批严禁作业。
- 动火点 **10 米范围** 内清理易燃易爆物品，无法移除的采用防火毯、石棉板彻底隔离覆盖。
- 动火作业实行专人监护，监护人全程在岗不得擅离职守；特种作业人员必须持证上岗。
- 气瓶直立固定，间距不小于 **5 米**，距动火点不小于 **10 米**；高处动火采取接火盆、防火毯等防火花飞溅措施。
- 作业结束后留守监护 **30 分钟以上**，确认无复燃隐患后方可离开。

#### 2. 临时用电

- 临时用电系统做到 **"一机一闸一漏一箱"**，接地接零保护规范可靠。
- 潮湿、受限空间等危险区域使用安全电压（**≤36V**，特别潮湿 **≤12V**）。
- 电缆架空敷设或穿管保护，严禁碾压、拖拽、浸泡水中；配电箱上锁管理，非专业人员严禁操作。
- 停电作业执行 **"停电—验电—挂牌—上锁"** 制度。

#### 3. 动土作业

- 施工前组织管线产权单位对施工范围内现有地下管线进行确认及排障作业，对工长、班组长及工人进行安全技术交底，明确可能涉及的管线种类及走向。
- 沿原有挡土墙边线开挖探沟，探沟长 **36m**、宽 **0.8m**、深 **1m**，指派专人全程指挥跟进。
- 人工开挖若发现管线，应立即停止作业、做好标记、通知产权单位二次确认，经同意后方可继续施工。
- 出现管线受损情况时，第一时间向项目负责人及动能部项目负责人报告，由动能部联系所属单位排查恢复。

### （三）应急救援组织

成立以 **项目经理为组长**，**生产经理、技术负责人、安全负责人为副组长**，各部门负责人为成员的应急救援领导小组，下设抢险救援组、医疗救护组、后勤保障组和事故调查组，形成完整的应急响应体系。

应急预案适用于本工程施工过程中可能发生的各类安全事故应急处置，坚持"以人为本、安全第一"的处置原则。
