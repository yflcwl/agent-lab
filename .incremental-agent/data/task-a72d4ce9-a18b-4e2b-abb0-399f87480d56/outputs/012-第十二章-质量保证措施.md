# 第十二章 质量保证措施

## 第一节 工程质量目标与质量管理体系

### 一、工程质量总目标

本工程严格执行国家现行施工质量验收规范及《建筑工程质量管理条例》要求，确保各分项工程施工质量符合设计规范和相关质量标准。**工程检查验收一次通过**。具体质量目标包括：

- 材料进场合格率：所有进场的材料（含辅材）必须符合设计要求和相关质量标准
- 工序交接合格率：严格执行自检、互检、交接检制度，每道工序合格后方可进入下道工序
- 质量通病防治：重点防范外墙抹灰空鼓开裂、防水层渗漏、地坪起砂脱壳等常见质量问题
- 成品保护到位率：施工完毕后经专人检查并记录修补情况，确保交付质量

### 二、质量管理体系与组织职责

本工程质量管理体系在项目经理统筹领导下运行，实行分级负责、专兼职相结合的管理机制。根据施工组织设计中的人员配备，各岗位在质量工作中的具体职责如下表所示：

| 序号 | 职务 | 质量岗位职责 |
|------|------|-------------|
| 1 | 项目经理 | 统筹安排施工事宜，全面负责工程质量目标的落实 |
| 2 | 生产经理 | 现场组织和管理工作，协调各班组工序衔接，保障成品保护措施执行到位 |
| 3 | 技术负责人 | 编制施工方案及相关方案，组织施工技术交底，及时解决施工中出现的技术问题 |
| 4 | 安全负责人 | 进行隐患排查，确保施工质量与安全措施的协同落实 |
| 5 | 施工员 | 落实施工方案，协调相关事宜，严格工程工序管理 |

施工现场设置专职质量员，负责日常质量检查措施的落实。施工人员进场前做好技术教育和质量意识培训。

## 第二节 质量保证组织措施

### 一、人员管理与教育培训

- **进场教育**：在施工人员进场前做好技术教育，明确各分项工程的工艺要求和操作要点
- **技术交底**：施工前对全体施工人员进行施工技术交底，逐级落实到班组和个人
- **专职质量员**：施工中确定专职质量员，全程跟踪监督各道工序的施工质量

### 二、工序管理制度

认真执行**"三检制"**（自检、互检、交接检）及工序检查制度，具体要求为：

1. **自检**：每道作业面完成后由操作人员自行检查是否符合工艺要求
2. **互检**：同班组作业人员交叉检查相邻作业面的施工质量
3. **交接检**：上道工序向下一道工序移交时，双方共同确认是否满足转入下道工序的条件
4. **工序检查**：专职质量员对各隐蔽工程及关键节点进行专门检查验收

通过上述制度，确保每个检验批的施工作业均处于受控状态，保证工程检查验收一次通过。

### 三、奖罚机制

对施工质量管理和执行情况实行严格的奖罚制度，将质量指标与施工人员的经济利益挂钩，形成质量管理的正向激励约束机制。

## 第三节 质量保证技术措施

### 一、材料与设备质量保证

#### （一）材料进场检验

所有进场的材料（含辅材）必须符合设计要求和相关质量标准。主要控制环节包括：

| 控制环节 | 控制内容 |
|---------|---------|
| 资质审查 | 供应商应具备合法经营资格和产品合格证 |
| 外观检查 | 材料品种、规格、型号应符合设计要求 |
| 抽检复试 | 涉及结构安全和功能的重要材料按规定批次抽样复检 |
| 标识管理 | 进场材料分类存放，做好标识防止混用错用 |

#### （二）仓储保管措施

对于易受潮或需特殊存放的材料，应采取相应的防护存储措施：

- 板材、水泥、石膏腻子等易受潮材料堆放时，地面采用木方做基础垫高处理，防止受潮变质
- 其他零星材料设置金属货架整齐堆放，避免磕碰损坏
- 防水材料应严格按照产品说明书要求的环境条件存储

### 二、基层与工作面质量控制

#### （一）基层面要求

施工前必须在基层面满足要求后才能施工。各分项工程对基层的基本要求为：

| 分项工程 | 基层要求 |
|---------|---------|
| 外墙翻新 | 原抹灰层铲除清理干净，基层平整度偏差控制在规范允许范围内 |
| 天棚墙面 | 原涂料层/砂浆面层铲除至坚实基面，浮灰油污清除干净 |
| 车库地坪 | 原环氧层/破损混凝土地面清除至坚实基面 |
| 卫生间改造 | 原装饰层拆除后基层平整干燥，管槽预留位置正确 |
| 挡土墙区域 | 土方开挖人工清底，不得扰动原状土；基础底部承载力满足设计要求 |

#### （二）防水基层要求

卫生间涂膜防水层的基层应平整、洁净、干燥，阴阳角做成圆弧过渡，管根部位做加强处理，确保防水涂层粘结牢固。

### 三、施工过程质量控制

#### （一）总体技术要求

按照施工方案的要求逐项作业，严格控制以下关键环节：

1. **按方案施工**：严格按照审批通过的施工方案及工艺标准执行
2. **分层施工**：外墙抹灰必须分层施工，每层厚度不超过规范要求，避免空鼓开裂
3. **干燥等待**：涂装工序必须待前一道工序完全干燥后方可进行，严禁赶工强行交叉
4. **坡度控制**：车库地坪、卫生间找坡层做好坡度，确保排水通畅，防止积水
5. **振捣密实**：混凝土浇筑时充分振捣，确保密实度和强度达标

#### （二）重点工序控制

| 重点工序 | 控制要求 |
|---------|---------|
| 土方开挖与回填 | 人工清底，不得扰动原状土；分层夯实，压实度满足设计要求 |
| 砖砌体工程 | 砂浆饱满度≥80%，上下错缝砌筑，墙体垂直度偏差控制在规范允许范围内 |
| 钢筋工程 | 钢筋间距、保护层严格按方案执行，绑扎牢固无松动 |
| 防水涂膜层 | JS涂膜防水材料涂刷遍数、厚度均匀一致，节点附加层先于大面施工 |
| 饰面贴砖 | 面砖铺贴前充分浸泡，排砖预排，缝隙均匀饱满 |

### 四、改造工程专项技术措施

针对本工程为维修改造翻新项目的特点，特别注意以下质量风险的控制：

1. **隐蔽工程隐患识别**：改造翻新项目存在较多不可预见因素，特别是原有装饰层下可能存在隐蔽裂缝、渗水痕迹、结构损伤等问题，施工前应尽量探查清楚
2. **新旧界面衔接**：新做层与原结构的接缝处应做好界面处理，采取挂网抗裂等措施增强新旧材料的粘结力
3. **技术问题及时处置**：施工过程中出现的技术问题要及时上报并由技术负责人组织研究处理方案，不得擅自变更工艺

## 第四节 分项工程质量控制要点

### 一、外墙翻新工程质量控制

#### （一）保温层及旧抹灰层拆除

- 保温材料拆除过程中应轻拿轻放，防止大块脱落造成安全隐患
- 旧抹灰层铲除应铲至坚实基层，不得留有松散层

#### （二）新建抹灰层

- 抹灰前基层充分湿润
- 分层抹灰，每遍厚度控制在合理范围内
- 养护期不得提前上人踩踏
- 空鼓开裂专项检查：完成大面积抹灰后逐面敲击检查，发现空鼓处切割剔除后重新补抹

#### （三）防水涂膜层

- 基层含水率控制在规定范围内方可涂刷防水层
- 涂刷方向相互垂直，搭接宽度满足要求
- 闭水试验：防水层施工完成后进行蓄水试验，确认无渗漏后方可进入饰面层施工

#### （四）真石漆饰面层

- 腻子层打磨平整，无划痕流坠
- 底漆涂刷均匀封闭
- 真石漆喷涂压力稳定，纹理一致，色差控制在允许范围内
- 罩面漆喷涂均匀，光泽一致

### 二、天棚及墙面翻新工程质量控制

#### （一）涂料拆除与基层处理

- 原涂料层彻底铲除至坚实基面
- 混合水泥砂浆面层铲除应保证基层不受破坏
- 浮灰、油污清除干净，必要时用清水冲洗晾干

#### （二）抹灰找平

- 不同基面交接处应按规范要求挂钢丝网防裂
- 抹灰层平整度、垂直度使用靠尺检测控制
- 阴阳角方正度偏差符合规范要求

#### （三）乳胶漆饰面

- 满刮成品耐水型腻子两遍以上，每遍干透后方可进行下一遍
- 第一遍底漆+两遍面漆（一底两面）
- 乳胶漆颜色均匀一致，无明显刷纹流坠

### 三、车库环氧/固化地坪工程质量控制

#### （一）基层清理与修复

- 原环氧层铲除至坚实基面
- 混凝土病害区域切割剔凿后采用高强修补砂浆修复
- 地坪表面打磨抛丸处理，增加表层粗糙度

#### （二）密封固化剂施工

- 固化剂溶液均匀喷洒于洁净基面
- 自然渗透反应时间满足产品技术要求
- 机械抛光至镜面效果

#### （三）质量检查

- 固化层与基层粘结牢固，无空鼓脱落
- 地坪表面色泽均匀，光泽度一致
- 坡度准确，地漏周边排水通畅无积水

### 四、卫生间改造工程质量控制

#### （一）防水层施工

- JS涂膜防水层按方案要求的遍数和厚度施工
- 管根、地漏、墙角等薄弱部位预先做附加层
- 防水层高度：淋浴区墙面不低于1800mm，其余部位不小于300mm
- 防水层完成后进行不少于24h的闭水试验

#### （二）内墙面砖铺贴

- 面砖吸水率、规格、颜色一致
- 铺贴粘结饱满，空鼓率控制在规范允许范围内
- 砖缝横平竖直，勾缝密实饱满

#### （三）铝合金扣板吊顶

- 吊杆间距及龙骨安装符合方案要求
- 扣板板块尺寸整齐，接缝严密顺直
- 灯具风口位置准确，收口美观

### 五、挡土墙及杆塔区域工程质量控制

#### （一）土方开挖与基础垫层

- 沟槽土方开挖人工清底，严禁超挖扰动原状土
- C20混凝土垫层浇筑厚度均匀，表面平整

#### （二）Mu15页岩砖砌筑工程

- Mu15页岩砖及M10水泥砂浆的进场复试符合要求
- 砂浆饱满度≥80%，采用百格网检查
- 组砌方法正确，内外搭砌，上下错缝
- 清水墙窗间墙无通缝；混水墙中不得有长度大于300mm的通缝

#### （三）地圈梁及压顶

- 钢筋规格、间距、保护层厚度严格按图纸要求
- 混凝土坍落度适中，振捣密实无蜂窝麻面
- 压顶标高及线形顺直

#### （四）C30预制沟盖板安装

- 安装前检查边角完整性
- 就位水平，板缝均匀
- 安装后整体平整度偏差在允许范围内

### 六、不锈钢护栏利旧安装质量控制

- 拆除阶段做好成品保护，栏杆部件编号标记防止混装错位
- 安装前检查构件变形情况，有变形的先行校正修复
- 安装保证牢固、顺直，焊缝饱满连续，防腐处理到位

## 第五节 成品保护措施

### 一、成品保护的总体要求

为避免和移动重型机械设备对已完工程造成的损害，尽可能避免交叉作业，以防其他人员破坏。制定专门的成品保护方案和值班巡检制度。

### 二、分项成品保护措施

| 已完分项 | 保护措施 |
|---------|---------|
| 外墙真石漆面 | 设警示围挡禁止触碰，脚手架拆除时轻拿轻放不刮擦墙面 |
| 天棚乳胶漆面 | 后续管线安装尽量采用明敷方式减少高空作业，必要时铺设防护垫 |
| 车库固化地坪 | 设置限载标识，固化层完全熟化前严禁车辆驶入 |
| 卫生间瓷砖面 | 铺贴完成后24h内禁止踩踏，养护期内禁止后续工种穿行 |
| 挡土墙砌筑体 | 养护期内防止碰撞，压顶完成后至回填前设置临时围栏 |
| 不锈钢护栏 | 利旧安装就位后进行二次检查螺栓紧固情况 |

### 三、巡检与修补制度

- **值班制度**：施工现场安排专职人员进行日常值班巡逻
- **损坏标识**：发现有不慎损坏的部位，应及时标识并立即通知相关值班施工人员进行修补
- **修补记录**：施工完毕后，应由专人检查修补情况并做记录，形成闭环管理

## 第六节 质量检验与验收标准

### 一、质量检验制度

本工程质量检验按下列程序组织实施：

1. **检验批验收**：每一分项工程的每个检验批施工完毕后，由施工员自检、质量员复查合格后报监理验收
2. **隐蔽工程验收**：被下道工序覆盖前必须经建设单位/监理单位验收确认，并形成书面验收记录
3. **分项工程验收**：检验批全部合格后进入分项工程验收
4. **竣工验收**：所有分项工程验收合格后组织单位工程竣工验收

### 二、砖砌体工程质量允许偏差

砖砌体尺寸、位置的允许偏差及检验应符合现行规范《砌体结构工程施工质量验收规范》GB50203-2011的相关规定，具体参数如下表所示：

| 项序 | 项目 | 允许偏差(mm) | 检验方法 |
|------|------|-------------|---------|
| 1 | 轴线位置偏移 | 10 | 用经纬仪复测或拉线和尺量检查 |
| 2 | 基础和墙顶面标高 | ±15 | 用水准仪和尺量检查 |
| 3 | 垂直度 | ≤5m：5<br>＞5m：10 | 用2m托线板检查 |
| 4 | 表面平整度 | 8 | 用2m靠尺和楔形塞尺检查 |
| 5 | 水平灰缝平直度 | 10 | 拉10m线和尺量检查 |
| 6 | 门窗洞口宽高 | ±5 | 尺量检查 |
| 7 | 外墙上下窗口偏移 | 20 | 用经纬仪或吊线尺量检查 |

**注**：原文未提供完整的允许偏差全表数据，上表按现行国标常用值整理列出，实际施工以设计图纸和 GB50203-2011 条文为准。

### 三、灰缝厚度控制

水平灰缝厚度宜为 10mm，不应小于 8mm，也不应大于 12mm。竖向灰缝宽度同样控制在 8~12mm 范围内。

### 四、砂浆饱满度检查

- 采用百格网检查法，每检验批抽查不少于 5 处
- 砖砌体的水平灰缝砂浆饱满度不得低于 80%
- 凡不满 80% 的部位视为不合格，须返工重砌

### 五、混凝土工程质量控制

- 混凝土坍落度符合配合比设计要求
- 振捣密实，无蜂窝麻面和孔洞
- 表面平整度偏差控制在规范允许范围内
- 养护措施及时到位

## 第七节 质量通病防治措施

### 一、外墙抹灰空鼓开裂防治

| 产生原因 | 预防措施 |
|---------|---------|
| 基层未清理干净 | 抹灰前充分铲除旧层并清洗干净 |
| 基层过于干燥 | 抹灰前适量洒水湿润基层 |
| 单层抹灰过厚 | 分层施工，每层厚度控制合理 |
| 不同基面交接处未挂网 | 新旧墙体交接处、线槽回填处加挂钢丝网，每边搭接宽度不小于 150mm |
| 养护不及时 | 抹灰层终凝后及时喷水养护，养护期不少于 7d |

### 二、防水层渗漏防治

| 产生原因 | 预防措施 |
|---------|---------|
| 基层含水率过大 | 防水施工前测定基层含水率，达到要求后再施工 |
| 节点附加层遗漏 | 管根、阴阳角、地漏周边等节点部位必须先做附加层 |
| 涂刷遍数不足或厚度不够 | 按设计方案规定的遍数和厚度施工，严禁偷减遍数 |
| 闭水试验遗漏 | 防水层固化后必须进行不少于 24h 的闭水试验确认无渗漏 |

### 三、地坪起砂脱壳防治

| 产生原因 | 预防措施 |
|---------|---------|
| 基层疏松未处理 | 老化的地坪面层彻底铲除，露出坚实基面 |
| 配比失控 | 严格按实验室出具的配合比拌合砂浆和混凝土 |
| 养护不到位 | 地面工程完成后及时覆盖养护，养护期间不得上人 |
| 环境温湿度超标 | 施工环境温度不低于 5℃，相对湿度不宜过高 |

### 四、面砖空鼓脱落防治

| 产生原因 | 预防措施 |
|---------|---------|
| 面砖未浸水润湿 | 陶瓷面砖铺贴前应充分浸泡至不再冒气泡后捞出晾干的备用 |
| 粘结砂浆不均匀 | 采用揉压法铺贴，确保背面浆料饱满 |
| 勾缝不及时 | 铺贴完成 24h 后及时勾缝，防止雨水渗入导致空鼓扩大 |

## 第八节 质量记录与档案管理

### 一、质量记录内容

本工程施工全过程应留存以下质量记录和档案资料：

1. 材料进场检验记录及合格证、出厂检测报告
2. 隐蔽工程验收记录（含影像资料）
3. 施工技术交底记录
4. 自检、互检、交接检记录
5. 检验批、分项工程质量验收记录
6. 闭水试验、蓄水试验记录
7. 值班巡检和成品保护巡查记录
8. 质量问题及处理记录
9. 竣工验收资料

### 二、竣工交付

各项质量验收记录齐全完整后方可申请竣工验收。竣工后及时向建设单位移交完整的质量管理档案资料。
