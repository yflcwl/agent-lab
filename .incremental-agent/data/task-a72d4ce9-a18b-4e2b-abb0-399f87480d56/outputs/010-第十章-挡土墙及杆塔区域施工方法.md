# 第十章 挡土墙及杆塔区域施工方法

## 10.1 工程概况

### 10.1.1 工程位置及背景

本次维修工程位于双流机场110kV羊航线1#杆塔处，施工区域邻近高压电力设施。工程内容包括对1#杆塔6 m × 6 m范围地面进行硬化、更换损坏沟盖板以及修复塌陷挡土墙。拟采用2.5 m轻钢龙骨彩钢板对施工及影响区域进行全封闭打围，打围长度约36 m，施工作业时段为8:00—18:00。

该区域紧邻110 kV输电线路，施工全过程须严格注意与带电设备的安全距离，做好停电监护或安全隔离措施（具体电气安全距离要求详设计及供电部门规定）。

### 10.1.2 主要工作内容

| 序号 | 工作项目 | 主要内容 |
|------|----------|----------|
| 1 | 不锈钢护栏保护性拆除 | 编号分类、妥善保管，利旧恢复 |
| 2 | 场地清表及地坪拆除 | 清除杂草腐殖土，拆除内外侧原有混凝土地坪 |

## 10.2 施工总体流程

本分部工程整体遵循"先拆后建、先地下后地上、先结构后装饰"的原则施工。各工序之间紧密衔接，前一道工序验收合格后方可进入下一道。

```
不锈钢护栏保护性拆除 → 场地清表 → 内外侧混凝土地坪拆除 
→ 旧挡土墙人工拆除 → 探沟开挖及管线排查 → 沟槽土方人工开挖 
→ 基底修整夯实 → C20混凝土垫层浇筑 → Mu15页岩砖基础砌筑 
→ Mu15页岩砖挡土墙砌筑 → 基础外侧素土分层回填夯实 
→ 杆塔内场地平整找坡 → 地圈梁钢筋制安 → 地圈梁模板支设 
→ C20地圈梁浇筑 → 杆塔内钢筋网铺设 → C20钢筋混凝土地坪浇筑 
→ C30预制沟盖板吊装就位 → 挡土墙外立面抹灰 → 界面剂 + 外墙腻子 
→ 一底两面外墙乳胶漆 → 黄黑相间警示漆 → 不锈钢护栏利旧安装 → 清理收尾
```

## 10.3 前期拆除及场地清表

### 10.3.1 不锈钢护栏保护性拆除

1. 拆除前对现有不锈钢护栏进行全面编号，按段落分类标记并堆放于指定区域，确保保管过程中不发生变形或划伤。
2. 采用手工工具配合便携式切割机缓慢拆卸连接节点，避免暴力拆解造成结构性损伤。
3. 拆除后的护栏组件集中存放，由专人负责成品保护，作为后续利旧安装的备件储备。

> **质量控制要点：** 拆除全过程做好影像记录，编号台账清晰可追溯，确保利旧安装时能够精准定位归位。

### 10.3.2 场地清表

人工清除施工区域内的杂草、腐殖土、垃圾杂物及其他影响后续施工的表层松散材料，将表层浮土一并清理干净，直至露出坚实土层。清表作业覆盖整个围挡范围内约36 m长的工作面。

### 10.3.3 内外侧混凝土地坪拆除

使用电镐人工分段拆除挡土墙内侧及外侧原有的混凝土地坪。拆除过程应逐段推进，不得大面积同时破碎以防意外坍塌。混凝土碎渣集中堆放后装车外运，严禁随意抛洒污染周边环境。

### 10.3.4 旧挡土墙拆除

1. 人工拆除已经塌陷、开裂的旧砖砌挡土墙，**自上而下逐层拆砖**，严禁掏掘底部导致墙体突然大面积坍塌。
2. 拆除过程中随时观察相邻未拆部位的稳定性，必要时增设临时支撑。
3. 拆下的完好砖块分类回收备用，废渣随建筑垃圾一并外运处置。

## 10.4 探沟开挖及管线排查

### 10.4.1 探沟开挖技术要求

施工区域临近110 kV电力设施且地下可能存在各类管线，在正式沟槽开挖前必须先行探明地下管线分布情况。

1. **探沟位置及尺寸：** 沿现有挡土墙边线人工开挖探沟，总开挖长度约36 m，沟宽0.8 m，深1 m。
2. **开挖方式：** 必须采用人工手铲挖掘，**严禁使用十字镐、钢钎等冲击型工具开挖探沟**，以最大限度降低破坏既有管线的风险。
3. **专人守护：** 开挖过程由专人现场值守，发现任何异常情况立即停止作业。
4. **管线保护：** 当探沟开挖至基础底标高深度仍未发现管线时，方可签署书面确认文件并进入下一步施工作业。

### 10.4.2 管线异常处理程序

1. 若在开挖中发现地下管线，应立即报告现场负责人，暂停该区域一切作业。
2. 轻轻扩宽暴露范围，小心探明管线的种类、规格、根数、走向和埋设深度，并做好位置标记。
3. 对管线状况进行影像留底并编制书面记录。
4. 请监理单位人员现场确认，通知产权单位对管线进行二次复核和保护措施制定。
5. 未经产权单位和监理联合确认之前，不得擅自继续施工。

### 10.4.3 裸露管线防护措施

对已探明的裸露管线采取包裹防护和支托加固措施，防止后续沟槽开挖及回填过程中的扰动损伤。保护措施完成后设置醒目的禁入标志牌。

## 10.5 沟槽土方开挖与基底处理

### 10.5.1 沟槽土方挖运

1. 按照挡土墙基础边线人工开挖基槽，基槽宽度按0.8 m控制。
2. 开挖出的土方就近堆放在围挡内场地指定区域，堆放高度不宜超过1.5 m，距槽边不小于0.5 m，防止荷载过大使槽壁坍塌。
3. 多余渣土及时装车外运，保持场内整洁通畅。

### 10.5.2 修边捡底及基底处理

1. 人工修整沟槽边坡，使坡面平顺无凹凸突变。
2. 清理槽底浮土、淤泥及有机杂质，确保基底土质均匀密实。
3. 将基底夯实平整，用轻便夯具全线碾压一遍，保证基底平整度满足垫层浇筑的规范要求。
4. 基底验收合格后应及时浇筑垫层，避免基底长时间暴露在空气中受雨水浸泡或风化。

## 10.6 C20混凝土垫层施工

### 10.6.1 材料与构造要求

| 项目 | 参数 |
|------|------|
| 混凝土强度等级 | C20 |
| 垫层厚度 | 100 mm |
| 垫层宽度 | 570 mm（每侧超出基础边线100 mm） |

### 10.6.2 施工工艺

1. **支模：** 在验槽合格的基底上弹设垫层边线，安装侧向模板，模板顶面标高中控制垫层厚度为100 mm，加固牢靠防止跑模。
2. **浇筑：** 采用商品混凝土或现场搅拌C20混凝土，倒入模内后用插入式振捣棒或木杠振捣密实。
3. **找平收光：** 刮杠刮平表面后使用铁抹子搓平收光，确保垫层表面平整，无积水坑洼。
4. **养护：** 浇筑完成后自然养护不少于24 h，期间禁止上人踩踏。

## 10.7 Mu15页岩砖砌筑工程

### 10.7.1 材料要求

| 项目 | 参数 |
|------|------|
| 基础砌筑砖材 | Mu15页岩砖 |
| 墙身砌筑砖材 | Mu15页岩砖 |
| 砌筑砂浆 | M10水泥砂浆 |
| 基础厚度 | 370 mm（一砖半墙） |
| 墙身厚度 | 240 mm（一砖墙） |

所用Mu15页岩砖应具备出厂合格证，进场后抽样复检抗压强度合格后方可使用。M10水泥砂浆应按实验室配合比拌制，稠度控制在70～90 mm之间。

### 10.7.2 砖基础砌筑

1. **放线定位：** 待C20垫层达到一定强度后，在垫层顶面弹出基础中心线和边线。
2. **摆砖撂底：** 按组砌方式试摆第一皮砖，调整灰缝宽度，确保上下错缝、内外搭砌。
3. **盘角挂线：** 先在四角或转角处立皮数杆、盘角，然后通小线控制基础顶面标高和纵向水平度。
4. **砌筑操作：** 采用"三一"砌筑法（一铲灰、一块砖、一揉挤），做到灰缝饱满、通缝错开。砂浆饱满度不应低于80%。
5. **高度控制：** 基础总砌筑高度为0.9 m，砌筑过程中随时用水准仪校核标高，基础顶面应做找平处理。

### 10.7.3 挡土墙墙身砌筑

1. 在基础顶面弹设墙体边线，立皮数杆控制墙身标高。
2. 采用M10水泥砂浆砌筑240 mm厚Mu15页岩砖挡土墙，墙身自基础顶面向上砌筑，**总墙高1.2 m**（详见第10.1.3节注①说明）。
3. 砌筑过程中随时用线锤和靠尺检查墙体垂直度和表面平整度，偏差控制在规范允许范围内。
4. 每日砌筑高度不宜超过1.5 m，以保证砂浆充分凝结稳固。
5. 墙体交接处应同时砌筑，如必须留槎时应留设斜槎，斜槎水平投影长度不应小于高度的2/3。

### 10.7.4 压顶钢筋混凝土施工

| 项目 | 参数 |
|------|------|
| 压顶截面尺寸 | 240 mm × 200 mm |
| 混凝土强度等级 | C20 |
| 主筋 | 4Φ12 |
| 箍筋 | Φ8 @ 200 |

1. **钢筋制安：** 按设计间距弯制箍筋，绑扎4根Φ12主筋，保证搭接长度与锚固长度符合《混凝土结构设计规范》要求。
2. **模板制安：** 采用钢模板支设压顶侧模，加固牢靠防止涨模、漏浆。模板内侧面涂刷脱模剂以利拆模。
3. **混凝土浇筑：** 浇筑C20混凝土，振捣密实用抹刀整平顶面，拆模后保湿养护不少于7天。

## 10.8 基础回填与杆塔内场地平整

### 10.8.1 基础外侧土方回填

1. 挡土墙砌筑完成并经自检合格后，即可开展基础外侧的回填作业。
2. 回填材料选用优质素土，**严禁夹杂有机物、冻土块及大粒径石料**。
3. 采用分层回填方式，**每层虚铺厚度不大于300 mm**，使用手动或小型机械夯实工具分层碾压夯实，压实系数需满足设计要求。
4. 回填至原地面标高后复核回填面上高程，确保与周边地形顺接。

### 10.8.2 杆塔内场地平整找坡

1. 清理杆塔区域内回填土，人工整平后分层碾压夯实。
2. 按设计要求找2%排水坡度，坡向宜朝向杆塔外围方向，确保地表水顺利排出，不向内积聚。
3. 平整完成面应无明显车辙、凸凹，为后续混凝土地坪浇筑提供良好基层。

## 10.9 C20钢筋混凝土地圈梁施工

地圈梁沿挡土墙内侧基础顶部周圈设置，起到增强整体结构刚度、防止不均匀沉降的作用。

### 10.9.1 钢筋制安

1. 按设计尺寸下料，主筋采用4根Φ12 HRB级别钢筋，箍筋直径Φ8、间距200 mm。
2. 现场绑扎成笼状骨架，主筋搭接长度及锚固长度严格按《混凝土结构工程施工质量验收规范》执行。
3. 钢筋保护层垫块间距不超过800 mm，确保钢筋有效埋置深度。

### 10.9.2 模板支设

1. 采用钢模板拼装，接缝处粘贴双面胶带防漏浆。
2. 外侧利用基坑壁作临时侧模或加设斜撑加固，内侧独立支模，防止胀模、跑模。
3. 支模完成后复核断面尺寸及轴线位置，偏差控制在±5 mm以内。

### 10.9.3 混凝土浇筑与养护

1. 浇筑C20混凝土，插入式振捣棒分层振捣，每层厚度不大于500 mm。
2. 振捣时插点均匀布置，快插慢拔，避免漏振或过振。
3. 顶面用木抹搓平，拉毛处理以利与上部地坪结合。
4. 浇筑完毕终凝后覆盖浇水保湿养护，养护期不少于7天。

## 10.10 杆塔内100 mm厚C20钢筋混凝土地坪施工

### 10.10.1 构造参数

| 项目 | 参数 |
|------|------|
| 面层混凝土 | C20细石混凝土 |
| 面层厚度 | 100 mm |
| 钢筋网片 | Φ8 @ 150，单层双向 |
| 排水坡度 | 2%（坡向外侧） |

### 10.10.2 施工工艺

1. **钢筋网片铺设：** 按150 mm网格间距铺设Φ8双向钢筋网片，钢筋交叉点用铁丝绑扎牢固。钢筋下设混凝土垫块（厚度约30～40 mm），确保网片位于地坪中部偏上的有效受力位置，防止浇筑时网片下沉贴底。
2. **分格跳仓浇筑：** 按3 m × 3 m左右面积划分浇筑区块，逐块跳仓施工，减少收缩裂缝。
3. **振捣与找平：** 用平板振捣器振捣密实，随即用刮杠按2%坡度刮平。
4. **压光收面：** 初凝前用铁抹子进行三遍压光（初压→复压→终压），确保表面平整致密，无砂眼、起砂现象。
5. **养护：** 覆盖薄膜或湿草帘保湿养护，养护期不少于7天。养护期间严禁上人踩踏或堆放重物。

> **质量控制要点：** 地坪完成后进行泼水试验检验2%排水坡度，确认无局部积水后方可验收。

## 10.11 C30预制混凝土沟盖板制作与安装

### 10.11.1 构造参数

| 项目 | 参数 |
|------|------|
| 混凝土强度等级 | C30 |
| 外形尺寸 | 100 mm（厚） × 500 mm（宽） × 1 000 mm（长） |
| 配筋 | Φ12 @ 150，单层双向 |
| 制作方式 | 预制场加工 |

### 10.11.2 预制制作

1. 在集中预制场按设计尺寸定制钢模具，模具内涂刷脱模剂。
2. 绑扎Φ12 @ 150单层双向钢筋网，下放垫块保证保护层厚度。
3. 浇筑C30混凝土，振捣密实，顶面抹平压光。
4. 自然养护至设计强度75%以上方可吊出模具堆放。

### 10.11.3 吊装安装

1. 盖板运输采用人工抬运或小推车运输，防止碰撞缺棱掉角。
2. 安装时人工吊装就位，板端搭接宽度不小于50 mm。
3. 铺设平整后用水平尺逐个校验，板间缝隙用1:2.5水泥砂浆填塞饱满。
4. 盖板顶面应与周边地坪标高一致，不得凸起或凹陷。

## 10.12 挡土墙外立面装饰涂装工程

### 10.12.1 施工工艺流程

```
基层清理 → 浇水湿润 → 15 mm厚1:3水泥砂浆两遍抹灰 
→ 满刷界面剂1遍 → 批刮外墙耐水腻子2遍 → 打磨平整 
→ 外墙底漆1遍 → 外墙面漆2遍 → 黄黑相间警示漆
```

### 10.12.2 水泥砂浆抹灰

1. 挡土墙及混凝土压顶基层全面清理干净，铲除浮灰、油污及松动颗粒。
2. 抹灰前一日对墙面均匀浇水湿润，使基层充分吸水但施工时基面无明水积存。
3. **分两遍抹15 mm厚1:3水泥砂浆，两遍成活：** 第一遍打底找平约8～10 mm厚，第二遍找平收光约5～7 mm厚。
4. 抹灰表面应平整顺直，阴阳角方正，无空鼓、裂缝、起砂现象。
5. 抹灰完成后洒水养护，养护期不少于7天。

### 10.12.3 界面剂及外墙腻子

1. 抹灰层自然干燥至含水率低于10%后，满刷界面剂1道，涂刷均匀不漏刷。
2. 批刮2遍外墙耐水腻子，首遍以找平为主，二遍精细收面。每遍间隔时间应根据环境温湿度及产品说明确定，一般不少于4 h。
3. 腻子层打磨平整后用扫帚或吸尘设备清除浮灰。

### 10.12.4 外墙乳胶漆

1. **底漆：** 涂刷水性外墙封闭底漆1遍，作用为封闭腻子层、增强面漆附着力。
2. **面漆：** 涂刷高性能外墙面漆2遍，采用滚涂或喷涂工艺，色泽均匀、无流挂、无色差。
3. 每次涂刷均应待前一道涂层完全干燥后进行。

### 10.12.5 黄黑相间警示油漆

1. 在挡土墙外立面及混凝土压顶的显著位置，分块涂刷黄黑相间警示油漆，用以提醒过往人员和车辆注意安全。
2. 警示线条宽度均匀、顺直规整，色泽饱满一致。
3. 涂刷范围及色带宽度按现场实际和设计示意确定。

> **干燥间隔强调：** 原方案明确"涂装工序必须待前一道工序完全干燥后方可进行"，各涂层间间歇时间应在实际施工中根据气象条件灵活掌握，雨天或相对湿度大于85%时不得进行涂装作业。

## 10.13 不锈钢护栏利旧安装及收尾

### 10.13.1 护栏修复

对前期编号拆除的不锈钢护栏逐段检查，对锈蚀严重部位进行打磨除锈，对接头松动处进行补焊加固，恢复其结构完整性和外观美观度。

### 10.13.2 原位安装

1. 按照拆除时的编号及定位记录，将修复后的护栏逐段安装回原位置。
2. 采用化学锚栓或预埋件固定支架，焊接节点满焊并进行防锈涂层处理。
3. 安装完成后校核整体直线度和竖向平整度，确保牢固顺直。

### 10.13.3 清理收尾

1. 清运全部建筑垃圾及剩余废弃材料，恢复场地整洁。
2. 拆除施工围挡范围内的临时设施，撤出机械设备。
3. 会同建设单位、监理单位对挡土墙及附属设施进行全面联合验收，填写完工记录。

## 10.14 质量控制要点汇总

| 序号 | 工序 | 质量控制要点 |
|:---:|------|-------------|
| 1 | 探沟开挖 | 人工手铲挖掘，禁用十字镐/钢钎；发现管线立即停工上报 |
| 2 | 沟槽开挖 | 基槽宽0.8 m；人工清底不得扰动原状土 |
| 3 | 垫层浇筑 | C20混凝土，厚100 mm宽570 mm；振捣密实、表面找平 |
| 4 | 砖砌筑工程 | 灰缝饱满度≥80%；上下错缝；墙体垂直度偏差控制在规范范围内 |
| 5 | 基础回填 | 分层素土回填，每层≤300 mm，分层夯实至原地面标高 |
| 6 | 钢筋制安 | 间距、保护层严格按方案执行；搭接与锚固符合规范 |
| 7 | 混凝土浇筑 | 振捣密实；地坪做好2%坡度防积水 |
| 8 | 抹灰层 | 分层施工共15 mm厚；避免空鼓开裂；养护≥7天 |
| 9 | 涂装体系 | 前一道工序完全干燥后方可进行下一道；雨天湿度＞85%不得施工 |
| 10 | 护栏安装 | 利旧修复后原位安装，固定牢固、顺直美观 |
| 11 | 沟盖板 | 安装平稳无缝隙高低差；缝内砂浆填塞饱满 |
