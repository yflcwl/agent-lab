# 第六章 外墙翻新施工方法 - 章节记忆

## 摘要
本章详细描述了外墙翻新工程的全部施工工艺，从基层处理到真石漆喷涂完成，共包含12个主要分项：保温层拆除、抹灰涂料拆除、基层修补、界面剂、素水泥浆、25mm干混砂浆抹灰、抗裂砂浆+网格布（4mm）、JS防水1.5mmⅡ型、耐水腻子2遍、真石漆喷涂（底漆→中层→罩面）、铝塑板幕墙安装（60×3龙骨/600间距/4mm铝板）及挑檐屋面防水（3涂一布≥2.0mm）。

## 关键参数来源
- **PDF工程量清单**：所有材料类型、厚度、工程量数据均来自项目特征描述
- **DOCX施工方案**：质量控制要点来自方案中第7项"质量控制要点"第(4)条
- 未明确参数处已用提示性文字标注不虚构

## 重要约束
- 抹灰必须分层施工（每层7-10mm），总厚25mm
- JS防水两遍涂刷方向须垂直交叉
- 涂层间干燥时间严格要求
- 网格布搭接≥100mm，转角增设45°加强网
