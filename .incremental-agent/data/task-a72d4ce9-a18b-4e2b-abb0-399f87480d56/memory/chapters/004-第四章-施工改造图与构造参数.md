# 第四章记忆：施工改造图与构造参数

## 摘要
本章系统梳理了消防站维修工程四大类维修内容（外墙翻新、天棚及墙面翻新、车库地面翻新、卫生间翻新）的详细构造参数和分层做法，以及挡土墙/杆塔区域的完整结构尺寸与配筋数据。

## 关键事实（来源确认）
- **数据来源**：`sources/双流机场东消防站维修工程项目清单-背景资料.pdf` 的分部分项工程"项目特征描述"列；`sources/双流机场东消防站维修工程施工方案-背景资料.docx` 的"主要构造参数"表。
- **挡土墙矛盾**：原文一处写墙高1.2m，另一处施工步骤中写0.4m，已在正文中明确标注建议与设计方核实。
- **车库"环氧"实际为固化地坪**：工程量名虽叫"车库环氧地面翻新"，但实际做法是C30混凝土250mm+密封固化剂五次研磨+三次抛光，无环氧涂层体系。
- **外墙九层构造**：基层→界面剂→素水泥浆→25mm干混砂浆抹灰→抗裂砂浆+网格布(4mm)→JS防水1.5mm→耐水腻子2遍→真石漆喷涂→罩面保护漆。
- **建筑面积/总层数/檐口高度等建筑基本参数**：原资料仅标注"详设计"，具体数值未找到，正文中以"详设计"表述处理。

## 术语统一
- JS涂膜防水：卫生间及外墙防水材料
- 固化地坪：车库地面实际工艺，非传统环氧涂层
- 3涂一布：聚氨酯防水聚合物丙烯酸防水涂料体系
- 370厚Mu15页岩砖：挡土墙基础厚度
- M10水泥砂浆：挡土墙砌筑用砂浆等级
