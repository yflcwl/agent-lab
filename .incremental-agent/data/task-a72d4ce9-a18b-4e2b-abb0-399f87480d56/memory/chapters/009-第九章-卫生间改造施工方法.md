# 第九章 卫生间改造施工方法（章节记忆）

## 摘要
本章为双流机场东消防站维修工程中二楼战斗员宿舍卫生间翻新的完整施工方法描述。涵盖从全部拆除→管道暗埋→基层找平→JS涂膜防水→面砖铺贴→吊顶恢复→洁具设备安装的完整工序流程，共计23项清单项，分部小计造价63,455.05元。

## 关键参数（事实来源：项目清单PDF offset ~7098~10052）
- **工程量**：地砖35.720㎡、墙砖165.840㎡、铝合金扣板吊顶拆安135.450㎡、JS涂膜防水地面/墙面各35.720/165.840㎡、PPR DN25给水管暗埋100m、蹲便器利旧7组+新装3组等
- **防水材料**：(JS)防水涂料Ⅱ型，厚度1.5mm，需闭水试验24h
- **地砖规格**：300×300防滑地砖，厚12mm，20mm水泥砂浆粘接层
- **面砖规格**：300×600内墙面砖，厚10mm，25mm厚1:2.5干硬性水泥砂浆结合层
- **排水坡度**：1%坡向地漏，最薄处20mm
- **吊顶**：项目名称"铝合金扣板吊顶拆安"但特征描述面层为"600×600石膏板"，属清单编制不一致
- **管道材质**：PPR DN25，暗埋敷设，热熔连接，水压试验≥0.6MPa稳压1h降≤0.05MPa
- **利旧设备**：热水器挂式RS50型、淋浴器成套手动、吸顶灯、蹲便器7组
