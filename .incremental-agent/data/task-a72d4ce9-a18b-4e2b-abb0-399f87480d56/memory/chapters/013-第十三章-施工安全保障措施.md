# 第十三章 施工安全保障措施 — 章节记忆

## 摘要
本章围绕施工现场安全管控建立完整体系，涵盖安全管理组织架构（5人核心管理组）、安全技术交底制度（入场/临电/动土/特种四类交底）、四大专项保障措施（动火作业三级管控+临时用电"一机一闸一漏一箱"+动土开挖管线防护）、高处作业安全防护、机械设备安全管理、劳动防护用品管理、交叉作业协调和安全检查隐患排查十个方面。

## 关键参数
- **动火安全距离**：易燃物清理10米内 / 气瓶间距≥5米 / 气瓶距动火点≥10米 / 留守监护≥30分钟
- **用电参数**："一机一闸一漏一箱" / 安全电压≤36V（特别潮湿≤12V）/ 三级配电箱 / "停电—验电—挂牌—上锁"
- **消防配置**：施工区每50㎡或每15米半径≥2具3A级5KG干粉灭火器 / 库房每15㎡设2具3A级5KG / 动火点额外配2具4A级8KG
- **探沟规格**：长36m、宽0.8m、深1m
- **围挡尺寸**：全长36m、高2.5m
- **登高设备**：登高作业车1辆

## 术语统一
- 三级配电箱：分级配电、逐级保护的用电网络
- 一机一闸一漏一箱：每台用电设备独立配备开关箱、漏电保护器
- 停电—验电—挂牌—上锁：停电作业四步程序
- 三检制：自检、互检、交接检（第十二章定义，与本章安全检查衔接）
