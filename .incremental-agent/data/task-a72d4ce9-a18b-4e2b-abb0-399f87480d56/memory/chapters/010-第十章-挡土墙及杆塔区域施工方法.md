# 第十章记忆：挡土墙及杆塔区域施工方法

## 摘要
本章系统描述了双流机场东消防站维修工程中110kV羊航线1#杆塔区域的挡土墙修复及场地硬化施工方案。工程范围涵盖不锈钢护栏拆除/利旧安装、探沟开挖与管线保护、旧挡墙拆除、C20混凝土垫层→Mu15页岩砖砌筑（基础370厚×0.9m高+墙身240厚）、C20地圈梁、杆塔内C20钢筋混凝土地坪（Φ8@150单层双向，2%坡度）、C30预制沟盖板（100×500×1000mm，Φ12@150）、挡土墙外立面抹灰涂装系统及黄黑警示漆等完整施工流程。总打围长度约36m，紧邻高压设施需特别注意安全防护。

## 关键事实（来源确认）
- **数据来源**：`sources/双流机场东消防站维修工程施工方案-背景资料.docx` 全文相关段落。
- **核心工艺链**：护栏拆除→清表→地坪拆除→旧墙拆除→探沟→沟槽开挖→基底处理→垫层→基础砌筑→墙身砌筑→回填→场地平整→地圈梁→地坪→沟盖板→装饰涂装→护栏利旧安装。
- **构造参数矛盾标注**：原方案"构造参数"栏写墙高1.2m，但"砌筑步骤"中写墙身高度0.4m，正文中已明确标注建议与设计核实。推测前者为总高，后者为地面以上净高。
- **Mu15页岩砖**：实际采用页岩砖而非毛石浆砌，这是与一般挡土墙常见的浆砌片石不同的构造形式。
- **管线保护特殊要求**：探沟严禁使用十字镐、钢钎开挖；发现管线须停工报告、影像留底、监理确认后方可继续。
- **无泄水孔/土工格栅/沉降缝设计**：本方案未涉及这些常见挡土墙构造细节。

## 术语统一
- Mu15页岩砖：挡土墙及基础专用砌筑材料
- M10水泥砂浆：挡土墙砌筑用砂浆等级
- 一底两面：底漆1遍+面漆2遍的乳胶漆涂装体系
- 探沟：人工开挖排查地下管线的浅坑（36m×0.8m×1m）
