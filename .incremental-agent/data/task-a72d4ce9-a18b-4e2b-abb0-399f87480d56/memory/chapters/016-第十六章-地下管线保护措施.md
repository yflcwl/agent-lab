# 第十六章 地下管线保护措施 — 章节记忆

## 摘要
本章围绕施工现场既有地下管线的保护工作展开，涵盖管线确认排障、人工探沟探测方案（36m×0.8m×1m）、探沟开挖六步技术要求、裸露管线包裹与支托防护措施、动土作业全过程安全管控、管线事故应急处置流程、LEC风险评价（D=270较大风险）及专项管理台账的建立。全文共七节。

## 关键数据参数
- 探沟总长：36米；宽度：0.8米；深度：1米
- 开挖方式：纯人工，禁用十字镐/钢钎
- LEC评价：L=3, E=6, C=15, D=270（较大风险）
- 报告流程：发现人→项目负责人+动能部→产权单位抢修
- 防护手段：包裹、支托、覆盖保护

## 术语
- 永临结合：探沟同时满足临时探测和永久排水需求
- 管线确认单：产权单位现场确认后形成的书面文件
- 二次确认：管线初步识别后由产权单位再次核实
