# 第十四章 危险源识别与风险管控 — 章节记忆

## 摘要
本章采用LEC评价法（D=L×E×C）对工程危险源进行系统辨识和风险分级。原文提供了两大类清单：①《风险评价及分级管控清单》含施工方案编审项（L/S法，公司级重大风险）；②《作业活动风险评价及分级管控清单》含5大类共5条目（LEC法），每条有L/E/C/D值、风险等级、控制措施和管控层级。主要事故类型为火灾、触电、物体打击、机械伤害四类。
