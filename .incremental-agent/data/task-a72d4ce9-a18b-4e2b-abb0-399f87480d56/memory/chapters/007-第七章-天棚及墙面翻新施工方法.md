# 第七章 天棚及墙面翻新施工方法 - 章节记忆

## 摘要
本章涵盖室内天棚及墙面翻新的施工工艺，包括涂料铲除（4902㎡+500㎡）、13mm干混砂浆抹灰（500㎡）、界面剂涂刷、满挂成品腻子2遍、乳胶漆底漆1遍面漆2遍（4902㎡）、石膏板吊顶新做（135.45㎡，600×600mm同原厚）、铝合金扣板吊顶拆安（拆除135㎡/安装4㎡利旧）以及玻璃贴防爆膜（46.5㎡）。

- sources/双流机场东消防站维修工程项目清单-背景资料.pdf 分部分项工程清单表：项目特征描述（石膏板吊顶规格、抹灰面乳胶漆构造层次等）

## 关键数据
- 天棚及墙面涂料拆除：4,902 ㎡
- 墙柱面铲除混合/水泥砂浆面：500 ㎡
- 墙面一般抹灰（13mm干混砂浆）：500 ㎡
- 抹灰面乳胶漆及腻子：4,902 ㎡
- 玻璃贴防爆膜：46.5 ㎡
- 石膏板吊顶面层新做（600×600mm）：135.45 ㎡
- 铝合金扣板吊顶拆除：135 ㎡ / 安装4 ㎡

## 术语统一
- 满挂成品腻子：指满墙面刮涂成品耐水型腻子膏，不分局部修补
- 一底两面：底漆1遍+面漆2遍的乳胶漆涂装体系
- 利旧回装：拆除后重新安装使用原设备

## 跨章约束
- 第五章已完成前期拆除工作，第七章是后续工序
- 第六章外墙抹灰25mm与第七章内墙抹灰13mm不同，不可混淆
- 第十章挡土墙区域施工中可能涉及室内墙面保护
