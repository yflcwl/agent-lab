# 第八章 车库环氧地坪翻新施工方法 - 章节记忆

## 摘要
本章涵盖车库环氧地面翻新工程的四层施工作业：原环氧地坪铲除(758㎡)、混凝土构件拆除(28m³)、局部C30混凝土找补新做(112㎡/250mm厚)以及混凝土地面固化地坪新做(758㎡)。核心工艺为"清理基层→打磨两遍→坑洞修补→吸尘→混凝土密封固化剂五次固化研磨→三次抛光后撒抛光剂"的固化剂研磨抛光体系，非传统环氧涂层。

## 事实来源
- sources/双流机场东消防站维修工程施工方案-背景资料.docx offset 480~650: "三、车库环氧地面翻新工程"工程量表（4个子目）及项目概况中关于车库环氧地面翻新的描述
- sources/双流机场东消防站维修工程项目清单-背景资料.pdf offset 6037~6900: 【车库环氧地面翻新工程】分部分项清单计价表含详细工序特征描述及单价数据

## 关键数据
- 铲除原环氧地坪: 758㎡ (方案) / 758.560㎡ (清单)，26.80元/㎡
- 混凝土构件拆除: 28m³, 253.11元/m³ (厚度250mm)
- 混凝土楼地面 C30/250mm厚: 112㎡, 149.38元/㎡, 泵送
- 混凝土地面固化地坪: 758㎡ (方案) / 758.560㎡ (清单), 67.60元/㎡
- 分部小计: 95,425.71元
- 编制依据: GB50209-2010《建筑地面工程施工质量验收规范》
