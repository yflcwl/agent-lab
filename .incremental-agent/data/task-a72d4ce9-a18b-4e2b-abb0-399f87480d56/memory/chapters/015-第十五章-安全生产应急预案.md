# 第十五章：安全生产应急预案 — 章节记忆

## 摘要
本章围绕应急管理主题，建立项目应急组织架构（项目经理任组长、设抢险救援/医疗救护/后勤保障/事故调查四组），明确一/二/三级应急响应分级标准和对应报告时限（一级15分钟、二级30分钟、三级项目负责人处置），提供六类专项应急处置措施（高处坠落、物体打击、机械伤害、触电、火灾、中毒窒息）及坍塌应急处置补充措施，涵盖通信联络电话、应急物资装备配备要求与管理制度、演练培训安排、后期处置流程。急救电话85205120，火警85205119。

## 术语定义
- **一级响应**：死亡/重伤、严重机场运行影响事件 → 15分钟内逐级上报
- **二级响应**：轻伤事故、运行不安全事件 → 30分钟内上报
- **三级响应**：后果较轻 → 项目负责人现场处置
- **CPR（心肺复苏）**：触电等无呼吸心跳时的紧急急救手段
- **应急物资台账**：由后勤保障组专人管理，每月检查维护
