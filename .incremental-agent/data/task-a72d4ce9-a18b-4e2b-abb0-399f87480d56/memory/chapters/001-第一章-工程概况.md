# 第一章 工程概况 — 独立记忆

## 摘要
本章介绍了双流机场东消防站维修工程的基本信息、四大类维修改造范围（外墙翻新、天棚及墙面翻新、车库环氧地面翻新、战斗员宿舍卫生间翻新）、计划工期、工程特点分析及场地周边条件简述。

## 关键事实（来源：sources/双流机场东消防站维修工程施工方案-背景资料.docx）
- 编制单位：成都空港建设开发服务有限公司；编制日期：2026年7月
- 项目地址：双流机场东消防站；临近110kV羊航线1#杆塔区域
- 围墙：2.5m轻钢龙骨彩钢板全封闭打围，长约36m
- 作业时段：8:00-18:00
- 工程量清单共四大类，包含42个清单子目

### 外墙翻新工程（16项，约70万元造价）
- 外立面抹灰及涂料拆除/恢复、真石漆等核心面积各1,789㎡
- 保温层拆除1,361㎡
- 铝塑板幕墙88㎡，窗户打胶维修288㎡

### 天棚及墙面翻新工程（5项，约33万元造价）
- 涂料拆除/乳胶漆施工面4,902㎡
- 玻璃防爆膜46.5㎡

### 车库环氧地面翻新工程（4项）
- 铲除旧环氧+新固化地坪各758㎡

### 二楼战斗员宿舍卫生间翻新工程（18项）
- 防水重做、瓷砖铺贴、管线更新
