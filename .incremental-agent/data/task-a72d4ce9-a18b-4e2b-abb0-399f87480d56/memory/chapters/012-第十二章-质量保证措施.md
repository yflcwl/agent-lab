# 第十二章 质量保证措施 — 章节记忆

## 摘要
本章系统构建了工程质量目标体系、质量管理组织职责（项目经理/生产经理/技术负责人/安全负责人/施工员五岗位），以及"三检制"（自检、互检、交接检）的质量管理流程。技术措施涵盖材料进场检验、仓储保管、基层面要求、分层抹灰、干燥等待等关键环节。五个分项工程（外墙翻新、天棚墙面、车库地坪、卫生间改造、挡土墙砌筑）分别列出质量控制要点。成品保护设值班巡检制度和损坏修补记录机制。质量检验按检验批→隐蔽工程→分项工程→竣工验收四级程序执行。提供了砖砌体GB50203-2011允许偏差参数表和砂浆饱满度≥80%指标。针对四类常见质量通病（空鼓开裂、渗漏、起砂脱壳、面砖脱落）给出成因与防治对照表。质量记录档案包含材料合格证、隐蔽验收、试验记录等九类文件。

## 关键参数
- 砂浆饱满度≥80%，百格网检查每检验批不少于5处
- 水平灰缝厚度10mm(8~12mm)，竖向灰缝宽度8~12mm
- 清水墙窗间墙无通缝；混水墙＞300mm通缝不允许，200~300mm每间≤3处
- JS涂膜防水淋浴区墙面≥1800mm高，其余≥300mm
- 闭水试验不少于24h
- 外墙抹灰养护期不少于7d
- 面砖挂网搭接宽度≥150mm

## 术语定义
- 三检制：自检、互检、交接检的统称
- 百格网：检查砂浆饱满度的专用工具
- 闭水试验：蓄水不少于24h观察有无渗漏的质量检测方法
