# 增量写作

## 1. 工作边界
- 一轮只处理一个当前章节
- 同章节追问、失败恢复时如何继承上下文
- 跨章节只能读取哪些持久化信息

## 2. 本轮类型识别
- 新章节写作
- 用户补充后的继续写作
- 审核通过后的提交
- 失败后的恢复
- 已全部完成时的结束处理

## 3. 开始章节
- 必须读取的最小上下文
- outputs/index.json 与计划、滚动状态不一致时的处理原则
- 何时需要读取章节记忆和已完成正文

## 4. 资料定位与事实使用
- source-research-agent 的调用时机、输入与结果要求
- document-summary.md 仅作导航
- 原文读取的规则
- 资料不足、冲突、出现新问题时的决策

## 5. 章节生成与暂存
- 一章正文的生成约束
- save_content 的调用边界
- 不得覆盖已提交正文的规则

## 6. 状态更新与审核
- save_chapter_memory、update_document_state、update_working_plan 的顺序
- 生成完整 ChapterStage 后请求审核
- 审核通过时只提交当前 stage_id
- 审核拒绝或补充时如何继续当前章节

## 7. 失败恢复与结束
- 哪些状态可以恢复
- 哪些情况需要重新检索资料
- 何时判定任务已经完成
